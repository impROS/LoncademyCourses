## Neden bu konu

Bu, **servis eşleştirme** konusudur. Sınav sana bir ihtiyaç verir, sen doğru güvenlik servisini seçersin.
Zorluğu, birbirine çok benzeyen isimlerin olmasıdır: GuardDuty / Inspector / Macie / Detective, KMS / CloudHSM, WAF / Shield.

**Strateji:** Her servis için **tek cümlelik "bu neyi çözer"** cevabını ezberle. Derinlik gerekmiyor.

---

## 1. Şifreleme

### Bekleyen veri (at rest) vs aktarımdaki veri (in transit)
- **At rest:** Diskte/depoda duran veri → S3 sunucu tarafı şifreleme, EBS şifreleme, RDS şifreleme
- **In transit:** Ağda giden veri → **TLS/SSL** (HTTPS), VPN

### AWS KMS (Key Management Service)
- **Şifreleme anahtarlarını oluşturur, saklar ve yönetir.** AWS servislerinin çoğuyla entegredir (S3, EBS, RDS, Lambda...).
- Anahtar türleri: **AWS owned**, **AWS managed** (ücretsiz), **Customer managed key (CMK)** — 💸 aylık ücretlidir.
- **Çok kiracılı (multi-tenant)**, donanım güvenlik modülleriyle desteklenir, **FIPS 140-2/3 Level 3** doğrulanmış HSM'lerde çalışır.
- CloudTrail ile entegre: anahtarın **her kullanımı** loglanır.
- Otomatik **anahtar rotasyonu** desteği vardır.

### AWS CloudHSM
- Sana **ayrılmış (single-tenant), fiziksel** bir donanım güvenlik modülü verir.
- Anahtarları **sen yönetirsin, AWS erişemez.**
- Mevzuat **özel/adanmış HSM** şart koşuyorsa veya kendi anahtar materyalinin tam kontrolünü istiyorsan.
- KMS'ten **daha pahalı ve daha çok yönetim işi.**

> ⭐ **Ayrım:** Varsayılan tercih **KMS**. Soruda *"dedicated hardware security module"*, *"single-tenant"*,
> *"customer must have exclusive control of keys"* geçiyorsa → **CloudHSM.**

### AWS Certificate Manager (ACM)
- **SSL/TLS sertifikalarını** sağlar, yönetir ve **otomatik yeniler.**
- AWS servisleriyle kullanıldığında (ELB, CloudFront, API Gateway) **genel sertifikalar ücretsizdir.**
> Refleks: "SSL/TLS certificate", "HTTPS for my load balancer", "certificate renewal" → **ACM**

## 2. ⭐ Tehdit tespiti dörtlüsü: GuardDuty / Inspector / Macie / Detective

Bu dördü sınavın en sık karıştırdığı gruptur. Her birinin **tek işi** var:

| Servis | Tek cümlelik işi | Neye bakar | Tetikleyici |
|---|---|---|---|
| **Amazon GuardDuty** | **Kötü niyetli/anormal davranışı** tespit eder | CloudTrail, VPC Flow Logs, DNS logları (loglara bakar, ajan kurmaz) | "threat detection", "unusual API activity", "crypto mining", "communication with known malicious IP" |
| **Amazon Inspector** | **Bilinen güvenlik açıklarını** tarar | EC2, konteyner imajları (ECR), Lambda fonksiyonları | "vulnerability scan", "CVE", "unintended network exposure", "software patches missing" |
| **Amazon Macie** | **S3'teki hassas veriyi** bulur | S3 nesneleri (kişisel veri ve kredi kartı numarası tespiti) | "sensitive data", "PII", "personally identifiable information in S3" |
| **Amazon Detective** | Bir bulgunun **kök nedenini** araştırır | GuardDuty bulguları + loglar (grafik analizi) | "investigate the root cause", "analyze security findings" |

**Hafıza kancası:**
- **GuardDuty** = *bekçi köpeği* → sürekli davranış izler, havlar
- **Inspector** = *müfettiş* → yazılım/açık taraması yapar
- **Macie** = *veri dedektifi* → S3'te kişisel veri arar
- **Detective** = *dedektif* → olay sonrası soruşturma

### AWS Security Hub
Yukarıdakilerin (ve daha fazlasının) bulgularını **tek panelde toplar**, yaygın güvenlik standartlarına karşı **otomatik uyumluluk kontrolü** yapar.
> Refleks: "single pane of glass for security findings", "aggregate findings across accounts" → **Security Hub**

---

## 3. Ağ ve uygulama koruması: WAF / Shield / Firewall Manager

| Servis | Neyi durdurur | Katman |
|---|---|---|
| **AWS WAF** | SQL injection, XSS, kötü bot, ülke/IP bazlı filtreleme, rate limiting | **Uygulama katmanı (L7)** — CloudFront, ALB, API Gateway önünde |
| **AWS Shield Standard** | Yaygın **DDoS** saldırıları (L3/L4) | **Tüm AWS müşterileri için otomatik ve ÜCRETSİZ** |
| **AWS Shield Advanced** | Gelişmiş DDoS + 7/24 DDoS Response Team + **maliyet koruması** | 💸 Ücretli (aylık taahhüt) |
| **AWS Firewall Manager** | WAF kurallarını, Shield Advanced korumasını ve SG'leri **birden çok hesapta merkezî yönetir** | Organizations ile |
| **AWS Network Firewall** | VPC için **yönetilen ağ güvenlik duvarı** (trafik filtreleme, IPS) | Ağ katmanı |

> ⭐ **WAF vs Shield:** Web **uygulaması** saldırısı (SQLi/XSS/bot) → **WAF.** Hacimsel **DDoS** → **Shield.**
> ⭐ Shield **Standard** ücretsiz ve **otomatik açıktır**; ayrıca etkinleştirmen gerekmez.

## 4. ⭐ Security Group vs Network ACL

Bu ayrım her sınavda çıkar.

| | **Security Group (SG)** | **Network ACL (NACL)** |
|---|---|---|
| Nerede çalışır | **Instance / ENI** seviyesinde | **Subnet** seviyesinde |
| Durum takibi | **Stateful** — gelen izin verildiyse cevabı otomatik çıkar | **Stateless** — gidiş ve dönüş için **ayrı kural** yazmalısın |
| Kural tipi | **Sadece ALLOW** (deny yazılamaz) | **ALLOW ve DENY** yazılabilir |
| Değerlendirme | **Tüm kurallar** birlikte değerlendirilir | **Numara sırasına göre**, ilk eşleşen kazanır |
| Varsayılan | Tüm gelen kapalı, tüm giden açık | Varsayılan NACL: her şey açık (özel oluşturulan: her şey kapalı) |
| Kaç tane uygulanır | Bir kaynağa birden çok SG | Bir subnet'e **tek** NACL |

**Hafıza kancası:** SG = **kapıdaki güvenlik görevlisi** (kişiyi tanır, çıkarken sormaz).
NACL = **sitenin bariyeri** (giriş ve çıkış için ayrı ayrı kural, kara liste tutabilir).

> Sınav refleksi: "block a specific IP address" → **NACL** (SG deny yazamaz!).
> "allow HTTPS to my web server" → **SG.**

## 5. Sır yönetimi: Secrets Manager vs Parameter Store

| | **AWS Secrets Manager** | **Systems Manager Parameter Store** |
|---|---|---|
| Ne için | Parola, veritabanı kimlik bilgisi, API anahtarı | Konfigürasyon değerleri ve sırlar |
| **Otomatik rotasyon** | **Var** (RDS ile yerleşik entegrasyon) | Yok (kendin kurarsın) |
| Ücret | 💸 Sır başına aylık ücret | **Standard parametreler ücretsiz** |
| Şifreleme | KMS | KMS (SecureString) |

> ⭐ Soruda **"automatically rotate database credentials"** geçiyorsa cevap **Secrets Manager**'dır.
> Sadece ücretsiz konfigürasyon saklama isteniyorsa **Parameter Store.**

## 6. Trusted Advisor (güvenlik tarafı)

Hesabını **otomatik tarar** ve 5 kategoride öneri verir:
**Cost Optimization · Performance · Security · Fault Tolerance · Service Limits (Service Quotas)**

Güvenlik kontrollerine örnek: root'ta MFA yok, S3 bucket'ı herkese açık, güvenlik grubunda `0.0.0.0/0` ile açık port, IAM access key rotasyonu yapılmamış, MFA'sız kullanıcılar.

**Destek planına göre kapsam:**
| Plan | Trusted Advisor kapsamı |
|---|---|
| Basic / Developer | **Sınırlı** kontroller (temel güvenlik + servis limitleri) |
| Business / Enterprise On-Ramp / Enterprise | **Tüm** kontroller + API erişimi + programatik kullanım |

> Detayı 4.3'te. Sınav ipucu: "full set of Trusted Advisor checks" → **Business plan ve üzeri.**

## 7. Sık karıştırılanlar — servis eşleştirme tablosu

| İhtiyaç | Servis |
|---|---|
| Şifreleme anahtarı yönet (varsayılan) | **AWS KMS** |
| Adanmış, tek kiracılı donanım HSM | **AWS CloudHSM** |
| SSL/TLS sertifikası al ve otomatik yenile | **ACM** |
| Anormal/kötü niyetli davranış tespiti | **GuardDuty** |
| EC2 ve konteynerde bilinen güvenlik açığı taraması | **Inspector** |
| S3'te kişisel veri (PII) keşfi | **Macie** |
| Güvenlik olayının kök nedeni araştırması | **Detective** |
| Tüm güvenlik bulgularını tek panelde topla | **Security Hub** |
| SQL injection ve XSS'i engelle | **WAF** |
| DDoS koruması (ücretsiz, otomatik) | **Shield Standard** |
| Gelişmiş DDoS + uzman ekip + maliyet koruması | **Shield Advanced** |
| Çok hesapta WAF/Shield kurallarını merkezî yönet | **Firewall Manager** |

| Ücretsiz konfigürasyon parametresi sakla | **Parameter Store** |
| Hesap genelinde güvenlik/maliyet önerileri | **Trusted Advisor** |

## 🖥 Pratik — Güvenlik düğmelerini gör ve dene (35 dk)

**💸 Maliyet:** Bu pratikte **ücretli hiçbir şey açmıyorsun.** KMS müşteri anahtarı, Secrets Manager sırrı,
GuardDuty/Inspector/Macie **açılmayacak** — sadece incelenecek.

### A. Security Group: stateful davranışı gör (ücretsiz)
1. `VPC` → sol menü → **Security groups** → **Create security group**.
   - **Name:** `sg-deneme` · **Description:** `clfc02 test` · **VPC:** varsayılan VPC
   - **Inbound rules** → **Add rule:** Type `HTTPS`, Source `My IP`
   - **Outbound rules:** dokunma (varsayılan: tüm çıkış açık)
   - **Create security group**
2. Oluşan gruba gir. **Şunu fark et:** Inbound'da sadece 1 kural var, **Deny seçeneği yok** — SG'de sadece ALLOW yazılır.
3. **Stateful ne demek:** Gelen HTTPS isteğine **cevap dönmek için outbound kural yazmadın.** SG bağlantıyı hatırlar,
   cevabı otomatik geçirir. NACL'de böyle olmayacak — birazdan göreceksin.

### B. Network ACL: stateless ve numaralı kurallar
4. `VPC` → sol menü → **Network ACLs** → varsayılan NACL'e tıkla.
5. **Inbound rules** sekmesi: `100 · All traffic · Allow` ve `* · All traffic · Deny` satırlarını gör.
   - **Numara sırası** var: küçük numara önce değerlendirilir, ilk eşleşen kazanır.
   - `*` kuralı **explicit deny**'dır ve silinemez — hiçbir kural eşleşmezse trafiği keser.
6. **Outbound rules** sekmesine geç: **ayrı bir kural listesi** olduğunu gör.
   **İşte stateless budur:** dönüş trafiği için ayrıca izin gerekir.
7. **Edit inbound rules** ekranını aç → **Deny** seçeneğinin **var** olduğunu gör → **Cancel**.

- [ ] **Gözlem:** SG'de Deny yok, NACL'de var. Bir IP'yi engellemek gerekiyorsa → **NACL.**

### C. KMS: anahtarlara bak, oluşturma 💸
8. `KMS` → **AWS managed keys**: `aws/s3`, `aws/ebs`, `aws/rds` gibi anahtarları gör. **Bunlar ücretsizdir.**
9. **Customer managed keys** → **Create key** ekranını aç:
   - **Key type:** Symmetric / Asymmetric seçeneklerini gör
   - **Key material origin** ve **Key rotation** seçeneklerini incele
   - **💸 CANCEL ile çık.** Müşteri yönetimli anahtar aylık ücretlidir (~1 USD/ay), silmesi de 7–30 günlük bekleme gerektirir.

### D. Parameter Store: ücretsiz sır saklama (aç–kullan–sil)
10. `Systems Manager` → sol menü → **Parameter Store** → **Create parameter**.
    - **Name:** `/clfc02/deneme-ayar`
    - **Tier:** `Standard` (**ücretsiz**)
    - **Type:** `String`
    - **Value:** `merhaba-clfc02`
    - **Create parameter**
11. Parametreye tıkla, değerini gör.
12. Şimdi `Secrets Manager` konsolunu aç, **Store a new secret** ekranına gir:
    - **Secret type** seçeneklerini gör (RDS credentials, other type of secret)
    - **Rotation** adımının varlığını fark et — **Parameter Store'da bu yok.**
    - **💸 CANCEL ile çık.** Secrets Manager sır başına aylık ücretlidir.

- [ ] **Gözlem:** Otomatik rotasyon = Secrets Manager. Ücretsiz konfigürasyon = Parameter Store.

### E. Tehdit tespiti servisleri: sadece incele 💸
13. `GuardDuty` açılış sayfasını aç. **Neyi analiz ettiğini** oku: CloudTrail olayları, VPC Flow Logs, DNS logları.
    **💸 "Enable GuardDuty" butonuna basma** (30 günlük ücretsiz deneme sonrası ücretlidir).
14. `Inspector` açılış sayfası: **EC2, ECR imajları ve Lambda** için zafiyet taraması yaptığını gör. **Etkinleştirme.**
15. `Macie` açılış sayfası: **S3'te hassas veri keşfi** yaptığını gör. **Etkinleştirme.**
16. `Security Hub` açılış sayfası: hangi standartları desteklediğini gör (AWS Foundational Security Best Practices, CIS, PCI DSS). **Etkinleştirme.**

> Dördünün de açılış sayfasındaki **tek cümlelik tanımı oku.** Sınavda tam olarak o cümleler soru olur.

### F. Trusted Advisor güvenlik kontrolleri
17. `Trusted Advisor` → **Security** kategorisi.
18. Görebildiğin kontrolleri oku (ör. MFA on Root Account, Security Groups – Unrestricted Access).
19. **Root MFA kontrolü yeşil mi?** Değilse 0.1 dosyasına dön ve MFA'yı tak.

### 💸 Temizlik
20. `Systems Manager` → **Parameter Store** → `/clfc02/deneme-ayar` seç → **Delete**.
21. `VPC` → **Security groups** → `sg-deneme` seç → **Actions** → **Delete security group**.
- [ ] **Kontrol:** Parametre silindi, güvenlik grubu silindi, GuardDuty/Inspector/Macie/Security Hub **kapalı**, KMS'te müşteri anahtarı **yok**.

## Sınavda nasıl sorulur — örnek kalıplar

**Kalıp 1 — Dörtlü ayrım**
> *A company wants to discover credit card numbers stored in its S3 buckets.* → **Amazon Macie**
> *A company wants to detect EC2 instances communicating with known malicious IP addresses.* → **Amazon GuardDuty**
> *A company wants to scan EC2 instances for software vulnerabilities (CVEs).* → **Amazon Inspector**

**Kalıp 2 — WAF vs Shield**
> *Which service protects a web application from SQL injection?* → **AWS WAF**
> *Which service provides DDoS protection at no additional cost to all AWS customers?* → **AWS Shield Standard**

**Kalıp 3 — SG vs NACL**
> *Which allows explicit DENY rules to block a specific IP address at the subnet level?* → **Network ACL**
> *Which is stateful and applied at the instance level?* → **Security group**

**Kalıp 4 — KMS vs CloudHSM**
> *A regulation requires single-tenant, dedicated hardware for key storage.* → **AWS CloudHSM**

**Kalıp 5 — Secrets**
> *A company needs to rotate RDS database credentials automatically.* → **AWS Secrets Manager**

## 60 saniyelik özet

- **KMS** = varsayılan anahtar yönetimi · **CloudHSM** = adanmış tek kiracılı HSM · **ACM** = SSL/TLS sertifikası.
- **GuardDuty** davranış · **Inspector** zafiyet · **Macie** S3'te hassas veri · **Detective** kök neden · **Security Hub** hepsini toplar.
- **WAF** L7 (SQLi/XSS/bot) · **Shield Standard** ücretsiz DDoS · **Shield Advanced** ücretli + DRT · **Firewall Manager** merkezî yönetim.
- **SG:** instance, stateful, sadece allow · **NACL:** subnet, stateless, allow+deny, numaralı.
- **Secrets Manager** otomatik rotasyon (ücretli) · **Parameter Store** ücretsiz konfigürasyon.
- **Trusted Advisor:** 5 kategori; tüm kontroller **Business plan ve üzeri**.
