## 1. Sabit maliyet vs değişken maliyet

| | **Sabit maliyet (fixed / CapEx)** | **Değişken maliyet (variable / OpEx)** |
|---|---|---|
| Ne zaman ödersin | **Önden**, kullanmadan | **Kullandıkça**, ay sonunda |
| Kullanmasan | Yine ödersin | Ödemezsin |
| Örnek | Sunucu satın alma, veri merkezi kirası, jeneratör | EC2 saati, S3 GB, veri transferi |
| Riski | Yanlış tahmin = atıl donanım veya yetersiz kapasite | Kontrolsüz kullanım = şişen fatura |

**Bulutun temel vaadi:** sabit maliyeti değişken maliyete çevirmek → **yanlış tahminin cezası ortadan kalkar.**

> Klasik şirket içi sorunu: Kara Cuma'ya göre sunucu alırsın, yılın 360 günü o kapasitenin %90'ı **boşta durur** ama parasını ödersin.
> Bulutta o kapasiteyi sadece 5 gün açar, sonra kapatırsın.

---

## 2. TCO — Toplam Sahip Olma Maliyeti

**TCO (Total Cost of Ownership):** Bir sistemin ömrü boyunca **görünen + görünmeyen** tüm maliyetleri.

Şirket içi TCO'nun içindekiler — ve buluta geçince ne oluyor:

| Kalem | Şirket içi | AWS'te |
|---|---|---|
| Sunucu donanımı | Peşin alım + 3–5 yılda yenileme | Yok (kullanım ücretine gömülü) |
| Veri merkezi alanı / rack | Kira, tadilat | Yok |
| **Elektrik ve soğutma** | Sürekli, büyük kalem | Yok |
| Ağ donanımı, kablolama | Alım + bakım | Yok |
| **Yedek donanım (spare)** | Atıl duran stok | Yok |
| Fiziksel güvenlik | Personel, kamera, kart sistemi | Yok (AWS'in sorumluluğu) |
| **Sistem yöneticisi işgücü** | Yama, izleme, donanım değişimi | **Büyük ölçüde azalır** |
| Yazılım lisansları | Ayrı satın alım | BYOL veya lisans-dahil |
| Fazladan kapasite (over-provisioning) | Zorunlu | Gerekmez |

> ⚠️ **Sınav tuzağı:** TCO karşılaştırmasında insanlar sadece sunucu fiyatına bakar.
> AWS'in vurguladığı nokta, **elektrik, soğutma, alan ve personel** gibi "gizli" kalemlerin de yok olmasıdır.

**TCO'yu hesaplayan araç:** **AWS Pricing Calculator** (eski adı TCO Calculator / Simple Monthly Calculator).
Göç senaryosunda iş gerekçesi çıkarmak için: **Migration Evaluator**.

## 3. Right-sizing — doğru boyutlandırma

**Tanım:** Her iş yükünü **ihtiyacı kadar** kaynakla çalıştırmak; ne fazla ne eksik.

Buluttaki en büyük israf kalemi: **aşırı boyutlandırılmış (over-provisioned)** kaynaklar.
Şirket içinde makineyi büyük almak zorundaydın (sonradan değiştiremezsin); bulutta **istediğin an küçültebilirsin.**

**Right-sizing döngüsü:**
1. **Ölç** — CloudWatch metrikleri (CPU, bellek, ağ)
2. **Öneri al** — **AWS Compute Optimizer** (ML tabanlı instance tipi önerisi) veya **Trusted Advisor** (düşük kullanımlı instance uyarısı)
3. **Küçült / değiştir**
4. **Tekrarla** — tek seferlik iş değil, sürekli bir alışkanlık

> Sınav refleksi: *"instances are underutilized / running at 5% CPU"* → **right-sizing** + **Compute Optimizer**.

---

## 4. Otomasyon ve yönetilen servisler → işgücü maliyeti

Bulut ekonomisinin en az konuşulan ama sınavda çıkan kısmı: **insan maliyeti.**

| Yaklaşım | Kimin işi |
|---|---|
| EC2 üzerinde kendi MySQL'ini kur | Yamalar, yedekleme, failover, izleme = **senin** |
| Amazon RDS kullan | Bunların hepsi = **AWS'in** |
| Lambda kullan | Sunucu diye bir şey yok = **hiç kimsenin** |

Bu geçişin adı: **operational overhead** (işletim yükü) azaltmak.
> Sınavda **"LEAST operational overhead"** ifadesini gördüğünde her zaman **en yönetilen / serverless** şıkkı seç.

Altyapıyı kod olarak yazmanın (CloudFormation, Systems Manager) ekonomik faydası aynıdır: manuel iş = adam-saat = para.

---

## 5. Lisans maliyetleri: BYOL vs lisans dahil

| Model | Ne demek | Ne zaman avantajlı |
|---|---|---|
| **BYOL (Bring Your Own License)** | Elindeki lisansı AWS'e taşırsın | Zaten satın alınmış, taşınabilir (mobility hakkı olan) lisansların varsa |
| **License Included** | Lisans ücreti saatlik AWS fiyatına gömülüdür (örn. Windows Server'lı EC2, SQL Server'lı RDS) | Yeni lisans almak istemiyorsan, kısa süreli/değişken kullanımda |

**AWS License Manager:** Lisans kullanımını takip eder, aşımları engeller, uyumsuzluğu raporlar.
> Sınav refleksi: *"track software license usage and stay compliant"* → **AWS License Manager**.

Ek not: Bazı lisanslar **Dedicated Host** gerektirir (fiziksel çekirdek/soket bazlı lisanslama).
Bu yüzden Dedicated Host, sınavda genelde **BYOL / lisans uyumluluğu** senaryolarıyla birlikte geçer.

---

## 6. Bulut ekonomisinin diğer kalemleri

- **Kullanılmayanı kapat:** Test/geliştirme ortamlarını gece ve hafta sonu durdurmak, EC2 faturasının %60–70'ini düşürebilir. (Instance Scheduler / Systems Manager)
- **Doğru fiyat modeli:** Sürekli çalışan iş yükü → Savings Plans/Reserved. Kesintiye dayanıklı → Spot. (Detayı 4.1)
- **Doğru depolama sınıfı:** Nadiren erişilen veriyi S3 Standard'da tutmak israftır → lifecycle kuralı. (Detayı 3.6)
- **Veri transferi:** Bulut **içine** giriş genelde ücretsiz, **dışarı** çıkış ücretlidir — mimari kararlarını etkiler.
- **Elastikiyet = doğrudan tasarruf:** Gece kapasiteyi düşürmek faturayı düşürür.

| Soruda geçen | Doğru cevap |
|---|---|

| "LEAST operational overhead" | En **yönetilen/serverless** seçenek |

## 🖥 Pratik — Pricing Calculator ile gerçek bir TCO karşılaştırması (25 dk)

**Amaç:** Bir mimarinin aylık maliyetini kendin çıkarmak ve şirket içi maliyetle karşılaştırmak.
**💸 Maliyet:** **Ücretsiz.** Hesap bile gerekmez (`calculator.aws` herkese açıktır), ama konsoldan da açılır.

### Adımlar
1. Tarayıcıda `https://calculator.aws` aç → **Create estimate**.
2. **Region:** çalıştığın region.
3. **Add service** → arama kutusuna `EC2` yaz → **Amazon EC2** → **Configure**.
   - **Tenancy:** Shared Instances
   - **Operating system:** Linux
   - **Workload:** `Constant usage`
   - **Number of instances:** `2`
   - **Instance type:** `t3.medium` (arama kutusuna yaz)
   - **Pricing strategy:** önce `On-Demand` seç → **aylık tutarı not et:** ______ USD
   - Şimdi `Compute Savings Plans` → `3 year` → `No Upfront` seç → **yeni tutarı not et:** ______ USD
   - **Aradaki fark yüzde kaç?** ______ %
4. **Add service** → `S3` → **Amazon S3** → **Configure**.
   - **S3 Standard storage:** `500` GB/ay
   - **PUT/COPY/POST/LIST requests:** `100000`
   - **GET requests:** `1000000`
   - **Data transfer OUT to internet:** `100` GB/ay → **not et:** ______ USD
   - **Gözlem:** Veri **içeri** girişinin (inbound) fiyatına bak — **0 USD** olmalı. Bu, sınavda çıkan bir kuraldır.
5. Üstten **View summary** → toplam **aylık** ve **12 aylık** maliyeti gör.
6. **Export** → **CSV** ile indir (isteğe bağlı, arşivin olsun).

### Şirket içi karşılaştırma (kâğıt üzerinde, 5 dk)
Aynı 2 sunucuyu kendi ofisinde çalıştırsan, 3 yıl için şunları topla:

| Kalem | 3 yıllık tahmin |
|---|---|
| 2 sunucu donanımı | |
| Elektrik + soğutma | |
| Rack/alan | |
| Sistem yöneticisi (ayda 4 saat × saatlik ücret) | |
| Yedek donanım | |
| **TOPLAM** | |

- [ ] **Sonuç:** AWS 3 yıllık toplam ______ USD · Şirket içi ______ USD

> Rakam tutmasa da önemli değil — sınavda hesap sorulmaz. Önemli olan **TCO'nun içinde hangi kalemler olduğunu** görmen.

### 💸 Temizlik
Hiçbir kaynak açmadın; tahmin `calculator.aws` üzerinde kalır, ücret doğurmaz.

## Sınavda nasıl sorulur — örnek kalıplar

**Kalıp 1**
> *Which cost is eliminated when a company moves from an on-premises data center to AWS?* → **Power and cooling** (elektrik/soğutma)

> *Several EC2 instances consistently run below 10% CPU utilization. Which practice reduces cost?* → **Right-sizing** (ve **Compute Optimizer** ile öneri alma)

**Kalıp 3**
> *A company wants to estimate the monthly cost of a proposed AWS architecture before deploying.* → **AWS Pricing Calculator**

**Kalıp 4**
> *Which option requires the LEAST operational overhead for running a relational database?* → **Amazon RDS** (EC2'ye kendin kurmak değil)

**Kalıp 5**
> *A company wants to use its existing Microsoft licenses on AWS.* → **BYOL** (takip için **License Manager**, bazen **Dedicated Host**)

## 60 saniyelik özet

- **Sabit → değişken maliyet:** kullanmadığına ödemezsin, yanlış tahminin cezası kalkar.
- **TCO** = donanım + alan + **elektrik/soğutma** + ağ + yedek donanım + **personel** + lisans. Buluta geçince bunların çoğu yok olur.
- **Right-sizing:** ölç → Compute Optimizer önerisi → küçült → tekrarla.
- **Yönetilen servis = daha az işgücü.** "LEAST operational overhead" → serverless/managed seç.
- **BYOL** kendi lisansın · **License Included** fiyata gömülü · **License Manager** takip eder.
- **Pricing Calculator** = önden tahmin · **Cost Explorer** = geçmiş analiz · **Migration Evaluator** = göç iş gerekçesi.
