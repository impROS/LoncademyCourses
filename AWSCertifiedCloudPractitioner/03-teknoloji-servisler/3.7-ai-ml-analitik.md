## Neden bu konu

Bu konuda **derinlik yok, eşleştirme var.** Sınav sana bir ihtiyaç verir (*"sesi metne çevirmek"*),
sen servisin adını söylersin (*Transcribe*). Hepsi **tek cümlelik tanım** düzeyindedir.

**Strateji:** Aşağıdaki iki tabloyu ezberle. Her servis için tek bir fiil aklında kalsın.

## 1. Hazır (pre-trained) AI servisleri — makine öğrenmesi bilmeden kullanılır

| Servis | **Tek fiil** | Girdi → Çıktı | Örnek |
|---|---|---|---|
| **Amazon Rekognition** | **GÖR** | Görüntü/video → nesne, yüz, metin, uygunsuz içerik | Fotoğrafta kaç kişi var, yüz eşleştirme |
| **Amazon Textract** | **OKU** | Taranmış **belge** → metin, tablo, form alanları | Faturadan tutar çıkarma, kimlik okuma |
| **Amazon Comprehend** | **ANLA** | Metin → duygu, varlık (entity), anahtar ifade, dil, konu | Müşteri yorumlarının olumlu/olumsuz analizi |
| **Amazon Transcribe** | **YAZ** (sesten metne) | Ses/video → metin (altyazı) | Çağrı merkezi kaydının dökümü |
| **Amazon Polly** | **KONUŞ** (metinden sese) | Metin → doğal ses | Sesli haber okuma, telefon menüsü anonsu |
| **Amazon Translate** | **ÇEVİR** | Metin → başka dilde metin | Site içeriğinin yerelleştirilmesi |
| **Amazon Lex** | **SOHBET ET** | Konuşma/metin → sohbet botu (Alexa'nın motoru) | Müşteri hizmetleri botu |
| **Amazon Kendra** | **ARA** | Kurumsal doküman → akıllı arama | Şirket içi bilgi arama |
| **Amazon Personalize** | **ÖNER** | Kullanıcı davranışı → ürün önerisi | E-ticaret öneri motoru |
| **Amazon Fraud Detector** | **YAKALA** | İşlem verisi → dolandırıcılık skoru | Sahte hesap/ödeme tespiti |
| **Amazon Forecast** | **TAHMİN ET** | Zaman serisi → gelecek tahmini | Talep/stok tahmini |

**Hafıza kancası (en çok karışan üçlü):**
- Görüntüde **nesne/yüz** → **Rekognition**
- **Belgede** yazı/tablo/form → **Textract**
- Elindeki **metnin anlamı** → **Comprehend**

**Ses yönü tuzağı:**
- **Transcribe** = ses → **metin** (*transcript* = döküm)
- **Polly** = metin → **ses** (*Polly konuşur*)

## 2. Kendi modelini kurma ve üretken yapay zekâ

| Servis | Ne yapar |
|---|---|
| **Amazon SageMaker AI** | Kendi makine öğrenmesi modelini **hazırlama, eğitme, ayarlama ve yayınlama** platformu. Uçtan uca ML yaşam döngüsü |
| **Amazon Bedrock** | Farklı sağlayıcıların **temel modellerine (foundation models)** tek API ile erişim; üretken yapay zekâ uygulamaları geliştirme |
| **Amazon Q** | AWS'in üretken yapay zekâ **asistanı** — AWS hakkında sorulara cevap verir, kod ve iş verisi üzerinde çalışır |

> ⭐ **Ayrım:** Hazır bir yetenek yeterli mi → **AI servisleri** (Rekognition, Comprehend...).
> **Kendi verinle kendi modelini** mi eğiteceksin → **SageMaker AI**.
> Hazır **temel modelle üretken yapay zekâ uygulaması** mı → **Bedrock**.

## 3. Analitik servisleri

| Servis | **Tek cümlelik işi** | Tetikleyici |
|---|---|---|
| **Amazon Athena** | **S3'teki veriye doğrudan SQL** sorgusu; sunucusuz, taranan veri kadar öde | "query data in S3 using SQL", "serverless queries", "no infrastructure" |
| **AWS Glue** | Sunucusuz **ETL** (çıkar-dönüştür-yükle) ve **veri kataloğu** | "ETL", "data catalog", "prepare and transform data" |
| **Amazon EMR** | Yönetilen **Hadoop / Spark / Hive** kümesi | "Apache Spark", "Hadoop", "big data framework" |
| **Amazon Kinesis** | **Gerçek zamanlı akış (streaming)** verisi toplama ve işleme | "real-time streaming data", "clickstream", "IoT telemetry" |
| **Amazon Data Firehose** | Akış verisini **S3/Redshift/OpenSearch'e** teslim eder | "deliver streaming data to a destination" |
| **Amazon QuickSight** | **İş zekâsı panosu ve görselleştirme** | "dashboards", "business intelligence", "visualize data" |
| **Amazon OpenSearch Service** | Arama ve **log analizi** | "search and analyze logs" |
| **Amazon Redshift** | **Veri ambarı (OLAP)** | "data warehouse", "petabyte-scale analytics" |
| **AWS Data Exchange** | Üçüncü parti veri setlerini bulma ve abone olma | "third-party data sets" |
| **AWS Lake Formation** | **Data lake** kurulumunu ve izinlerini kolaylaştırır | "build a data lake quickly, manage permissions" |

### ⭐ Athena vs Redshift (sınavın favorisi)
| | **Athena** | **Redshift** |
|---|---|---|
| Nerede duruyor veri | **S3'te olduğu yerde** | Redshift kümesine **yüklenir** |
| Altyapı | **Sunucusuz** | Küme (cluster) yönetimi (Serverless seçeneği de var) |
| Ücret | **Taranan veri** başına | Küme çalışma süresi başına |
| Ne zaman | Ara sıra, geçici (ad-hoc) sorgular | Sürekli, ağır, karmaşık analitik iş yükü |

---

## 4. Data lake (veri gölü) kavramı

**Tanım:** Ham veriyi, **şemasını önceden tanımlamadan**, olduğu gibi merkezî bir yerde saklama yaklaşımı.

- Merkezinde **Amazon S3** vardır (ucuz, sınırsız, dayanıklı).
- Üzerinde **Glue** (katalog/ETL), **Athena** (SQL), **EMR** (büyük veri), **Redshift** (ambar),
  **QuickSight** (görselleştirme), **SageMaker** (ML) çalışır.
- **Lake Formation** bu yapıyı kurmayı ve izinleri yönetmeyi kolaylaştırır.

| | **Data lake** | **Data warehouse** |
|---|---|---|
| Veri | Ham, her formatta (yapılandırılmış + yapılandırılmamış) | Temizlenmiş, yapılandırılmış |
| Şema | Okuma anında (schema-on-read) | Yazma anında (schema-on-write) |
| Servis | **S3** | **Redshift** |

> ⭐ Sınav refleksi: "central repository for all raw data at any scale" → **S3 tabanlı data lake**.

## 🖥 Pratik — Üç AI servisini 20 dakikada dene (30 dk)

**💸 Maliyet:** Polly, Rekognition ve Comprehend'in **ücretsiz kullanım katmanları** vardır ve bu pratikteki
kullanım oldukça küçüktür (birkaç yüz karakter, birkaç görüntü). **QuickSight'a abone OLMAYACAKSIN** —
abonelik ücret doğurur.

### A. Amazon Polly — metni sese çevir
1. Konsol araması → `Amazon Polly` → **Text-to-Speech**
2. **Language:** `Turkish` · **Voice:** `Filiz`
3. Metin kutusuna yapıştır:
```
AWS Certified Cloud Practitioner sinavina calisiyorum. Polly metni sese ceviren servistir.
```
4. **Listen** butonuna bas — **dinle.**
5. **Download** ile MP3'ü indir (isteğe bağlı).
6. **Neural** ve **Standard** motor seçeneklerini dene, farkı duy.

- [ ] **Gözlem:** Model eğitmedin, sunucu açmadın. **Hazır AI servisi** böyle çalışır.

### B. Amazon Rekognition — görüntüyü analiz et
7. Konsol araması → `Amazon Rekognition` → sol menü → **Label detection** (Demos altında)
8. Ekrandaki **örnek görüntüyle** başlar. Sağdaki **Results** panelinde tespit edilen
   nesneleri ve **confidence (güven) yüzdelerini** oku.
9. Sol menüden **Facial analysis** demosunu aç: yaş aralığı, gözlük, duygu tahminleri.
10. İstersen **Upload image** ile kendi fotoğrafını dene (küçük bir dosya).
   *(Kişisel fotoğraf yüklemek istemiyorsan örnek görüntülerle devam et — sınav için fark etmez.)*

- [ ] **Kaydet:** Rekognition örnek görüntüde en yüksek güvenle hangi etiketi buldu? ____________

### C. Amazon Comprehend — metni anla
11. Konsol araması → `Amazon Comprehend` → **Launch Amazon Comprehend** → **Real-time analysis**
12. **Input text** kutusuna şunu yapıştır (İngilizce daha zengin sonuç verir):
```
I ordered a laptop from ACME Corp in Berlin on March 3rd. The delivery was very late and the support team was unhelpful.
```
13. **Analyze** → sekmeleri incele:
   - **Entities:** `ACME Corp` (ORGANIZATION), `Berlin` (LOCATION), `March 3rd` (DATE)
   - **Key phrases**
   - **Sentiment:** `NEGATIVE` ✅
   - **Language**
14. Metni olumluya çevirip (`The delivery was fast and support was excellent.`) tekrar analiz et.
    **Sentiment `POSITIVE` oluyor mu?**

- [ ] **Gözlem:** Comprehend metnin **anlamını** çıkarır. Textract olsaydı **taranmış bir belgeden yazıyı** çıkarırdı.

### D. Analitik servislerini incele (oluşturma)
15. Konsol araması → `Amazon Athena`. **Query editor**'ü aç.
    - Athena'nın çalışması için bir **sonuç bucket'ı** ister; **ayarlama, sadece ekranı gör.**
    - Sol tarafta **Data sources / Database / Tables** panelini gör: veri **S3'te durur**, Athena onu **yerinde** sorgular.
16. Konsol araması → `AWS Glue` → **Crawlers** ve **Data Catalog** bölümlerini gör.
    Glue'nun işi: S3'teki veriyi **tarayıp şemasını çıkarmak** ve kataloğa yazmak. **Oluşturma.**
17. Konsol araması → `Amazon QuickSight`.
    **💸 "Sign up for QuickSight" butonuna BASMA** — abonelik ücret doğurur. Sadece açıklama sayfasını oku.
18. Konsol araması → `Amazon SageMaker AI` → açılış sayfasındaki adımları oku:
    veri hazırlama → model eğitme → dağıtma. **Studio açma** (💸 kaynak başlatır).

### 💸 Temizlik
Bu pratikte kalıcı kaynak oluşturmadın. Kontrol et:
- [ ] QuickSight aboneliği **yok**
- [ ] SageMaker'da çalışan **notebook/endpoint yok** (`SageMaker AI` → **Notebooks** ve **Endpoints** boş)
- [ ] S3'te yeni bucket oluşmadı

## 60 saniyelik özet

- **Rekognition** gör · **Textract** belge oku · **Comprehend** metni anla · **Transcribe** ses→metin ·
  **Polly** metin→ses · **Translate** çevir · **Lex** sohbet botu · **Kendra** kurumsal arama ·
  **Personalize** öneri · **Fraud Detector** dolandırıcılık · **Forecast** tahmin.
- **SageMaker AI** = kendi modelin · **Bedrock** = temel modeller · **Amazon Q** = AWS asistanı.
- **Athena** S3'te SQL (sunucusuz, taranan veri kadar) · **Glue** ETL+katalog · **EMR** Spark/Hadoop ·
  **Kinesis** gerçek zamanlı akış · **QuickSight** panolar · **OpenSearch** log arama · **Redshift** veri ambarı.
- **Data lake** = S3 merkezli, ham veri, schema-on-read. **Data warehouse** = Redshift, temiz veri, schema-on-write.
