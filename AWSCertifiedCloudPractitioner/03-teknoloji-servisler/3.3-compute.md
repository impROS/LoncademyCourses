## Neden bu konu

Compute, 3. alanın en ağır parçasıdır. Sınav burada **"hangi iş yükü için hangi compute servisi"** diye sorar.
Cevap her zaman şu spektrumda bir yerdedir:

> **EC2** (her şey senin) → **Konteyner (ECS/EKS)** → **Fargate** (sunucu yok, konteyner var) → **Lambda** (hiçbir şey yok, sadece fonksiyon)

## 1. Amazon EC2 (Elastic Compute Cloud)

**Ne:** Bulutta kiraladığın sanal sunucu. Üzerinde ne çalıştıracağın tamamen sana kalmış.

### Temel kavramlar
- **AMI (Amazon Machine Image):** Instance'ın açılış şablonu — işletim sistemi + önceden kurulu yazılım.
  Kendi AMI'ni oluşturup aynı sunucuyu defalarca açabilirsin.
- **Instance type:** Makinenin boyutu ve karakteri (`t3.micro`, `m5.large`, `c6i.4xlarge`).
  Okunuşu: `m5.large` → **m** aile, **5** nesil, **large** boyut.
- **Key pair:** SSH ile bağlanmak için anahtar çifti. (Alternatif: **Systems Manager Session Manager** — anahtarsız bağlantı.)
- **User data:** Instance ilk açılırken **bir kez** çalışan başlangıç betiği.
- **Security group:** Instance'ın sanal güvenlik duvarı.

### ⭐ Instance aileleri (sınavda çıkar)

| Aile | Adı | Ne için | Örnek |
|---|---|---|---|
| **General purpose** | Dengeli | Web sunucusu, küçük veritabanı, dev/test | `t3`, `t4g`, `m5`, `m7g` |
| **Compute optimized** | CPU ağırlıklı | Toplu işlem, oyun sunucusu, bilimsel modelleme, yüksek performanslı web | `c5`, `c7g` |
| **Memory optimized** | Bellek ağırlıklı | Büyük **veritabanları**, bellek içi önbellek, gerçek zamanlı büyük veri analizi | `r5`, `x2`, `z1d` |
| **Storage optimized** | Yüksek disk I/O | Veri ambarı, dağıtık dosya sistemleri, saniyede çok sayıda disk işlemi ([IOPS ↗](../00-baslangic/03-kavram-sozlugu.md#iops)) yapan veritabanları | `i3`, `d3`, `h1` |
| **Accelerated computing** | GPU/FPGA | Makine öğrenmesi eğitimi, grafik işleme, video kodlama | `p4`, `g5`, `inf` |

> **Hatırlama tüyosu:** **C** = CPU · **R** = RAM · **I/D/H** = disk (I/O) · **P/G** = GPU · **M/T** = genel amaçlı.
> Not: **AWS Graviton** (ARM tabanlı, `g` ekli: `m7g`, `c7g`) daha iyi fiyat/performans ve **daha düşük enerji tüketimi** sunar
> → sürdürülebilirlik sorularında da geçer.

### EC2 yaşam döngüsü
`pending` → `running` → (`stopping` → `stopped`) → `shutting-down` → `terminated`

| İşlem | Ne olur | Ücret |
|---|---|---|
| **Stop** | Instance kapanır, EBS diski **kalır**, veri korunur | Compute ücreti **durur**, EBS ücreti **devam eder** |
| **Terminate** | Instance ve (varsayılan olarak) kök diski **silinir** | Her şey durur |
| **Reboot** | Yeniden başlar, IP ve disk korunur | Devam eder |
| **Hibernate** | RAM içeriği diske yazılır, açılışta kaldığı yerden devam | EBS ücreti devam eder |

## 2. Elastic Load Balancing (ELB) ve Auto Scaling

### Elastic Load Balancing
Gelen trafiği **birden çok hedefe** (EC2, konteyner, IP, Lambda) dağıtır. Sağlıksız hedefe trafik göndermez (**health check**).

| Tür | Katman | Ne için |
|---|---|---|
| **Application Load Balancer (ALB)** | L7 (HTTP/HTTPS) | Web uygulamaları, yol/host bazlı yönlendirme, mikroservisler, konteynerler |
| **Network Load Balancer (NLB)** | L4 (TCP/UDP/TLS) | **Aşırı yüksek performans**, milyonlarca istek/sn, statik IP, düşük gecikme |
| **Gateway Load Balancer (GWLB)** | L3 | Üçüncü parti güvenlik cihazlarını (firewall, IDS) devreye alma |
| **Classic Load Balancer (CLB)** | Eski nesil | Yeni projelerde kullanılmaz |

> Refleks: HTTP/HTTPS ve yönlendirme kuralı → **ALB.** Ultra düşük gecikme, TCP/UDP, statik IP → **NLB.**

### Amazon EC2 Auto Scaling
Instance sayısını **talebe göre otomatik** artırır/azaltır. Sağlıksız instance'ı **sonlandırıp yenisini açar**.

- **Launch template:** Yeni instance'ın nasıl açılacağı (AMI, tip, SG, user data)
- **Minimum / Desired / Maximum capacity:** Alt sınır, hedef, üst sınır
- **Scaling policy:** Hedef takibi (örn. ortalama CPU %50'de kalsın), adım adım, planlı (scheduled)
- **Health check:** Bozuk instance'ı değiştirir → **self-healing**

> ⭐ **ELB + Auto Scaling birlikte** = elastikiyet + yüksek erişilebilirlik + hata toleransı.
> Sınavın en sevdiği kombinasyon budur.

## 3. AWS Lambda ve serverless

**Ne:** Kodunu yüklersin; bir **olay** (event) tetiklediğinde çalışır. Sunucu yönetmezsin, hatta sunucu görmezsin.

**Özellikleri:**
- **Olay tetikli:** S3'e dosya yüklendiğinde, API Gateway isteği geldiğinde, EventBridge zamanlayıcısıyla, DynamoDB değişiminde...
- **Ücretlendirme:** **İstek sayısı + çalışma süresi (ms) × ayrılan bellek.** Çalışmıyorken **0 USD.**
- **Maksimum çalışma süresi: 15 dakika.** Daha uzun süren işler Lambda'ya uygun değildir (→ ECS/Fargate/Batch).
- **Otomatik ölçeklenir** — eşzamanlı binlerce çağrıyı kendisi karşılar.
- Diller: Python, Node.js, Java, Go, .NET, Ruby + özel çalışma zamanları, konteyner imajı.

> ⭐ **Refleks:** "run code without provisioning servers", "pay only when the code runs",
> "event-driven", "short-lived tasks" → **Lambda**
> ⚠️ **Tuzak:** 15 dakikadan uzun süren iş, sürekli çalışan servis veya özel işletim sistemi gerektiren durum → **Lambda değil.**

**Serverless ailesi (sınavda "serverless" denince akla gelmesi gerekenler):**
Lambda · Fargate · S3 · DynamoDB · SQS · SNS · API Gateway · EventBridge · Step Functions · Aurora Serverless · Athena

## 4. Konteynerler: ECS, EKS, ECR, Fargate

| Servis | Ne |
|---|---|
| **Amazon ECS** (Elastic Container Service) | AWS'in **kendi** konteyner orkestrasyon servisi. Basit, AWS ile derin entegre |
| **Amazon EKS** (Elastic Kubernetes Service) | Yönetilen **Kubernetes**. Kubernetes standardına ihtiyacın varsa / taşınabilirlik istiyorsan |
| **Amazon ECR** (Elastic Container Registry) | Konteyner **imajlarının** deposu (Docker Hub'ın AWS'teki karşılığı) |
| **AWS Fargate** | ECS ve EKS için **sunucusuz çalıştırma motoru** — EC2 yönetmezsin |

**Launch type (çalıştırma tipi) farkı — sınavda çıkar:**
| | **EC2 launch type** | **Fargate launch type** |
|---|---|---|
| Sunucuları kim yönetir | **Sen** (yama, ölçekleme, kapasite) | **AWS** |
| Ücret | Çalışan EC2'lere göre | **Konteynerin kullandığı vCPU/bellek** kadar |
| Kontrol | Yüksek (instance tipi seçersin) | Düşük ama işletim yükü yok |

> Refleks: "run containers without managing servers" → **AWS Fargate**
> "managed Kubernetes" → **Amazon EKS** · "store container images" → **Amazon ECR**

## 5. Diğer compute servisleri

| Servis | Tek cümlelik işi | Ne zaman |
|---|---|---|
| **Amazon Lightsail** | **Sabit aylık fiyatlı**, basitleştirilmiş sanal sunucu + veritabanı + yük dengeleyici paketi | Basit web sitesi, WordPress, küçük uygulama; AWS'e yeni başlayan, öngörülebilir fiyat isteyen |
| **AWS Batch** | **Toplu iş (batch)** yüklerini planlar ve çalıştırır, kapasiteyi kendi ayarlar | Bilimsel hesaplama, render, gece çalışan büyük işler |
| **AWS Outposts** | AWS donanımı senin veri merkezinde | Hibrit, düşük gecikme, veri yerelleştirme |
| **AWS Elastic Beanstalk** | Kodu ver, altyapıyı AWS kursun | Hızlı web uygulaması dağıtımı (3.1'de detaylı) |
| **AWS App Runner** | Konteyner/kaynak kodundan doğrudan yönetilen web servisi | En az kurulumla web servisi yayınlama |
| **Amazon EC2 Auto Scaling** | Kapasiteyi otomatik ayarla | Elastikiyet |

## 🖥 Pratik A — User data ile 60 saniyede web sunucusu (25 dk)

**Amaç:** EC2 + Security Group + user data zincirini uçtan uca görmek.
**💸 Maliyet:** `t3.micro`/`t2.micro` Free Tier kapsamındadır. Public IPv4 adresi için saatlik çok küçük bir ücret
(~0,005 USD/saat) işleyebilir. **1 saat içinde bitir ve terminate et** — toplam maliyet birkaç kuruştur.

### Adımlar
1. `EC2` → **Launch instances**
2. **Name:** `web-denemesi`
3. **AMI:** `Amazon Linux 2023` (Free tier eligible)
4. **Instance type:** `t3.micro` veya `t2.micro` (Free tier eligible)
5. **Key pair:** `Proceed without a key pair`
6. **Network settings** → **Edit**:
   - **Auto-assign public IP:** `Enable`
   - **Firewall (security groups):** `Create security group`
   - **Security group name:** `web-denemesi-sg`
   - Kuralları şöyle bırak/ekle: **Type `HTTP` · Source `My IP`**
     *(SSH kuralına ihtiyacın yok, ekleme.)*
7. **Advanced details** bölümünü aç → en alttaki **User data** kutusuna yapıştır:

```bash
#!/bin/bash
dnf install -y httpd
systemctl enable --now httpd
TOKEN=$(curl -s -X PUT "http://169.254.169.254/latest/api/token" -H "X-aws-ec2-metadata-token-ttl-seconds: 300")
AZ=$(curl -s -H "X-aws-ec2-metadata-token: $TOKEN" http://169.254.169.254/latest/meta-data/placement/availability-zone)
IID=$(curl -s -H "X-aws-ec2-metadata-token: $TOKEN" http://169.254.169.254/latest/meta-data/instance-id)
cat > /var/www/html/index.html <<HTML
<h1>CLF-C02 calisiyor</h1>
<p>Availability Zone: $AZ</p>
<p>Instance ID: $IID</p>
HTML
```

8. **Launch instance** → **Instances** listesinde `2/2 checks passed` olana kadar bekle (1–2 dk).
9. Instance'ı seç → **Public IPv4 address** değerini kopyala.
10. Tarayıcıda **`http://<public-ip>`** adresini aç. *(HTTPS değil, `http://`!)*

- [ ] **Sonuç:** Sayfada "CLF-C02 calisiyor" ve **AZ adı** görünüyor mu? ✅
- [ ] **Kaydet:** Instance hangi AZ'de açıldı? ______________

> **Ne oldu?** Sen hiçbir sunucuya bağlanmadın. **User data** açılışta çalıştı, web sunucusunu kurdu.
> **Security group** sadece senin IP'nden HTTP'ye izin verdi. Bu, **immutable infrastructure**'ın temelidir:
> sunucuyu elle kurmuyorsun, **açılış betiği kuruyor.**

### Güvenlik grubunu test et
11. `EC2` → **Security Groups** → `web-denemesi-sg` → **Inbound rules** → **Edit**.
12. HTTP kuralının **Source** değerini `My IP` yerine bir başka IP'ye (`1.2.3.4/32`) çevir → **Save**.
13. Tarayıcıda sayfayı yenile → **artık açılmıyor** (zaman aşımı).
14. Kuralı `My IP`'ye geri al → sayfa yeniden açılıyor.

- [ ] **Gözlem:** SG değişikliği **anında** etkili oldu, instance yeniden başlamadı. SG **instance seviyesinde** çalışır.

### 💸 Temizlik (ŞART)
15. `EC2` → **Instances** → `web-denemesi` → **Instance state** → **Terminate (delete) instance**.
16. `terminated` olduğunu doğrula.
17. **Security Groups** → `web-denemesi-sg` → **Delete security group** (instance tamamen silinince serbest kalır).
18. **Elastic Block Store → Volumes** → `available` durumda volume kalmadığını doğrula.
19. **Elastic IPs** → boş olmalı.

## 🖥 Pratik B — İlk Lambda fonksiyonun (15 dk)

**💸 Maliyet:** Lambda'nın ücretsiz kullanım katmanı aylık 1 milyon istek içerir. Bu pratik **ücretsizdir.**

1. Konsol araması → `Lambda` → **Create function**
2. **Author from scratch** · **Function name:** `merhaba-clfc02` · **Runtime:** `Python 3.12` → **Create function**
3. **Code source** bölümüne şunu yapıştır (mevcut kodun üzerine yaz) → **Deploy**:

```python
import json, os, datetime

def lambda_handler(event, context):
    return {
        "statusCode": 200,
        "body": json.dumps({
            "mesaj": "Lambda calisti, sunucu yonetmedim",
            "isim": event.get("isim", "bilinmiyor"),
            "bellek_mb": context.memory_limit_in_mb,
            "kalan_sure_ms": context.get_remaining_time_in_millis(),
            "bolge": os.environ.get("AWS_REGION"),
            "zaman": datetime.datetime.utcnow().isoformat()
        })
    }
```

4. **Test** sekmesi → **Create new event** → **Event name:** `deneme` → JSON kutusuna:
```json
{ "isim": "Ridvan" }
```
→ **Save** → **Test**.

5. **Execution results** panelinde şunları oku:
   - Dönen JSON
   - **Duration** (kaç ms çalıştı) → **faturan bu**
   - **Billed duration**, **Memory size**, **Max memory used**
   - **Log output**

- [ ] **Kaydet:** Fonksiyon kaç ms çalıştı? ______ ms

6. **Configuration** → **General configuration** → **Edit**:
   **Timeout** değerini gör. Maksimuma çıkarmayı dene → **15 dakikadan fazlasını kabul etmez.**
   **Bu, sınavda sorulan bir limittir.** **Cancel**.
7. **Monitor** sekmesi → **View CloudWatch logs**: Lambda'nın logları otomatik **CloudWatch Logs**'a düşer.

### 💸 Temizlik
8. `Lambda` → **Functions** → `merhaba-clfc02` → **Actions** → **Delete** → onayla.
9. `CloudWatch` → **Log groups** → `/aws/lambda/merhaba-clfc02` → **Delete** (küçük ama olsun, alışkanlık).

## 60 saniyelik özet

- **EC2:** tam kontrol; **AMI** şablon, **user data** açılış betiği, **instance type** boyut/karakter.
- **Aileler:** M/T genel · **C** CPU · **R/X** bellek · **I/D/H** disk · **P/G** GPU. **Graviton** = ARM, ucuz + enerji verimli.
- **Stop** → compute durur, **EBS ücreti devam eder**. **Terminate** → her şey gider.
- **ELB:** ALB (HTTP/L7) · NLB (TCP/UDP, ultra hızlı, statik IP) · GWLB (güvenlik cihazları).
- **Auto Scaling:** min/desired/max + politika; sağlıksızı değiştirir (**self-healing**).
- **Lambda:** olay tetikli, **maks 15 dk**, çalıştığı kadar öde, otomatik ölçek.
- **ECS** AWS'in orkestratörü · **EKS** Kubernetes · **ECR** imaj deposu · **Fargate** sunucusuz konteyner.
- **Lightsail** sabit fiyat/basit · **Batch** toplu iş · **Outposts** kendi veri merkezin.
