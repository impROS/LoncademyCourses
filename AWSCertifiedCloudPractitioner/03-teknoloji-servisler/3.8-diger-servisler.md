## 1. ⭐ Mesajlaşma ve entegrasyon

Bu grubun tek amacı var: **bileşenleri birbirinden ayırmak (loose coupling).**

| Servis | Model | Tek cümlelik işi |
|---|---|---|
| **Amazon SQS** (Simple Queue Service) | **Kuyruk** (1 mesaj → 1 tüketici) | Mesajları güvenle **saklar**, tüketici hazır olduğunda **çeker (pull)**. Gönderen ile alan birbirini beklemez |
| **Amazon SNS** (Simple Notification Service) | **Pub/Sub** (1 mesaj → N abone) | Bir mesajı **birden çok aboneye aynı anda gönderir (push)**: e-posta, SMS, HTTP, Lambda, SQS |
| **Amazon EventBridge** | **Olay veri yolu (event bus)** | Olayları kurallara göre **doğru hedefe yönlendirir**; AWS servisleri ve SaaS uygulamalarıyla entegre; **zamanlanmış (cron)** tetikleme de yapar |
| **AWS Step Functions** | **İş akışı (workflow)** | Birden çok adımı **görsel durum makinesi** olarak sıraya koyar; hata yönetimi, tekrar deneme, dallanma |

### ⭐ SQS vs SNS — sınavın klasiği

| | **SQS** | **SNS** |
|---|---|---|
| Model | Kuyruk, **pull** | Yayın (pub/sub), **push** |
| Alıcı sayısı | Bir mesajı **bir** tüketici işler | Bir mesaj **tüm abonelere** gider |
| Mesaj saklanır mı | **Evet** (varsayılan 4 gün, en fazla 14 gün) | **Hayır** — anlık iletir |
| Kullanım | Sipariş işleme kuyruğu, yük tamponu | Bildirim, alarm, fan-out |

**Ezber cümlesi:** *SQS bekletir, SNS dağıtır.*
> Fan-out kalıbı: **SNS → birden çok SQS kuyruğu** (hem dağıtım hem güvenli saklama).

## 2. İzleme ve yönetim

| Servis | Tek cümlelik işi |
|---|---|
| **Amazon CloudWatch** | Metrik, log, alarm, pano — **sistem nasıl çalışıyor** |
| **AWS CloudTrail** | API çağrısı denetim kaydı — **kim ne yaptı** |
| **AWS Config** | Kaynak konfigürasyonu ve **uyumluluk** — **kurala uygun mu** |
| **AWS Systems Manager** | Sunucu filosunu işletme: **Patch Manager**, **Session Manager** (anahtarsız bağlantı), **Parameter Store**, **Run Command**, envanter |
| **AWS Compute Optimizer** | ML tabanlı **doğru kaynak boyutu** önerisi |
| **AWS Service Catalog** | Kurumun **onaylı ürün/şablon kataloğu** — kullanıcılar sadece izin verilenleri açar |
| **AWS Service Quotas** | Servis **limitlerini** görüntüleme ve **artırma talebi** |
| **AWS Health Dashboard** | AWS servis kesintileri ve **hesabına özel** olaylar |
| **AWS Trusted Advisor** | Hesabı tarar, 5 kategoride öneri verir |
| **AWS License Manager** | Yazılım lisansı takibi ve uyumluluk |
| **AWS Well-Architected Tool** | Soru-cevap temelli mimari öz-değerlendirme |
| **AWS Launch Wizard** | Belirli iş yüklerini (SAP, SQL Server) rehberli kurma |

### CloudWatch bileşenleri (biraz detay)
- **Metrics:** sayısal ölçümler (CPU, ağ, istek sayısı). Özel (custom) metrik gönderebilirsin.
- **Alarms:** eşik aşılınca aksiyon (SNS bildirimi, Auto Scaling, EC2 durdurma).
- **Logs:** uygulama ve servis logları (Lambda logları otomatik buraya düşer).
- **Dashboards:** özel panolar.
- **Events (EventBridge):** olay tabanlı tetikleme.

> ⚠️ **Tuzak:** EC2'nin **bellek (memory) kullanımı** varsayılan metriklerde **yoktur** —
> **CloudWatch agent** kurulması gerekir. Bu, sınavda geçebilen bir ayrıntıdır.

## 🖥 Pratik — SNS ve SQS'i uçtan uca çalıştır (30 dk)

**💸 Maliyet:** SNS'in ücretsiz katmanı aylık 1.000 e-posta bildirimi, SQS'inki 1 milyon istek içerir.
Bu pratik **ücretsizdir.**

### A. SNS konusu oluştur ve kendine abone ol
1. Konsol araması → `Amazon SNS` → **Topics** → **Create topic**
   - **Type:** `Standard` · **Name:** `clfc02-bildirim` → **Create topic**
2. Konu sayfasında → **Create subscription**
   - **Protocol:** `Email` · **Endpoint:** kendi e-posta adresin → **Create subscription**
3. **E-postana git**, AWS'ten gelen *"AWS Notification - Subscription Confirmation"* mesajındaki
   **Confirm subscription** bağlantısına tıkla.
4. Konsolda **Subscriptions** listesinde durumun `Confirmed` olduğunu gör.

### B. Mesaj yayınla
5. Konu sayfasında → **Publish message**
   - **Subject:** `CLF-C02 testi`
   - **Message body:** `SNS bir mesaji tum abonelere ayni anda gonderir.`
   - **Publish message**
6. **E-postanı kontrol et** — mesaj geldi. ✅

- [ ] **Gözlem:** SNS **push** yaptı; sen bir şey sormadın, mesaj sana geldi.

### C. Fan-out: aynı konuya ikinci abone ekle
7. CloudShell'i aç ve bir SQS kuyruğu oluştur:
```bash
QURL=$(aws sqs create-queue --queue-name clfc02-kuyruk --query QueueUrl --output text)
QARN=$(aws sqs get-queue-attributes --queue-url $QURL --attribute-names QueueArn --query Attributes.QueueArn --output text)
echo $QURL; echo $QARN
```
8. Konu ARN'ini al ve kuyruğu konuya abone et:
```bash
TARN=$(aws sns list-topics --query "Topics[?contains(TopicArn,'clfc02-bildirim')].TopicArn" --output text)
aws sqs set-queue-attributes --queue-url $QURL --attributes "{\"Policy\":\"{\\\"Version\\\":\\\"2012-10-17\\\",\\\"Statement\\\":[{\\\"Effect\\\":\\\"Allow\\\",\\\"Principal\\\":{\\\"Service\\\":\\\"sns.amazonaws.com\\\"},\\\"Action\\\":\\\"sqs:SendMessage\\\",\\\"Resource\\\":\\\"$QARN\\\",\\\"Condition\\\":{\\\"ArnEquals\\\":{\\\"aws:SourceArn\\\":\\\"$TARN\\\"}}}]}\"}"
aws sns subscribe --topic-arn $TARN --protocol sqs --notification-endpoint $QARN
```
9. Yeni bir mesaj yayınla:
```bash
aws sns publish --topic-arn $TARN --subject "Fan-out" --message "Bu mesaj hem e-postaya hem kuyruga gitti."
```
10. Hem **e-postana** bak, hem kuyruğu oku:
```bash
aws sqs receive-message --queue-url $QURL --max-number-of-messages 1 --query "Messages[0].Body" --output text
```

- [ ] **Gözlem:** **Tek yayın, iki hedef.** Buna **fan-out** denir ve `SNS → SQS` kalıbı sınavda geçer.

### D. SQS'in "bekletme" özelliğini gör
11. Kuyruğa doğrudan mesaj gönder:
```bash
aws sqs send-message --queue-url $QURL --message-body "Beni kimse okumazsa 4 gun beklerim."
```
12. Konsolda `Amazon SQS` → `clfc02-kuyruk` → **Messages available** sayacını gör.
13. **Send and receive messages** → **Poll for messages** → mesajı gör → seç → **Delete**.
14. Kuyruk detaylarında **Message retention period** ayarına bak: varsayılan **4 gün**, maksimum **14 gün.**

- [ ] **Gözlem:** SNS mesajı **saklamaz**, SQS **saklar**. Sınavda bu fark sorulur.

### E. Systems Manager Session Manager'a bak
15. Konsol araması → `Systems Manager` → **Session Manager** → **Start session** ekranını aç.
    Çalışan instance olmadığı için liste boş olacak. **Şunu not et:** Session Manager ile EC2'ye
    **SSH anahtarı olmadan ve 22 portu açmadan** bağlanılır — sınavda güvenlik sorusu olarak çıkar.

### F. Service Quotas
16. Konsol araması → `Service Quotas` → **AWS services** → `Amazon Elastic Compute Cloud (Amazon EC2)`
17. Bir kotayı seç (örn. *Running On-Demand Standard instances*), **Applied quota value** değerini gör.
18. **Request increase at account level** butonunu gör (**basma**). Sınav refleksi:
    *"increase a service limit"* → **Service Quotas.**

### 💸 Temizlik
19. ```bash
aws sqs delete-queue --queue-url $QURL
aws sns delete-topic --topic-arn $TARN
```
20. Konsolda doğrula: SNS → Topics boş, SQS → Queues boş.
- [ ] **Kontrol:** Her ikisi de silindi.

## Sınavda nasıl sorulur — örnek kalıplar

**Kalıp 1 — SQS vs SNS**
> *Which service decouples components using a message queue where messages are stored until processed?* → **Amazon SQS**
> *Which service sends a single message to multiple subscribers such as email, SMS and Lambda?* → **Amazon SNS**

**Kalıp 2 — Step Functions**
> *A company needs to coordinate a multi-step order workflow with retries and error handling.* → **AWS Step Functions**

**Kalıp 3 — Systems Manager**
> *A company must apply operating system patches to hundreds of EC2 instances centrally.* → **AWS Systems Manager (Patch Manager)**

**Kalıp 4 — Service Quotas**
> *A company reached the maximum number of VPCs in a Region and needs an increase.* → **AWS Service Quotas**

**Kalıp 5 — WorkSpaces**
> *A company needs managed virtual desktops for remote employees.* → **Amazon WorkSpaces**

**Kalıp 6 — X-Ray**
> *A developer must find which microservice is causing latency in a request.* → **AWS X-Ray**

## 60 saniyelik özet

- **SQS** bekletir (kuyruk, pull, 4–14 gün) · **SNS** dağıtır (pub/sub, push) · **EventBridge** olayı kurala göre yönlendirir ·
  **Step Functions** iş akışını sıraya koyar.
- **CloudWatch** nasıl · **CloudTrail** kim · **Config** uygun mu.
- **Systems Manager:** Patch Manager, **Session Manager (anahtarsız bağlantı)**, Parameter Store, Run Command.
- **Service Quotas** limit artırma · **Service Catalog** onaylı ürün kataloğu · **Health Dashboard** kesinti bildirimi.
- **X-Ray** izleme (tracing) · **CodePipeline** CI/CD · **Amplify** ön yüz.
- **WorkSpaces** sanal masaüstü · **AppStream** uygulama akışı · **Connect** çağrı merkezi · **SES** e-posta · **IoT Core** cihazlar.
