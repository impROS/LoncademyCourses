# 1.3 — Date-Time API: LocalDate, Duration, Period, Instant ve Saat Dilimleri

> **Alan:** Handling Date, Time, Text, Numeric and Boolean Values — tahmini ~2 soru
> **Süre:** ~35 dakika okuma + 20 dakika pratik
> **Test:** [`1.3-test.html`](1.3-test.html) · 14 soru

## Neden bu konu

`java.time` günlük işte kolay görünür çünkü IDE hangi metodun hangi tipte olduğunu söyler. Sınavda
söylemez ve API'nin en can alıcı özelliği tam burada: **her tip belirli birimleri destekler, desteklemediği
birim verildiğinde çalışma zamanında patlar.** `LocalDate`'e `Duration` eklemek derlenir ama
`UnsupportedTemporalTypeException` atar.

**Büyük fikir:** Bu API'de üç ayrı eksen vardır — **tarih mi, saat mi, ikisi mi**; **dilimli mi dilimsiz mi**;
**takvim tabanlı mı (Period) yoksa saniye tabanlı mı (Duration)**. Her soru bu üç eksenden birini yoklar.

---

## 1. ⭐⭐ Tipler haritası

| Tip | Neyi tutar | Örnek `toString()` |
|---|---|---|
| `LocalDate` | Yalnızca tarih | `2026-08-23` |
| `LocalTime` | Yalnızca saat | `14:30` / `14:30:05.100` |
| `LocalDateTime` | Tarih + saat, **dilim yok** | `2026-08-23T14:30` |
| `ZonedDateTime` | Tarih + saat + **saat dilimi** | `2026-08-23T14:30+03:00[Europe/Istanbul]` |
| `Instant` | Epoch'tan beri geçen an (UTC) | `2026-08-23T11:30:00Z` |
| `Period` | **Takvim** aralığı: yıl/ay/gün | `P1Y2M3D` |
| `Duration` | **Zaman** aralığı: saniye/nanosaniye | `PT1H30M` |

### Nesne nasıl üretilir

**Hiçbirinin public constructor'ı yoktur.** `new LocalDate(...)` → **derleme hatası**.

```java
LocalDate d1 = LocalDate.of(2026, 8, 23);
LocalDate d2 = LocalDate.of(2026, Month.AUGUST, 23);
LocalDate d3 = LocalDate.parse("2026-08-23");
LocalDate d4 = LocalDate.now();
LocalTime t1 = LocalTime.of(14, 30);              // saniye istege bagli
LocalDateTime dt = LocalDateTime.of(d1, t1);
ZonedDateTime z  = ZonedDateTime.of(dt, ZoneId.of("Europe/Istanbul"));
Instant i        = Instant.now();
```

> ⚠️ **Tuzak:** Ay **1 tabanlıdır** (`1 = Ocak`) — eski `Calendar` API'sinin aksine.
> Geçersiz değer → **`DateTimeException`**: `LocalDate.of(2026, 2, 30)` çalışma zamanında patlar,
> `LocalDate.of(2026, 13, 1)` de öyle.

## 2. ⭐⭐ Immutability ve `plus`/`minus`

Tüm `java.time` tipleri **immutable**'dır. `plusDays` yeni nesne döner:

```java
LocalDate d = LocalDate.of(2026, 1, 1);
d.plusDays(5);
System.out.println(d);            // 2026-01-01  — degismedi!

LocalDate yeni = d.plusDays(5);   // 2026-01-06
```

Zincirleme çalışır ve **sırayla** uygulanır:

```java
LocalDate x = LocalDate.of(2026, 1, 31)
        .plusMonths(1)      // 2026-02-28  (28'e cekilir, gun tasmaz)
        .plusMonths(1);     // 2026-03-28  (30/31'e geri DONMEZ)
```

> ⚠️⚠️ **Tuzak — sınavın favorisi:** Ay eklerken taşan gün **ayın son gününe çekilir** ve bir daha geri gelmez.
> Bu yüzden **adım sayısı sonucu değiştirir**:
>
> | İfade | Sonuç |
> |---|---|
> | `LocalDate.of(2026,1,31).plusMonths(1).plusMonths(1)` | **`2026-03-28`** |
> | `LocalDate.of(2026,1,31).plusMonths(2)` | **`2026-03-31`** |
>
> İlkinde ara adımda 28'e düşülür ve mart'a 28 olarak taşınır. İkincisinde tek hamlede mart hesaplanır
> ve 31 gün vardır. Aynı işlem, farklı cevap.

| Metot ailesi | Ne yapar |
|---|---|
| `plusX` / `minusX` | Yeni nesne döner (`plusDays`, `plusMonths`, `plusWeeks`, `plusYears`, `plusHours`…) |
| `withX` | O alanı **değiştirir**: `withDayOfMonth(1)`, `withYear(2030)` |
| `getX` | `getYear`, `getMonthValue` (int), `getMonth` (**`Month` enum**), `getDayOfWeek` |
| `isBefore` / `isAfter` / `isEqual` | Karşılaştırma |
| `atTime` / `atDate` / `atStartOfDay` / `atZone` | Tipler arası geçiş |

```java
LocalDate d = LocalDate.of(2026, 8, 23);
LocalDateTime dt = d.atTime(9, 0);          // LocalDate -> LocalDateTime
LocalDateTime g  = d.atStartOfDay();        // 2026-08-23T00:00
ZonedDateTime z  = dt.atZone(ZoneId.of("Europe/Istanbul"));
```

## 3. ⭐⭐ Period vs Duration — en sık sorulan ayrım

| | **`Period`** | **`Duration`** |
|---|---|---|
| Birim | Yıl, ay, gün (**takvim**) | Gün, saat, dakika, saniye, nano (**tam süre**) |
| `toString` | `P1Y2M3D` | `PT26H` / `PT1H30M` |
| `LocalDate` ile | ✅ çalışır | ❌ `UnsupportedTemporalTypeException` |
| `LocalTime` ile | ❌ `UnsupportedTemporalTypeException` | ✅ çalışır |
| `LocalDateTime` ile | ✅ | ✅ |
| `Instant` ile | ❌ | ✅ |
| Yaz saati (DST) | Takvim günü ekler (24 saat olmayabilir) | Tam olarak N saniye ekler |

```java
LocalDate d = LocalDate.of(2026, 1, 1);
d.plus(Period.ofDays(1));         // OK  -> 2026-01-02
d.plus(Duration.ofDays(1));       // DERLENIR, RUNTIME: UnsupportedTemporalTypeException

LocalTime t = LocalTime.of(10, 0);
t.plus(Duration.ofHours(2));      // OK -> 12:00
t.plus(Period.ofDays(1));         // RUNTIME: UnsupportedTemporalTypeException
```

> ⚠️ **Tuzak:** İkisi de `TemporalAmount` arayüzünü uyguladığı için **her ikisi de derlenir**.
> Hata çalışma zamanındadır. Şıklarda `Compilation fails` görürsen bu soruda **yanlıştır**.

### ⭐ Period'un zincir tuzağı

`Period.ofYears`, `ofMonths`, `ofDays` **static fabrika** metotlarıdır — zincirlenince öncekini **ezerler**:

```java
Period p = Period.ofYears(1).ofMonths(2).ofDays(3);
System.out.println(p);            // P3D   !!!  (yalnizca sonuncusu kaldi)

Period q = Period.of(1, 2, 3);    // P1Y2M3D  — dogrusu bu
```

### Duration üretme

```java
Duration.ofDays(1);        // PT24H
Duration.ofHours(26);      // PT26H   — gune cevrilmez
Duration.ofMinutes(90);    // PT1H30M
Duration.of(5, ChronoUnit.SECONDS);   // PT5S
Duration.ofSeconds(90).toMinutes();   // 1  (tam bolum)
```

> ⚠️ `Duration.of(1, ChronoUnit.MONTHS)` → **`UnsupportedTemporalTypeException`**. `Duration` yalnızca
> `DAYS` ve altındaki **kesin** birimleri kabul eder; ay/yıl takvime bağlı olduğu için reddedilir.

### Aralık hesaplama

```java
Period.between(d1, d2);                       // yil/ay/gun olarak
ChronoUnit.DAYS.between(d1, d2);              // long, tek birimde
Duration.between(t1, t2);                     // saat/dakika/saniye
```

## 4. Instant ve saat dilimleri

`Instant` bir **an**'dır (UTC epoch tabanlı). İnsan takvimi bilmez, bu yüzden `Period` kabul etmez.

```java
Instant now = Instant.now();
now.plus(Duration.ofHours(1));      // OK
now.plus(Period.ofDays(1));         // RUNTIME: UnsupportedTemporalTypeException
now.plus(1, ChronoUnit.DAYS);       // OK  (DAYS kesin sure sayilir)
```

| Dönüşüm | Nasıl |
|---|---|
| `Instant` → `ZonedDateTime` | `instant.atZone(zoneId)` |
| `ZonedDateTime` → `Instant` | `zdt.toInstant()` |
| `LocalDateTime` → `Instant` | **Doğrudan olmaz**, önce dilim ver: `ldt.atZone(z).toInstant()` |

### ⭐ Yaz saati (DST)

Yaz saati uygulayan dilimlerde bir gün **23 veya 25 saat** olabilir. Fark burada ortaya çıkar:

| İşlem | Davranış |
|---|---|
| `zdt.plus(Period.ofDays(1))` | **Aynı saat**, ertesi gün. Gerçekte 23 veya 25 saat geçmiş olabilir. |
| `zdt.plus(Duration.ofDays(1))` | **Tam 24 saat**. Saat kadranı 1 saat kaymış görünebilir. |

Geçiş anında var olmayan bir saat verilirse (`ZonedDateTime.of`) API **otomatik olarak ileri kaydırır**,
exception atmaz.

> ⚠️ **Tuzak:** Türkiye 2016'dan beri yaz saati uygulamıyor (kalıcı UTC+03). Sınav sorularında genelde
> `America/New_York` veya `Europe/Paris` kullanılır — dilim adına dikkat et.

## 5. Biçimlendirme ve ayrıştırma

```java
LocalDate d = LocalDate.of(2026, 8, 23);
DateTimeFormatter f = DateTimeFormatter.ofPattern("dd/MM/yyyy");

System.out.println(d.format(f));        // 23/08/2026
System.out.println(f.format(d));        // 23/08/2026   — ikisi de calisir
System.out.println(LocalDate.parse("23/08/2026", f));
```

| Sembol | Anlam | Not |
|---|---|---|
| `y` | Yıl | `yyyy` |
| `M` | Ay | `MM` = 08, `MMM` = Ağu, `MMMM` = Ağustos |
| `d` | Ayın günü | **`D` yılın günü demektir** |
| `H` | Saat 0-23 | **`h` 1-12'dir** |
| `m` | Dakika | **`M` ay demektir** |
| `s` | Saniye | |

> ⚠️ **Tuzak:** Tipin desteklemediği sembolü kullanırsan **çalışma zamanında** `UnsupportedTemporalTypeException`
> atılır: `LocalDate`'i `HH:mm` ile biçimlendirmeye çalışmak gibi.

Hazır biçimlendiriciler: `DateTimeFormatter.ISO_LOCAL_DATE`, `ISO_LOCAL_TIME`, `ISO_LOCAL_DATE_TIME`.

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| `new LocalDate(2026,1,1)` | **Derlenmez** | Public constructor yok; `of()` kullanılır |
| `LocalDate.of(2026, 2, 30)` | Runtime `DateTimeException` | Derlenir; geçersiz değer çalışma zamanında yakalanır |
| `d.plusDays(5);` sonra `d` | Değişmez | Immutable, dönüş atanmadı |
| `LocalDate + Duration` | Runtime `UnsupportedTemporalTypeException` | Derlenir (ikisi de `TemporalAmount`) |
| `LocalTime + Period` | Runtime `UnsupportedTemporalTypeException` | Aynı sebep, ters yön |
| `Period.ofYears(1).ofMonths(2)` | `P2M` | Static metotlar zincirlenmez, ezerler |
| `Duration.ofDays(1)` | `PT24H` | Gün cinsinden gösterilmez |
| `Duration.of(1, ChronoUnit.MONTHS)` | Exception | `Duration` takvim birimi almaz |
| `getMonth()` vs `getMonthValue()` | `Month` enum vs `int` | İkisi farklı tip döner |
| Ay numarası | **1 tabanlı** | Eski `Calendar` 0 tabanlıydı |
| `31 Ocak + 1 ay` | `28/29 Şubat` | Taşan gün son güne çekilir, exception atılmaz |
| `Instant + Period` | Exception | `Instant` takvim bilmez |
| Biçimde `mm` | Dakika | Ay için `MM` kullanılır |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Immutability**
> ```java
> LocalDate d = LocalDate.of(2026, 1, 1);
> d.plusDays(30);
> System.out.println(d);
> ```
> → **`2026-01-01`**. Dönüş atanmadı.

**Kalıp 2 — Yanlış birim**
> ```java
> LocalDate d = LocalDate.of(2026, 1, 1);
> System.out.println(d.plus(Duration.ofDays(1)));
> ```
> → **`UnsupportedTemporalTypeException` at runtime.** `Compilation fails` çeldiricisi yanlıştır.

**Kalıp 3 — Ay taşması**
> ```java
> System.out.println(LocalDate.of(2026, 1, 31).plusMonths(1));
> ```
> → **`2026-02-28`**. Exception atılmaz.

**Kalıp 4 — Period zinciri**
> ```java
> System.out.println(Period.ofYears(2).ofMonths(3));
> ```
> → **`P3M`**. Yıl bilgisi kayboldu.

**Kalıp 5 — Geçersiz tarih**
> ```java
> LocalDate d = LocalDate.of(2026, 2, 30);
> ```
> → **`DateTimeException` at runtime.** Derlenir.

## 60 saniyelik özet

- Constructor yok: `of()`, `parse()`, `now()`. `new LocalDate(...)` **derlenmez**.
- Ay **1 tabanlı**. Geçersiz değer → çalışma zamanında `DateTimeException`.
- Tüm tipler **immutable**; dönüş atanmadıysa satır etkisiz.
- `plusMonths` taşan günü **ayın son gününe çeker**, geri döndürmez.
- `Period` = takvim (yıl/ay/gün), `Duration` = kesin süre (saat/dakika/saniye).
- `LocalDate` + `Duration` ve `LocalTime` + `Period` → **runtime** `UnsupportedTemporalTypeException`.
- `Period.ofYears(1).ofMonths(2)` = `P2M` — static fabrikalar zincirlenmez.
- `Duration.ofDays(1)` → `PT24H`. `Duration.of(1, MONTHS)` → exception.
- `Instant` takvim bilmez: `Period` kabul etmez, `Duration` eder.
- DST'de `Period.ofDays(1)` saat kadranını korur, `Duration.ofDays(1)` tam 24 saat ekler.
- Biçimde `MM` = ay, `mm` = dakika, `HH` = 0-23, `hh` = 1-12, `dd` = ayın günü, `DD` = yılın günü.
