> **Alan:** Handling Exceptions — tahmini ~2 soru
> **Süre:** ~35 dakika okuma + 20 dakika pratik
> **Test:** [`4.1-test.html`](4.1-test.html) · 15 soru

---

## Neden bu konu

Sınav exception'lardan iki tür soru üretir: **akış sorusu** ("bu kod ne yazdırır?") ve
**derlenirlik sorusu** ("bu `catch` ulaşılabilir mi?").

Akış sorularının anahtarı `finally`'dir: **her zaman çalışır** ve içindeki `return`
her şeyi ezer. Derlenirlik sorularının anahtarı ise **hiyerarşi**: alt sınıf `catch`'i üst sınıftan
**önce** gelmeli, multi-catch'te tipler **akraba olmamalı**.

**Büyük fikir:** Checked exception'lar derleyicinin **zorladığı** sözleşmedir: ya yakala ya bildir.
Unchecked olanlar programlama hatasıdır ve derleyici takip etmez.

## 1. ⭐⭐ Hiyerarşi

```
Throwable
├── Error                    (unchecked) — yakalanmamali
│   ├── StackOverflowError
│   ├── OutOfMemoryError
│   └── ExceptionInInitializerError
└── Exception                (CHECKED)
    ├── IOException          (checked)
    │   └── FileNotFoundException
    ├── SQLException         (checked)
    ├── ClassNotFoundException (checked)
    └── RuntimeException     (UNCHECKED)
        ├── NullPointerException
        ├── IllegalArgumentException
        │   └── NumberFormatException
        ├── IllegalStateException
        ├── ArithmeticException
        ├── ClassCastException
        ├── IndexOutOfBoundsException
        │   ├── ArrayIndexOutOfBoundsException
        │   └── StringIndexOutOfBoundsException
        ├── UnsupportedOperationException
        ├── ConcurrentModificationException
        ├── DateTimeException
        └── ArithmeticException
```

| | **Checked** | **Unchecked** |
|---|---|---|
| Kim | `Exception` ve altı, **`RuntimeException` hariç** | `RuntimeException` ve `Error` ve altları |
| Derleyici zorlar mı | ✅ **Yakala ya da bildir** | ❌ |
| Ne anlatır | Beklenen dış sorun (dosya yok, ağ koptu) | Programlama hatası |
| `throws` gerekir mi | ✅ | ❌ (yazılabilir ama gereksiz) |

> ⚠️ **Tuzak:** `NumberFormatException` `IllegalArgumentException`'ın **alt sınıfıdır**, dolayısıyla
> **unchecked**'tir. `Integer.parseInt("abc")` için `try/catch` **zorunlu değildir**.

> ⚠️ **`Error` yakalanabilir** (`catch (Error e)` derlenir) ama **yakalanmamalıdır**.
> `catch (Throwable t)` her şeyi yakalar — sınav bunu "derlenir mi" diye sorabilir: **derlenir**.

## 2. ⭐ Handle-or-declare kuralı

```java
void oku() {
    throw new IOException();            // DERLENMEZ: checked, bildirilmedi
}

void oku2() throws IOException {        // OK: bildirildi
    throw new IOException();
}

void oku3() {
    try { oku2(); }
    catch (IOException e) { }           // OK: yakalandi
}
```

> ⚠️⚠️ **Tuzak:** Bir metodun gövdesinde **atılamayacak** bir checked exception'ı yakalamak
> **derleme hatasıdır**:
> ```java
> try { System.out.println("x"); }
> catch (IOException e) { }        // DERLENMEZ: exception is never thrown in body
> ```
> Ama `Exception` veya `RuntimeException` yakalamak **her zaman geçerlidir**.

---

## 3. ⭐⭐⭐ try / catch / finally akışı

| Kural | Detay |
|---|---|
| Sıra | `try` → (0+ `catch`) → (0-1 `finally`) |
| Yalnız `try` | ❌ En az bir `catch` **veya** `finally` gerekir |
| `finally` çalışır mı | ✅ **Her zaman** — `return`, `break`, `continue`, exception fark etmez |
| Tek istisna | `System.exit()` çağrılırsa `finally` **çalışmaz** |
| `finally` içinde `return` | **Önceki `return`'ü ve exception'ı ezer** |
| `catch` bloğu atarsa | `finally` yine çalışır, sonra exception yayılır |
| İki `catch` aynı anda | ❌ Yalnızca **ilk uyan** çalışır |

```java
static int f() {
    try {
        return 1;
    } finally {
        return 2;         // 1'i EZER
    }
}
f();      // 2
```

```java
static int g() {
    int x = 1;
    try {
        return x;         // donus degeri BURADA hesaplanir (1)
    } finally {
        x = 99;           // gec kaldi
    }
}
g();      // 1
```

> ⚠️⚠️ **Tuzak:** `finally` içinde `return` yazmak exception'ı **sessizce yutar**. Sınav bunu
> "hangi exception fırlatılır?" diye sorar; cevap **hiçbiri**dir.

### Yakalama sırası

```java
try { ... }
catch (Exception e) { }
catch (IOException e) { }      // DERLENMEZ: exception has already been caught
```

**Alt sınıf önce, üst sınıf sonra.** Tersi ulaşılamaz koddur.

## 4. ⭐ Multi-catch

```java
try { ... }
catch (IOException | SQLException e) {     // e ORTUK final
    // e = new IOException();              // DERLENMEZ: atama yapilamaz
    System.out.println(e.getMessage());
}
```

| Kural | Detay |
|---|---|
| Tipler ilişkili olamaz | `catch (IOException \| FileNotFoundException e)` → **derleme hatası** |
| Değişken | **Örtük `final`** — yeniden atanamaz |
| Değişken sayısı | Tek bir isim, sonda |
| Ortak tip | `e`'nin derleme zamanı tipi, listedeki tiplerin **en yakın ortak üst tipidir** |
| Kaç tip | Sınırsız |

> ⚠️ **Tuzak:** `catch (Exception | IOException e)` derlenmez, çünkü `IOException` zaten
> `Exception`'ın altındadır — *alternatives in a multi-catch statement cannot be related by subclassing*.

---

## 5. `throw` vs `throws` ve exception zinciri

| | `throw` | `throws` |
|---|---|---|
| Nerede | Gövde içinde, deyim | Metot imzasında |
| Ne alır | **Bir nesne** | **Bir veya daha çok tip** |
| `throw null;` | Derlenir, çalışma zamanında **NPE** | — |

```java
try {
    dusukSeviye();
} catch (SQLException e) {
    throw new RuntimeException("kayit okunamadi", e);   // sebep (cause) zinciri
}
```

| Metot | Ne verir |
|---|---|
| `getMessage()` | Mesaj metni |
| `getCause()` | Sarmalanan orijinal exception |
| `printStackTrace()` | Yığın izini `System.err`'e yazar |
| `getSuppressed()` | try-with-resources'ta bastırılanlar (4.2) |

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| `NumberFormatException` | **Unchecked** | `IllegalArgumentException`'ın altı |
| `IOException` | **Checked** | Yakala ya da bildir |
| Yalnızca `try { }` | Derlenmez | `catch` veya `finally` şart |
| `catch (Exception e)` sonra `catch (IOException e)` | Derlenmez | Ulaşılamaz |
| Atılmayan checked exception'ı yakalama | Derlenmez | `Exception`/`RuntimeException` istisna |
| `finally`'de `return` | Her şeyi **ezer** | Exception'ı da yutar |
| `try`'da `return x`, `finally`'de `x` değişir | **Eski değer** döner | Dönüş değeri önce hesaplanır |
| `System.exit()` sonrası `finally` | **Çalışmaz** | Tek istisna |
| `catch (IOException \| FileNotFoundException e)` | Derlenmez | Akraba tipler |
| Multi-catch değişkenine atama | Derlenmez | Örtük `final` |
| `throw null;` | Derlenir, **NPE** atar | Derleme hatası değil |
| `catch (Error e)` | Derlenir | Yapılmamalı ama yasak değil |
| Alt sınıfta yeni checked exception | Derlenmez (3.4) | Unchecked serbest |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — finally return**
> ```java
> static int f() { try { return 1; } finally { return 2; } }
> ```
> → **`2`**.

**Kalıp 2 — Yakalama sırası**
> ```java
> try { } catch (Exception e) { } catch (IOException e) { }
> ```
> → **Compilation fails.**

**Kalıp 3 — Atılmayan checked**
> ```java
> try { System.out.println("x"); } catch (IOException e) { }
> ```
> → **Compilation fails.**

**Kalıp 4 — Multi-catch akrabalığı**
> ```java
> catch (FileNotFoundException | IOException e) { }
> ```
> → **Compilation fails.**

**Kalıp 5 — finally exception yutar**
> ```java
> try { throw new RuntimeException(); } finally { return; }
> ```
> → **Hiçbir exception fırlatılmaz.**

## 60 saniyelik özet

- `Exception` **checked**, `RuntimeException` ve `Error` **unchecked**.
- `NumberFormatException` unchecked'tir (`IllegalArgumentException` altı).
- Checked exception: **yakala ya da bildir**. Atılamayan checked'i yakalamak **derleme hatası**
  (`Exception`/`RuntimeException` hariç).
- `try` tek başına olmaz; `catch` veya `finally` gerekir.
- `finally` **her zaman** çalışır — tek istisna `System.exit()`.
- `finally` içindeki `return` önceki `return`'ü **ve exception'ı** ezer.
- `try`'daki `return` ifadesi **hemen** hesaplanır; `finally`'de değişkeni değiştirmek geç kalır.
- `catch` sırası **alt sınıftan üst sınıfa**; tersi ulaşılamaz koddur.
- Multi-catch tipleri **akraba olamaz**; değişken **örtük `final`**'dır.
- `throw` nesne alır, `throws` tip alır; `throw null;` derlenir ve **NPE** atar.
- Exception zinciri için `new X("mesaj", sebep)`; `getCause()` ile okunur.
