# 4.2 — try-with-resources ve Özel Exception'lar

> **Alan:** Handling Exceptions — tahmini ~2 soru
> **Süre:** ~30 dakika okuma + 20 dakika pratik
> **Test:** [`4.2-test.html`](4.2-test.html) · 14 soru

---

## Neden bu konu

try-with-resources sınavın **sıra sorusu** kaynağıdır: kaynaklar hangi sırayla kapanır,
`catch` bloğundan önce mi sonra mı, iki exception aynı anda olursa hangisi kazanır.

Bu üç sorunun cevabı ezberlenir:
**ters sırayla · `catch`'ten önce · gövdedeki kazanır, kapatmadaki bastırılır.**

**Büyük fikir:** try-with-resources, senin yazmadığın gizli bir `finally` bloğudur ve
**`catch`/`finally` bloklarından önce** çalışır.

---

## 1. ⭐ Sözdizimi ve `AutoCloseable`

```java
try (BufferedReader r = new BufferedReader(new FileReader("a.txt"))) {
    System.out.println(r.readLine());
}                                    // catch ve finally ISTEGE BAGLI
```

| Kural | Detay |
|---|---|
| Kaynak tipi | **`AutoCloseable`** uygulamalı (`Closeable` onun alt arayüzüdür) |
| `AutoCloseable.close()` | `throws Exception` |
| `Closeable.close()` | `throws IOException` (daha dar) |
| Kaç kaynak | Sınırsız, **noktalı virgülle** ayrılır |
| Son kaynaktan sonra `;` | İsteğe bağlı |
| Kaynak değişkeni | **Örtük `final`** — gövdede yeniden atanamaz |
| `catch`/`finally` | **İsteğe bağlı** (klasik `try`'ın aksine) |
| Java 9+ | Zaten var olan **effectively final** bir değişken doğrudan yazılabilir |

```java
var r = new BufferedReader(new FileReader("a.txt"));
try (r) { ... }                      // Java 9+ : degisken effectively final olmali
```

```java
try (var a = new Kaynak("A"); var b = new Kaynak("B")) { }
// kapanis sirasi: B, sonra A   <- TERS SIRA
```

## 2. ⭐⭐⭐ Çalışma sırası — ezberlenecek

```
1. Kaynaklar bildirim sirasina gore acilir
2. try govdesi calisir
3. Kaynaklar TERS SIRAYLA kapatilir            <-- catch'ten ONCE
4. catch blogu (varsa ve uyan bir exception varsa)
5. finally blogu (varsa)
```

```java
try (var a = new Kaynak("A"); var b = new Kaynak("B")) {
    System.out.println("govde");
} catch (Exception e) {
    System.out.println("catch");
} finally {
    System.out.println("finally");
}
// cikti: govde / kapandi B / kapandi A / finally
```

> ⚠️⚠️ **Tuzak:** Sınav "`catch` bloğunda kaynağı kullanabilir miyim?" diye sorar. **Hayır** —
> kaynak değişkeni `try` bloğunun **kapsamı dışındadır** ve zaten **kapatılmıştır**.

## 3. ⭐⭐ Bastırılmış (suppressed) exception'lar

Hem gövde hem `close()` exception atarsa:

| Kim atar | Sonuç |
|---|---|
| Yalnızca gövde | Gövdenin exception'ı yayılır |
| Yalnızca `close()` | `close()`'un exception'ı yayılır |
| **İkisi de** | **Gövdeninki yayılır**, `close()`'unki **bastırılır** |

```java
try (var k = new PatlayanKaynak()) {
    throw new RuntimeException("govde");
} catch (Exception e) {
    System.out.println(e.getMessage());                    // govde
    for (Throwable t : e.getSuppressed())
        System.out.println("bastirilan: " + t.getMessage()); // kapatma
}
```

> ⚠️ Klasik `finally` ile yazsaydın `close()`'un exception'ı gövdedekini **tamamen kaybettirirdi**.
> try-with-resources'ın asıl kazancı budur.

| Metot | Ne verir |
|---|---|
| `getSuppressed()` | `Throwable[]` — bastırılanlar, **kapanış sırasında** |
| `addSuppressed(t)` | Elle eklemek için (nadiren gerekir) |

## 4. Özel exception yazma

```java
public class YetersizBakiyeException extends Exception {          // CHECKED
    private final double eksik;

    public YetersizBakiyeException(String mesaj, double eksik) {
        super(mesaj);
        this.eksik = eksik;
    }
    public YetersizBakiyeException(String mesaj, Throwable sebep) {
        super(mesaj, sebep);                                      // zincir
        this.eksik = 0;
    }
    public double eksik() { return eksik; }
}
```

| Karar | Ne seçilir |
|---|---|
| Çağıran **düzeltebilir** mi | Evet → `extends Exception` (**checked**) |
| Programlama hatası mı | Evet → `extends RuntimeException` (**unchecked**) |
| `Error` genişletmek | ❌ Asla |
| Constructor'lar | En az `(String)`; zincir için `(String, Throwable)` |
| Adlandırma | Sonu **`Exception`** ile biter |

> ⚠️ **Tuzak:** `super(mesaj)` çağrılmazsa `getMessage()` **`null`** döner. Sınav bunu
> "ne yazdırır?" diye sorar.

### Kendi `AutoCloseable`'ını yaz

```java
class Kaynak implements AutoCloseable {
    private final String ad;
    Kaynak(String ad) { this.ad = ad; System.out.println("acildi " + ad); }
    @Override public void close() { System.out.println("kapandi " + ad); }
}
```

`close()` daha **dar** bir exception bildirebilir veya hiç bildirmeyebilir (3.4 override kuralı).

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| İki kaynağın kapanma sırası | **Ters** (son açılan önce) | Bildirim sırası değil |
| Kaynak ne zaman kapanır | **`catch`'ten önce** | `finally`'den de önce |
| `catch` içinde kaynak değişkeni | **Kapsam dışı**, derlenmez | Yalnızca `try` gövdesinde |
| Kaynağa yeniden atama | Derlenmez | Örtük `final` |
| `try (res) { }` (Java 9+) | ✅ Geçerli | Değişken effectively final olmalı |
| try-with-resources'ta `catch` yok | ✅ Geçerli | Klasik `try`'da gerekli |
| Gövde + `close()` ikisi de atar | **Gövdeninki** yayılır | `close()`'unki bastırılır |
| `getSuppressed()` | `Throwable[]` | Boş dizi dönebilir, null dönmez |
| `AutoCloseable.close()` | `throws Exception` | `Closeable` daha dar: `IOException` |
| `super(mesaj)` yazılmadı | `getMessage()` **null** | — |
| Özel exception `Error`'dan | Yapılmaz | `Exception`/`RuntimeException` seçilir |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Kapanma sırası**
> ```java
> try (var a = new K("A"); var b = new K("B")) { }
> ```
> → **`kapandi B`**, sonra **`kapandi A`**.

**Kalıp 2 — Kapanma zamanı**
> `try` gövdesi exception atıyor, hem `catch` hem `finally` var. Sıra?
> → **kapatma → `catch` → `finally`**.

**Kalıp 3 — Kaynak kapsamı**
> ```java
> try (var r = new K("A")) { }
> catch (Exception e) { System.out.println(r); }
> ```
> → **Compilation fails.** `r` kapsam dışı.

**Kalıp 4 — Bastırma**
> Gövde `RuntimeException("a")`, `close()` `RuntimeException("b")` atıyor.
> → Dışarı **`a`** çıkar, `getSuppressed()[0]` **`b`**'dir.

**Kalıp 5 — Mesaj null**
> ```java
> class E extends Exception { E(String m) { } }
> System.out.println(new E("x").getMessage());
> ```
> → **`null`**. `super(m)` çağrılmadı.

## 60 saniyelik özet

- Kaynak **`AutoCloseable`** uygulamalı; `Closeable` onun `IOException` atan alt arayüzüdür.
- Kaynak değişkenleri **örtük `final`**; `catch`/`finally` **isteğe bağlıdır**.
- Java 9+: var olan **effectively final** bir değişken `try (r)` biçiminde kullanılabilir.
- Kapanma **ters sırayla** olur ve **`catch`'ten de `finally`'den de önce** gerçekleşir.
- Kaynak değişkeni `catch` bloğunda **görünmez**.
- Gövde ve `close()` birlikte atarsa **gövdeninki yayılır**, `close()`'unki **bastırılır**.
- Bastırılanlara `getSuppressed()` ile ulaşılır; hiç yoksa **boş dizi** döner.
- Klasik `finally` ile kapatmada gövdenin exception'ı **kaybolur** — bu yüzden try-with-resources var.
- Özel exception: düzeltilebilir sorun → `Exception`, programlama hatası → `RuntimeException`.
- `super(mesaj)` çağrılmazsa `getMessage()` **`null`** döner.
