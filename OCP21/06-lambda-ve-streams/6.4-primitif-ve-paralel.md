## Neden bu konu

İki ayrı konu ama aynı yerde sorulur, çünkü ikisi de **stream'in tipini** değiştirir.

Primitif stream'ler sınavda **tip dönüşümü** sorusu üretir: `IntStream`'den `Stream<Integer>`'a
nasıl geçersin, `average()` neden `OptionalDouble` döner.

Paralel stream'ler ise **doğruluk** sorusu üretir: hangi işlem paralelde farklı sonuç verir.

**Büyük fikir:** Primitif stream'ler **kutulamayı ortadan kaldırır** ve karşılığında `sum()`,
`average()` gibi sayısal terminaller kazandırır. Paralellik ise **sırayı ve yan etki güvenliğini**
feda eder — kazanç her zaman garanti değildir.

## 1. ⭐ Üç primitif stream

`IntStream`, `LongStream`, `DoubleStream`. **`CharStream`, `BooleanStream` yoktur.**

| Oluşturma | Yazım |
|---|---|
| Değerlerden | `IntStream.of(1, 2, 3)` |
| Aralık | `IntStream.range(1, 5)` · `rangeClosed(1, 5)` |
| Diziden | `Arrays.stream(new int[]{1,2})` |
| Nesne stream'inden | `stream.mapToInt(String::length)` |
| Metinden | `"abc".chars()` → **`IntStream`** |
| Sonsuz | `IntStream.iterate(1, x -> x + 1)` · `generate` |

### Dönüşümler

| Yön | Metot |
|---|---|
| `Stream<T>` → `IntStream` | `mapToInt(ToIntFunction)` |
| `IntStream` → `Stream<Integer>` | **`boxed()`** |
| `IntStream` → `Stream<R>` | `mapToObj(IntFunction)` |
| `IntStream` → `LongStream` / `DoubleStream` | `asLongStream()` / `asDoubleStream()` |
| `IntStream` → `IntStream` | `map(IntUnaryOperator)` |

```java
List<Integer> l = IntStream.range(1, 4).boxed().toList();          // [1, 2, 3]
List<String> s  = IntStream.range(1, 4).mapToObj(i -> "#" + i).toList();
int toplam = Stream.of("a", "bb").mapToInt(String::length).sum();  // 3
```

> ⚠️ **Tuzak:** `IntStream.toList()` **yoktur**; `boxed().toList()` gerekir.
> `Stream<Integer>` üzerinde de `sum()` **yoktur** — önce `mapToInt` gerekir.

## 2. ⭐⭐ Primitif stream'e özel terminaller

| Metot | Döner | Boş stream'de |
|---|---|---|
| `sum()` | `int` / `long` / `double` | **`0`** |
| `average()` | **`OptionalDouble`** | Boş Optional |
| `min()` / `max()` | **`OptionalInt`** vb. | Boş Optional |
| `count()` | `long` | `0` |
| `summaryStatistics()` | `IntSummaryStatistics` | count=0 |

```java
IntStream.of().sum();          // 0
IntStream.of().average();      // OptionalDouble.empty
IntStream.of(1,2,3).average(); // OptionalDouble[2.0]
IntStream.of(1,2,3).max().getAsInt();   // 3
```

| Optional türü | Değer alma |
|---|---|
| `Optional<T>` | `get()` / `orElse(v)` |
| `OptionalInt` | **`getAsInt()`** |
| `OptionalLong` | `getAsLong()` |
| `OptionalDouble` | `getAsDouble()` |

> ⚠️ `OptionalInt`'te `get()` **yoktur**, `getAsInt()` vardır. Ayrıca `OptionalInt`
> `Optional<Integer>`'ın alt tipi **değildir** — ilişkisiz sınıflardır.

## 3. ⭐⭐ Paralel stream'ler

```java
liste.parallelStream()...          // koleksiyondan dogrudan
stream.parallel()...               // mevcut stream'i paralellestir
stream.sequential()...             // geri al
stream.isParallel()                // kontrol
```

Arkada **ForkJoinPool.commonPool** çalışır; varsayılan iş parçacığı sayısı
`Runtime.getRuntime().availableProcessors() - 1` + ana thread kadardır.

### ⭐ Paralelde ne değişir

| İşlem | Paralelde |
|---|---|
| `forEach` | **Sıra garantisi yok** |
| `forEachOrdered` | Sıra korunur (yavaşlar) |
| `findFirst` | Sıra korunur (yavaşlar) |
| **`findAny`** | Herhangi biri — **paralelde daha hızlı** |
| `sorted`, `distinct`, `limit`, `skip` | Sıra korunur ama **maliyetlidir** |
| `reduce(id, acc)` | Doğru **identity** şart |
| `collect(groupingBy(...))` | Çalışır; `groupingByConcurrent` daha hızlı olabilir |

### ⭐⭐ Doğruluk tuzakları

```java
// YANLIS: yan etkili, thread-safe olmayan biriktirme
List<Integer> sonuc = new ArrayList<>();
IntStream.range(0, 1000).parallel().forEach(sonuc::add);   // veri kaybi / exception

// DOGRU
List<Integer> sonuc2 = IntStream.range(0, 1000).parallel().boxed().toList();
```

```java
// YANLIS identity: her parca kendi identity'sini ekler
Stream.of("a","b","c").parallel().reduce("X", String::concat);   // "XaXbXc" gibi
```

> ⚠️⚠️ **Tuzak:** `reduce`'un identity'si **etkisiz eleman** olmalıdır (toplamada `0`,
> birleştirmede `""`). Aksi hâlde **sıralı çalışmada doğru, paralelde yanlış** sonuç alırsın —
> en sinsi hata türü budur.

### Ne zaman paralel kullanılır

| Uygun | Uygunsuz |
|---|---|
| Çok sayıda eleman | Az eleman (paralellik maliyeti kazancı yer) |
| CPU-yoğun işlem | I/O bekleyen işlem |
| Yan etkisiz (stateless) lambda | Paylaşılan durumu değiştiren lambda |
| `ArrayList`, dizi, `IntStream.range` (kolay bölünür) | `LinkedList`, `Stream.iterate` (zor bölünür) |

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| `IntStream.toList()` | **Yoktur** | `boxed().toList()` |
| `Stream<Integer>.sum()` | **Yoktur** | `mapToInt(...).sum()` |
| `"abc".chars()` | **`IntStream`** | `Stream<Character>` değil |
| `IntStream.average()` | **`OptionalDouble`** | `double` değil |
| `IntStream.of().sum()` | **`0`** | Optional değil |
| `OptionalInt.get()` | **Yoktur** | `getAsInt()` |
| `OptionalInt` ile `Optional<Integer>` | **İlişkisiz** tipler | Birbirine atanamaz |
| Paralelde `forEach` sırası | **Garantisiz** | `forEachOrdered` garanti eder |
| Paralelde `findFirst` | Sırayı korur, **yavaş** | `findAny` hızlı |
| Paralelde koleksiyona `add` | **Güvensiz** | `collect`/`toList` kullan |
| Yanlış identity + paralel | **Yanlış sonuç** | Sıralıda doğru görünebilir |
| `CharStream` | **Yoktur** | Yalnızca Int/Long/Double |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Tip dönüşümü**
> ```java
> List<Integer> l = IntStream.range(1, 4).toList();
> ```
> → **Compilation fails.** `boxed()` gerekir.

**Kalıp 2 — average dönüşü**
> ```java
> double d = IntStream.of(1,2).average();
> ```
> → **Compilation fails.** `OptionalDouble` döner.

**Kalıp 3 — chars tipi**
> ```java
> "abc".chars().forEach(System.out::print);
> ```
> → **`979899`** — karakterler `int` olarak akar.

**Kalıp 4 — Boş primitif stream**
> ```java
> System.out.println(IntStream.of().sum());
> ```
> → **`0`**, boş Optional değil.

**Kalıp 5 — Paralel identity**
> ```java
> Stream.of("a","b").parallel().reduce("X", String::concat);
> ```
> → Sonuç **tahmin edilemez** (`XaXb` veya `XaXb`'den farklı). Identity etkisiz eleman değil.

## 60 saniyelik özet

- Üç primitif stream var: **`IntStream`, `LongStream`, `DoubleStream`**. `CharStream` **yoktur**.
- `Stream<T>` → primitif: **`mapToInt`**; primitif → `Stream<Integer>`: **`boxed()`**;
  primitif → `Stream<R>`: **`mapToObj`**.
- `IntStream.toList()` **yoktur**; `Stream<Integer>.sum()` de **yoktur**.
- `"abc".chars()` → **`IntStream`**.
- `sum()` boş stream'de **`0`**; `average()` **`OptionalDouble`**; `max()` **`OptionalInt`**.
- `OptionalInt.getAsInt()` — `get()` yoktur; `OptionalInt` ile `Optional<Integer>` **ilişkisizdir**.
- `parallelStream()` / `parallel()` / `sequential()` / `isParallel()`.
- Paralelde `forEach` **sırasızdır**; `forEachOrdered` ve `findFirst` sırayı korur ama **yavaşlar**.
- **`findAny` paralelde tercih edilir.**
- `reduce` identity'si **etkisiz eleman** olmalı; değilse paralelde **yanlış sonuç**.
- Paralel `forEach` ile paylaşılan koleksiyona ekleme **güvensizdir** — `collect`/`toList` kullan.
- Paralellik az elemanda ve I/O ağırlıklı işte **fayda getirmez**.
