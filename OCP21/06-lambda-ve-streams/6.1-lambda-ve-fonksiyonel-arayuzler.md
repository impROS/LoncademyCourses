## Neden bu konu

Stream sorularının hepsi lambda üzerinden gelir; hangi **fonksiyonel arayüzün** hangi imzaya sahip
olduğunu bilmiyorsan `map` ile `filter` arasındaki farkı da göremezsin. Sınav doğrudan
**"bu lambda hangi arayüze uyar?"** diye sorar ve şıklara `Supplier`, `Consumer`, `Function` koyar.

İkinci kaynak: **`compose` ve `andThen` sırası** — birbirinin tersidir ve karıştırılır.

**Büyük fikir:** Bir lambda **kendi başına bir tip değildir**; **hedef tipten** (target type) anlam
kazanır. Aynı `x -> x` ifadesi `Function`, `UnaryOperator` veya senin yazdığın arayüz olabilir.

## 1. ⭐ Lambda sözdizimi

```java
() -> 42                            // parametresiz
x -> x * 2                          // tek parametre, parantez ISTEGE BAGLI
(x) -> x * 2                        // ayni sey
(int x) -> x * 2                    // tip yazildi -> parantez ZORUNLU
(var x, var y) -> x + y             // var: HEPSI var olmali
(x, y) -> { return x + y; }         // blok govde -> return ZORUNLU
x -> { System.out.println(x); }     // void govde
```

| Kural | Detay |
|---|---|
| Tek parametre + tip yok | Parantez isteğe bağlı |
| Tip yazılırsa | Parantez **zorunlu**, **tüm** parametrelerde tip olmalı |
| `var` kullanılırsa | **Tüm** parametreler `var` olmalı (karışık yazım hata) |
| Blok gövde | `{ }` + `return` (dönüş tipi `void` değilse) |
| İfade gövde | `return` **yazılmaz** |
| Yakalanan yerel değişken | **Effectively final** (3.2) |
| Parametre adı | Çevredeki bir yerel değişkenle **aynı olamaz** |
| `this` | **Çevreleyen sınıfı** gösterir (3.8) |

```java
int x = 5;
Function<Integer,Integer> f = x -> x * 2;    // DERLENMEZ: 'x' zaten tanimli
```

### ⭐ İnce kural: `void` SAM'e değer dönen ifade yazmak

```java
Consumer<String> a = x -> x.length();            // DERLENIR — sonuc atilir
Consumer<String> b = x -> { return x.length(); };// DERLENMEZ — acik return
Consumer<String> c = x -> x.isEmpty() ? 1 : 2;   // DERLENMEZ — deyim ifadesi degil
```

**İfade gövdeli** bir lambda, gövdesi bir **deyim ifadesi** (metot çağrısı, atama, `++`) ise
`void` dönen bir arayüze uyar; sonucu sessizce atılır. Ama **blok gövdede açık `return`** yazarsan
veya gövde bir **koşul ifadesiyse** derlenmez.

## 2. ⭐⭐⭐ Hazır fonksiyonel arayüzler

| Arayüz | Metot | İmza | Hafıza kancası |
|---|---|---|---|
| `Supplier<T>` | `get()` | `() -> T` | **Verir**, almaz |
| `Consumer<T>` | `accept(T)` | `T -> void` | **Alır**, vermez |
| `BiConsumer<T,U>` | `accept(T,U)` | `(T,U) -> void` | |
| `Predicate<T>` | `test(T)` | `T -> boolean` | **Sorar** |
| `BiPredicate<T,U>` | `test(T,U)` | `(T,U) -> boolean` | |
| `Function<T,R>` | `apply(T)` | `T -> R` | **Dönüştürür** |
| `BiFunction<T,U,R>` | `apply(T,U)` | `(T,U) -> R` | |
| `UnaryOperator<T>` | `apply(T)` | `T -> T` | Function'ın **aynı tipli** hâli |
| `BinaryOperator<T>` | `apply(T,T)` | `(T,T) -> T` | `reduce` için |
| `Runnable` | `run()` | `() -> void` | |
| `Callable<V>` | `call()` | `() -> V` **throws** | 8.2 |
| `Comparator<T>` | `compare(T,T)` | `(T,T) -> int` | 5.3 |

### Primitif sürümler (kutulamayı önler)

| Arayüz | İmza |
|---|---|
| `IntSupplier` | `() -> int` |
| `IntConsumer` | `int -> void` |
| `IntPredicate` | `int -> boolean` |
| `IntFunction<R>` | `int -> R` |
| `ToIntFunction<T>` | `T -> int` |
| `IntUnaryOperator` | `int -> int` |
| `IntBinaryOperator` | `(int,int) -> int` |
| `ObjIntConsumer<T>` | `(T,int) -> void` |

Aynı desen `Long` ve `Double` için de vardır. **`boolean` için yalnızca `BooleanSupplier`** vardır.

> ⚠️ **Tuzak:** `IntFunction<R>` **int alır**, `ToIntFunction<T>` **int döner**. Yön karıştırılır.

## 3. ⭐⭐ Default metotlar ve zincirleme

| Arayüz | Metot | Anlamı |
|---|---|---|
| `Function` | `andThen(g)` | **önce this**, sonra `g` |
| `Function` | `compose(g)` | **önce `g`**, sonra this |
| `Function` | `identity()` (static) | `t -> t` |
| `Predicate` | `and`, `or`, `negate` | Mantıksal birleştirme |
| `Predicate` | `not(p)` (static) | `negate` yerine |
| `Predicate` | `isEqual(o)` (static) | `t -> Objects.equals(o, t)` |
| `Consumer` | `andThen(c)` | İkisini sırayla çalıştırır |
| `Comparator` | `thenComparing`, `reversed` | 5.3 |

```java
Function<Integer,Integer> ekle = x -> x + 1;
Function<Integer,Integer> carp = x -> x * 2;

ekle.andThen(carp).apply(5);     // (5+1)*2 = 12
ekle.compose(carp).apply(5);     // (5*2)+1 = 11
```

> ⚠️⚠️ **`andThen` soldan sağa, `compose` sağdan sola.**
> Hafıza kancası: "*and then* = **sonra**; *compose* = **önce**."

`Predicate` zincirinde `and` ve `or` **kısa devre** yapar (1.1).

## 4. ⭐⭐ Method reference — dört biçim

| Biçim | Yazım | Karşılığı |
|---|---|---|
| **Static** | `Integer::parseInt` | `s -> Integer.parseInt(s)` |
| **Belirli bir nesnenin** | `System.out::println` | `x -> System.out.println(x)` |
| **Rastgele nesnenin** | `String::length` | `s -> s.length()` |
| **Constructor** | `ArrayList::new` | `() -> new ArrayList<>()` |

```java
Function<String,Integer> a = Integer::parseInt;      // static
Consumer<String> b = System.out::println;            // belirli nesne
Function<String,Integer> c = String::length;         // rastgele nesne
Supplier<List<String>> d = ArrayList::new;           // constructor
BiFunction<String,String,Boolean> e = String::startsWith;   // rastgele nesne + arguman
```

> ⚠️ **Tuzak:** `String::length` ile `s::length` farklıdır.
> İlki `Function<String,Integer>` (nesneyi parametre olarak alır),
> ikincisi `Supplier<Integer>` (nesne zaten belli).

> ⚠️ **Belirsizlik:** `String::compareTo` hem "rastgele nesne" hem "static" gibi okunabiliyorsa
> derleyici **ambiguous** hatası verir.

## 5. Lambda ve exception

Lambda gövdesi, hedef arayüzün metodunda **bildirilmemiş** bir checked exception atamaz:

```java
Function<String,Integer> f = s -> {
    throw new java.io.IOException();     // DERLENMEZ: apply checked exception bildirmez
};
Callable<Integer> c = () -> { throw new java.io.IOException(); };   // OK: call() throws Exception
```

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| `() -> 42` | `Supplier<Integer>` | `Consumer` parametre alır |
| `x -> System.out.println(x)` | `Consumer<T>` | Değer dönmez |
| `x -> x > 5` | `Predicate<T>` | `Function<T,Boolean>` de olur ama sınav `Predicate` bekler |
| `(x,y) -> x + y` aynı tipte | `BinaryOperator<T>` | `BiFunction` daha genel |
| `IntFunction<R>` | **int alır**, R döner | `ToIntFunction` tersi |
| `f.andThen(g)` | **Önce f** | `compose` önce g |
| `(int x, y) -> ...` | Derlenmez | Tip yazılırsa hepsinde olmalı |
| `(var x, int y) -> ...` | Derlenmez | Karışık yazım yasak |
| Lambda parametresi çevredeki değişkenle aynı ad | Derlenmez | Gölgeleme yasak |
| Lambda'da `this` | **Çevreleyen sınıf** | Anonim sınıfta kendisi |
| Lambda'da checked exception | SAM bildirmiyorsa **derlenmez** | `Callable` bildirir |
| `String::length` | `Function<String,Integer>` | `s::length` → `Supplier<Integer>` |
| `ArrayList::new` | Constructor referansı | `Supplier` veya `Function` olabilir |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Arayüz eşleme**
> `x -> x.isEmpty()` hangi arayüze atanabilir?
> → **`Predicate<String>`**.

**Kalıp 2 — compose sırası**
> ```java
> Function<Integer,Integer> f = x -> x + 1, g = x -> x * 2;
> System.out.println(f.compose(g).apply(3));
> ```
> → **`7`** (önce `g`: 6, sonra `f`: 7).

**Kalıp 3 — Karışık parametre**
> ```java
> BiFunction<Integer,Integer,Integer> f = (var x, int y) -> x + y;
> ```
> → **Compilation fails.**

**Kalıp 4 — Gölgeleme**
> ```java
> int x = 5;
> Predicate<Integer> p = x -> x > 3;
> ```
> → **Compilation fails.**

**Kalıp 5 — Method reference tipi**
> ```java
> Supplier<Integer> s = "abc"::length;
> Function<String,Integer> f = String::length;
> ```
> → **Her ikisi de geçerli**, farklı tipler.

## 60 saniyelik özet

- Lambda'nın tipi **hedef tipten** gelir; kendi başına tipi yoktur.
- Tip yazarsan **tüm** parametrelerde yaz; `var` kullanırsan **hepsinde** kullan.
- Yakalanan yerel değişken **effectively final**; lambda parametresi çevredeki adı **gölgeleyemez**.
- Lambda'da `this` = **çevreleyen sınıf**.
- `Supplier` verir · `Consumer` alır · `Predicate` sorar · `Function` dönüştürür.
- `UnaryOperator<T>` = `Function<T,T>`, `BinaryOperator<T>` = `BiFunction<T,T,T>`.
- `IntFunction<R>` **int alır**; `ToIntFunction<T>` **int döner**.
- **`andThen` önce this, `compose` önce argüman.**
- `Predicate`: `and`, `or`, `negate`, static `not`, `isEqual`.
- Method reference dört biçim: static · belirli nesne · rastgele nesne · constructor.
- `String::length` → `Function`, `"abc"::length` → `Supplier`.
- Lambda, SAM'in bildirmediği **checked exception** atamaz.
