## Neden bu konu

Stream soruları neredeyse her zaman aynı üç şeyi test eder: **tembellik** (terminal işlem yoksa
hiçbir şey çalışmaz), **tek kullanımlık olma** (aynı stream iki kez kullanılamaz) ve
**sonsuz stream'lerde `limit`'in yeri**.

`Optional` ise ayrı bir tuzak yuvasıdır: `orElse` ile `orElseGet` arasındaki fark ve
`Optional.of(null)`'ın NPE atması.

**Büyük fikir:** Stream bir **veri yapısı değil**, bir **işlem tarifidir**. Terminal işlem
çağrılana kadar hiçbir ara işlem yürümez; çağrıldığında ise elemanlar **teker teker** tüm boru
hattından geçer (yatay değil, **dikey** akış).

## 1. ⭐ Stream oluşturma

| Kaynak | Yazım |
|---|---|
| Koleksiyon | `liste.stream()` · `liste.parallelStream()` |
| Dizi | `Arrays.stream(dizi)` |
| Değerlerden | `Stream.of("a", "b")` |
| Boş | `Stream.empty()` |
| **Sonsuz** — üreteç | `Stream.generate(() -> 1)` |
| **Sonsuz** — yineleme | `Stream.iterate(1, x -> x + 1)` |
| **Sonlu** yineleme (Java 9+) | `Stream.iterate(1, x -> x < 10, x -> x + 1)` |
| Sayı aralığı | `IntStream.range(1, 5)` (5 **hariç**) · `rangeClosed(1, 5)` (5 **dahil**) |
| Metin | `"abc".chars()` (`IntStream`) · `metin.lines()` (`Stream<String>`) |
| Dosya | `Files.lines(path)` (9.2) |

> ⚠️ `Stream.generate` ve iki argümanlı `Stream.iterate` **sonsuzdur** — `limit` olmadan terminal
> işlem çağırırsan program **asla bitmez**.

## 2. ⭐⭐⭐ Tembellik ve tek kullanımlık olma

```java
Stream.of("a", "b")
      .filter(s -> { System.out.println("filtre " + s); return true; });
// HICBIR CIKTI YOK — terminal islem yok
```

```java
Stream<String> s = Stream.of("a", "b");
s.count();
s.count();          // RUNTIME: IllegalStateException: stream has already been operated upon or closed
```

### Dikey akış

```java
Stream.of("a", "b")
      .peek(x -> System.out.print("peek:" + x + " "))
      .map(x -> { System.out.print("map:" + x + " "); return x; })
      .forEach(x -> System.out.print("son:" + x + "  "));
// peek:a map:a son:a  peek:b map:b son:b
```

Her eleman boru hattını **baştan sona** geçer, sonra sıradaki eleman başlar.
Bu, `limit` ve `findFirst` gibi işlemlerin **kısa devre** yapabilmesini sağlar.

> ⚠️ **Tuzak:** Sınav "kaç kez `map` çalıştı?" diye sorar. Cevap boru hattının
> **kısa devre** yapıp yapmadığına bağlıdır.

## 3. ⭐⭐ Ara işlemler (intermediate)

| İşlem | Ne yapar | Not |
|---|---|---|
| `filter(Predicate)` | Eleyicidir | Eleman sayısını **azaltabilir** |
| `map(Function)` | 1 eleman → 1 eleman | Sayı **değişmez** |
| `flatMap(Function)` | 1 eleman → **0..n** eleman | İç içe yapıyı düzleştirir |
| `distinct()` | Tekrarları siler | `equals`/`hashCode` kullanır, **durum tutar** |
| `sorted()` / `sorted(Comparator)` | Sıralar | **Tüm** elemanları görmek zorunda; sonsuz stream'de **asla bitmez** |
| `limit(n)` | İlk `n` eleman | **Kısa devre** |
| `skip(n)` | İlk `n` elemanı atlar | |
| `peek(Consumer)` | Gözlem amaçlı | Yan etki için kullanılmamalı |
| `takeWhile(Predicate)` | Koşul **bozulana kadar** al | Java 9+ |
| `dropWhile(Predicate)` | Koşul **bozulana kadar** at | Java 9+ |
| `mapToInt` / `mapToObj` / `boxed` | Tip dönüşümü | 6.4 |

### `filter` vs `takeWhile`

```java
Stream.of(1, 2, 3, 1, 2).filter(x -> x < 3).toList();      // [1, 2, 1, 2]  — HEPSINI tarar
Stream.of(1, 2, 3, 1, 2).takeWhile(x -> x < 3).toList();   // [1, 2]        — 3'te DURUR
Stream.of(1, 2, 3, 1, 2).dropWhile(x -> x < 3).toList();   // [3, 1, 2]
```

### `map` vs `flatMap`

```java
List<List<String>> ic = List.of(List.of("a","b"), List.of("c"));
ic.stream().map(List::size).toList();          // [2, 1]
ic.stream().flatMap(List::stream).toList();    // [a, b, c]
```

> ⚠️ **Sonsuz stream + `sorted()`** = program asla bitmez. `limit` **`sorted`'dan önce** gelmeli.

## 4. ⭐⭐ `Optional`

```java
Optional<String> a = Optional.of("x");          // null verirsen NPE
Optional<String> b = Optional.ofNullable(null); // guvenli -> bos
Optional<String> c = Optional.empty();
```

| Metot | Davranış |
|---|---|
| `get()` | Boşsa **`NoSuchElementException`** |
| `orElse(v)` | Boşsa `v` — **`v` her durumda hesaplanır** |
| `orElseGet(Supplier)` | Boşsa supplier — **yalnızca gerekirse çalışır** |
| `orElseThrow()` | Boşsa `NoSuchElementException` |
| `orElseThrow(Supplier)` | Boşsa senin exception'ın |
| `isPresent()` / `isEmpty()` | |
| `ifPresent(Consumer)` | Doluysa çalıştırır |
| `ifPresentOrElse(Consumer, Runnable)` | Java 9+ |
| `map(Function)` | Sonuç `null` ise **boş Optional** |
| `filter(Predicate)` | Koşul sağlanmazsa boşaltır |
| `stream()` | 0 veya 1 elemanlı stream (Java 9+) |

### ⭐ `orElse` vs `orElseGet`

```java
static String pahali() { System.out.print("[hesaplandi] "); return "yedek"; }

Optional.of("var").orElse(pahali());        // [hesaplandi] var   <- BOSUNA calisti
Optional.of("var").orElseGet(() -> pahali());  // var             <- hic calismadi
```

> ⚠️⚠️ **Tuzak:** `orElse`'in argümanı **Optional dolu olsa bile** değerlendirilir; yalnızca
> sonucu kullanılmaz. Pahalı bir çağrıysa `orElseGet` kullanılmalıdır.

> ⚠️ `Optional.of(null)` → **`NullPointerException`**. `ofNullable` güvenlidir.
> `Optional`'ı **alan veya metot parametresi** yapmak önerilmez; **dönüş tipi** içindir.

## 60 saniyelik özet

- Stream **tembeldir**: terminal işlem yoksa hiçbir ara işlem çalışmaz.
- Bir stream **bir kez** kullanılır; ikincisinde **`IllegalStateException`**.
- Akış **dikeydir**: her eleman boru hattını baştan sona geçer.
- `Stream.generate` ve iki argümanlı `Stream.iterate` **sonsuzdur** → `limit` şart.
- Sonsuz stream'de `sorted()` **asla bitmez**; `limit` öne alınmalı.
- `IntStream.range` üst sınırı **hariç**, `rangeClosed` **dahil** tutar.
- `filter` tümünü tarar, **`takeWhile` ilk ihlalde durur**, `dropWhile` ilk ihlalden itibaren alır.
- `map` sayıyı korur, **`flatMap` düzleştirir**.
- `Optional.of(null)` → **NPE**; `ofNullable` güvenlidir.
- **`orElse` argümanını her zaman hesaplar**, `orElseGet` yalnızca gerekirse.
- Boş `Optional.get()` → **`NoSuchElementException`**.
- `optional.map(...)` `null` üretirse sonuç **boş Optional**'dır.
