ne yapar, `partitioningBy` boş sonuçta hangi anahtarları döner.

## 1. ⭐ Terminal işlemler

| İşlem | Döner | Not |
|---|---|---|
| `forEach(Consumer)` | `void` | Paralelde **sıra garantisi yok** |
| `forEachOrdered` | `void` | Paralelde bile sıralı |
| `count()` | `long` | |
| `min(Comparator)` / `max(Comparator)` | `Optional<T>` | Boşsa boş Optional |
| `findFirst()` / `findAny()` | `Optional<T>` | `findAny` paralelde daha hızlı |
| `anyMatch` / `allMatch` / `noneMatch` | `boolean` | **Kısa devre** |
| `toArray()` / `toArray(String[]::new)` | Dizi | |
| **`toList()`** | `List<T>` | Java 16+ · **değiştirilemez** · `null` **kabul eder** |
| `collect(Collector)` | Değişken | En genel |
| `reduce(...)` | Üç biçim | Aşağıda |

### ⭐⭐ Boş stream'de eşleştirme

```java
Stream.of().allMatch(x -> false);     // true   !!!  (vacuous truth)
Stream.of().noneMatch(x -> true);     // true
Stream.of().anyMatch(x -> true);      // false
```

> ⚠️ **Tuzak:** Boş stream'de `allMatch` **her zaman `true`** döner — "aksini gösteren eleman yok"
> mantığı. Sınav bunu çok sorar.

### `toList()` vs `collect(Collectors.toList())`

| | `stream.toList()` | `collect(Collectors.toList())` |
|---|---|---|
| Sürüm | Java 16+ | Java 8+ |
| Değiştirilebilir mi | ❌ **Değiştirilemez** | ✅ Genelde `ArrayList` |
| `null` eleman | ✅ | ✅ |
| `collect(toUnmodifiableList())` | — | ❌ Değiştirilemez, `null` **kabul etmez** |

## 2. ⭐⭐ `reduce` — üç biçim

```java
// 1) identity + accumulator  -> T doner (Optional DEGIL)
int t1 = Stream.of(1,2,3).reduce(0, Integer::sum);            // 6

// 2) yalnizca accumulator    -> Optional<T> doner
Optional<Integer> t2 = Stream.of(1,2,3).reduce(Integer::sum); // Optional[6]
Optional<Integer> t3 = Stream.<Integer>of().reduce(Integer::sum);  // Optional.empty

// 3) identity + accumulator + combiner  -> paralel icin
int t4 = Stream.of("a","bb").reduce(0, (n,s) -> n + s.length(), Integer::sum);  // 3
```

| Biçim | Dönüş | Ne zaman |
|---|---|---|
| `reduce(id, acc)` | `T` | Sonuç tipi eleman tipiyle aynı |
| `reduce(acc)` | `Optional<T>` | Identity yoksa (boş olabilir) |
| `reduce(id, acc, combiner)` | `U` | Sonuç tipi **farklı** ve/veya **paralel** |

> ⚠️ Identity, birleştirme için **etkisiz eleman** olmalı (toplamada `0`, çarpmada `1`, metinde `""`).
> Yanlış identity paralel çalıştırmada **yanlış sonuç** verir.

## 3. ⭐⭐⭐ `Collectors`

### Temel toplayıcılar

| Collector | Üretir |
|---|---|
| `toList()` / `toSet()` | `List` / `Set` (değiştirilebilir) |
| `toUnmodifiableList()` / `toUnmodifiableSet()` | Değiştirilemez, **null yasak** |
| `toMap(keyFn, valFn)` | `Map` — **çakışan anahtar → `IllegalStateException`** |
| `toMap(keyFn, valFn, mergeFn)` | Çakışmayı çözer |
| `toMap(keyFn, valFn, mergeFn, mapSupplier)` | `TreeMap` vb. |
| `joining()` / `joining(", ")` / `joining(", ", "[", "]")` | `String` |
| `counting()` | `Long` |
| `summingInt` / `averagingInt` / `summarizingInt` | `Integer`/`Double`/`IntSummaryStatistics` |
| `minBy` / `maxBy` | `Optional<T>` |
| `mapping(fn, downstream)` | Dönüştürüp aşağıya verir |
| `filtering(pred, downstream)` | Java 9+ |
| `teeing(c1, c2, merger)` | Java 12+ — iki toplayıcıyı birleştirir |

> ⚠️⚠️ **`toMap` tuzağı:** Anahtar tekrarlarsa **`IllegalStateException: Duplicate key`** atılır.
> Üç argümanlı biçim (`(a, b) -> a + b`) bunu çözer. Ayrıca **değer `null` olamaz** → NPE.

### ⭐ `groupingBy` ve `partitioningBy`

```java
List<String> l = List.of("elma", "armut", "ayva", "kiraz");

// varsayilan: HashMap<K, List<T>>
Map<Integer, List<String>> a = l.stream().collect(Collectors.groupingBy(String::length));

// downstream ile
Map<Integer, Long> b = l.stream()
    .collect(Collectors.groupingBy(String::length, Collectors.counting()));

// map tipi de secilebilir
Map<Integer, Set<String>> c = l.stream()
    .collect(Collectors.groupingBy(String::length, TreeMap::new, Collectors.toSet()));

// partitioningBy -> HER ZAMAN true ve false anahtarlari
Map<Boolean, List<String>> d = l.stream()
    .collect(Collectors.partitioningBy(s -> s.length() > 4));
```

| | `groupingBy` | `partitioningBy` |
|---|---|---|
| Anahtar | `Function` sonucu (istediğin kadar) | **Yalnızca `true` / `false`** |
| Boş sonuçta | O anahtar **hiç yoktur** | **Her iki anahtar da vardır** (boş liste ile) |
| Varsayılan map | `HashMap` | Özel iki elemanlı map |
| Downstream | ✅ | ✅ |

> ⚠️ **Tuzak:** `partitioningBy` sonucu hiçbir eleman `true` olmasa bile `map.get(true)`
> **boş liste** döner — `null` değil. `groupingBy`'da olmayan anahtar `null` döner.

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| Boş stream + `allMatch` | **`true`** | `anyMatch` `false` döner |
| `reduce(acc)` dönüşü | **`Optional<T>`** | Identity'li biçim `T` döner |
| `stream.toList()` üzerine `add` | `UnsupportedOperationException` | `collect(toList())` genelde değiştirilebilir |
| `collect(toUnmodifiableList())` + null | **NPE** | `stream.toList()` null'a izin verir |
| `toMap` çakışan anahtar | **`IllegalStateException`** | Merge fonksiyonu ekle |
| `toMap` null değer | **NPE** | — |
| `groupingBy` varsayılan map | `HashMap` | Sıra garantisi yok |
| `partitioningBy` boş taraf | **Boş liste** | `groupingBy`'da anahtar hiç olmaz |
| `min`/`max` dönüşü | `Optional<T>` | Doğrudan `T` değil |
| `count()` dönüşü | **`long`** | `int` değil |
| `forEach` paralelde | Sıra **garantisiz** | `forEachOrdered` sıralı |
| `joining` argümanları | `(ayirici, onek, sonek)` | Sırayı karıştırma |
| `counting()` dönüşü | **`Long`** | `Integer` değil |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Boş stream**
> ```java
> System.out.println(Stream.of().allMatch(x -> false));
> ```
> → **`true`**.

**Kalıp 2 — reduce dönüş tipi**
> ```java
> Optional<Integer> o = Stream.of(1,2).reduce(0, Integer::sum);
> ```
> → **Compilation fails.** Identity'li biçim `Integer` döner.

**Kalıp 3 — toMap çakışması**
> ```java
> Stream.of("aa","ab").collect(Collectors.toMap(s -> s.charAt(0), s -> s));
> ```
> → **`IllegalStateException` at runtime.**

**Kalıp 4 — toList değiştirilemez**
> ```java
> Stream.of("a").toList().add("b");
> ```
> → **`UnsupportedOperationException` at runtime.**

**Kalıp 5 — partitioningBy**
> Hiçbir eleman koşulu sağlamıyor; `map.get(true)` ne döner?
> → **Boş liste**, `null` değil.

## 60 saniyelik özet

- Boş stream'de **`allMatch` ve `noneMatch` `true`**, `anyMatch` `false`.
- `reduce(id, acc)` → `T`; `reduce(acc)` → **`Optional<T>`**; üç argümanlı biçim paralel/farklı tip için.
- `stream.toList()` (Java 16+) **değiştirilemez** ama **null kabul eder**;
  `toUnmodifiableList()` null **kabul etmez**.
- `min`/`max`/`findFirst`/`findAny` → **`Optional`**; `count()` → **`long`**.
- `Collectors.toMap` çakışan anahtarda **`IllegalStateException`**, null değerde **NPE**.
- `groupingBy` varsayılan olarak **`HashMap<K, List<T>>`** üretir; downstream ve map tipi verilebilir.
- `partitioningBy` **her zaman** `true` ve `false` anahtarlarını döner (boş listelerle).
- `counting()` **`Long`** döner.
- `joining(ayirici, onek, sonek)` sırasını karıştırma.
- `forEach` paralelde sırasızdır, `forEachOrdered` sıralıdır.
- `mapping`, `filtering`, `teeing` downstream toplayıcılarıdır.
