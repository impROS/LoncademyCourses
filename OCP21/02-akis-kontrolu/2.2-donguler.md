# 2.2 — Döngüler, break ve continue

> **Alan:** Controlling Program Flow — tahmini ~1-2 soru
> **Süre:** ~25 dakika okuma + 15 dakika pratik
> **Test:** [`2.2-test.html`](2.2-test.html) · 13 soru

## Neden bu konu

Döngüler basit görünür, sınav ise buradan **derleme hatası** ve **döngü sayımı** sorusu çıkarır:
`while (false) { }` neden derlenmez, `for (int i = 0, long j = 0; ...)` neden geçersiz,
etiketli `continue` hangi döngüye atlar.

**Büyük fikir:** Java'da **ulaşılamayan kod bir derleme hatasıdır.** Derleyici sabit bir koşulun
asla doğru olmayacağını görebiliyorsa gövdeyi ulaşılamaz sayar ve reddeder.

---

## 1. Dört döngü biçimi

| Biçim | Gövde en az kaç kez çalışır | Not |
|---|---|---|
| `for (init; cond; update)` | 0 | Üç bölüm de **boş bırakılabilir**: `for (;;)` sonsuz döngü |
| `for (T x : koleksiyon)` | 0 | Yalnızca dizi veya `Iterable` üzerinde |
| `while (cond)` | 0 | |
| `do { } while (cond);` | **1** | Sonundaki **noktalı virgül zorunlu** |

```java
for (;;) { break; }                 // gecerli sonsuz dongu
int i = 0;
do { i++; } while (i < 0);          // gövde 1 kez calisti, i = 1
```

### `for` başlığı kuralları

```java
for (int i = 0, j = 10; i < j; i++, j--) { }     // OK: ayni tipte coklu degisken
for (int i = 0, long j = 0; ; ) { }              // DERLENMEZ: tek tip bildirilebilir
int a; for (a = 0; a < 3; a++) { }               // OK: bildirim disarida
for (int i = 0; i < 3; i++);                     // OK ama govde BOS (noktali virgul!)
System.out.println(i);                           // DERLENMEZ: i dongu kapsaminda
```

> ⚠️ **Tuzak:** `for (...);` — başlığın hemen ardından noktalı virgül gövdeyi boşaltır.
> Altındaki blok döngüden bağımsız **bir kez** çalışır.

## 2. ⭐ Ulaşılamayan kod = derleme hatası

| Kod | Sonuç |
|---|---|
| `while (false) { x(); }` | **Derlenmez** — gövde ulaşılamaz |
| `for (; false; ) { x(); }` | **Derlenmez** |
| `if (false) { x(); }` | ✅ **Derlenir** (bilinçli istisna: koşullu derleme için) |
| `while (true) { } x();` | **Derlenmez** — `x()` ulaşılamaz |
| `while (true) { break; } x();` | ✅ Derlenir |
| `do { x(); } while (false);` | ✅ Derlenir — gövde bir kez çalışır |

> **Hafıza kancası:** "`if (false)` affedilir, `while (false)` affedilmez."

## 3. ⭐ Enhanced for (for-each)

```java
int[] dizi = {1, 2, 3};
for (int x : dizi) { x = 99; }        // diziyi DEGISTIRMEZ, x bir kopyadir
System.out.println(dizi[0]);          // 1

List<String> liste = new ArrayList<>(List.of("a", "b"));
for (String s : liste) {
    liste.remove(s);                  // RUNTIME: ConcurrentModificationException
}
```

| Kural | Detay |
|---|---|
| Neyin üzerinde çalışır | Dizi veya `Iterable` (yani `Collection`). **`Map` doğrudan olmaz** — `entrySet()` gerekir |
| Değişken | Her turda **yeni bir kopya**; ona atamak kaynağı değiştirmez |
| İndeks | **Yok**. İndekse ihtiyacın varsa klasik `for` kullan |
| Koleksiyonu değiştirmek | `add`/`remove` → **`ConcurrentModificationException`** |
| Güvenli silme | `Iterator.remove()` veya `Collection.removeIf(...)` |

```java
liste.removeIf(s -> s.equals("a"));       // guvenli
Iterator<String> it = liste.iterator();
while (it.hasNext()) { if (...) it.remove(); }   // guvenli
```

> ⚠️ **Tuzak:** `ConcurrentModificationException` **thread ile ilgili değildir** — tek thread'de de olur.
> Adı yanıltıcıdır.

## 4. ⭐ break, continue ve etiketler

| | `break` | `continue` |
|---|---|---|
| Ne yapar | Döngüden **çıkar** | Bu turu **atlar**, sonraki tura geçer |
| `for`'da | Döngü biter | `update` bölümü **çalışır**, sonra koşul |
| `while`'da | Döngü biter | Doğrudan koşula gider (**update yoksa sonsuz döngü riski**) |
| `switch` içinde | switch'ten çıkar | switch'e uygulanmaz, **en yakın döngüye** gider |

### Etiketli break/continue

```java
disari:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) continue disari;    // dis dongunun sonraki turuna
        if (i == 2) break disari;       // her iki dongudan cikar
        System.out.print(i + "" + j + " ");
    }
}
// cikti: 00 10
```

| Kural | Detay |
|---|---|
| Etiket nereye konur | **Döngünün hemen üstüne**, `ad:` biçiminde |
| `break etiket` | O etiketli döngüden **tamamen çıkar** |
| `continue etiket` | O etiketli döngünün **sonraki turuna** geçer |
| Etiket olmayan bloğa | `break etiket` bir bloğa da uygulanabilir; `continue` **yalnızca döngüye** |
| Var olmayan etiket | **Derleme hatası** |

> ⚠️ **Tuzak:** `continue` bir `switch` içinde yazıldığında switch'i değil, **çevreleyen döngüyü** hedefler.
> `break` ise en yakın olan `switch`'i hedefler — ikisi farklı davranır.

## 5. Döngü sayımı — sınavın favori sorusu

```java
int sayac = 0;
for (int i = 0; i < 5; i++) {
    if (i % 2 == 0) continue;
    sayac++;
}
System.out.println(sayac);        // 2   (i = 1 ve 3)
```

```java
int i = 0;
while (i < 5) {
    if (i == 2) continue;         // i ARTMAZ -> SONSUZ DONGU
    i++;
}
```

> ⚠️ **Tuzak:** `while` içinde `continue` kullanırken artırma satırını atlarsan sonsuz döngü olur.
> `for` içinde bu risk yoktur çünkü `update` bölümü `continue`'dan sonra da çalışır.

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| `while (false) { }` | **Derlenmez** | `if (false)` derlenir — istisna sadece `if`'te |
| `while (true) { }` sonrası kod | Derlenmez | Kod ulaşılamaz |
| `do { } while (false);` | Gövde **1 kez** çalışır | `while (false)`'un aksine derlenir |
| `for (int i=0, long j=0;;)` | Derlenmez | Başlıkta tek tip bildirilir |
| `for (...); { }` | Gövde boş, blok bir kez | Girinti yanıltır |
| for-each'te değişkene atama | Kaynağı değiştirmez | Değişken kopyadır |
| for-each içinde `remove` | `ConcurrentModificationException` | `removeIf` veya `Iterator.remove()` güvenli |
| `continue` `while` içinde | Artırma atlanır → sonsuz döngü | `for`'da `update` yine çalışır |
| `break` `switch` içinde | switch'ten çıkar | `continue` çevreleyen **döngüye** gider |
| Etiket sonrası boşluk | Etiket **döngünün üstünde** olmalı | Rastgele yere konamaz |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Ulaşılamaz kod**
> ```java
> while (false) { System.out.println("x"); }
> ```
> → **Compilation fails.**

**Kalıp 2 — Boş gövde**
> ```java
> for (int i = 0; i < 3; i++);
> System.out.println("a");
> ```
> → **`a`** bir kez yazılır.

**Kalıp 3 — for-each kopyası**
> ```java
> int[] d = {1, 2};
> for (int x : d) x *= 10;
> System.out.println(d[0]);
> ```
> → **`1`**.

**Kalıp 4 — Etiketli continue**
> ```java
> outer:
> for (int i = 0; i < 2; i++)
>     for (int j = 0; j < 2; j++) {
>         if (j == 0) continue outer;
>         System.out.print(i + "" + j);
>     }
> ```
> → **Hiçbir şey yazılmaz.** Her iç turda `j == 0`'da dışa atlanır.

**Kalıp 5 — do-while**
> ```java
> int i = 10;
> do { System.out.print(i); } while (i < 5);
> ```
> → **`10`**. Koşul yanlış olsa da gövde bir kez çalışır.

## 60 saniyelik özet

- `do-while` gövdeyi **en az bir kez** çalıştırır ve sonunda **noktalı virgül** ister.
- `while (false)` **derlenmez**, `if (false)` derlenir. `while (true)` sonrası kod ulaşılamaz → derlenmez.
- `for` başlığında **tek tip** bildirilir; üç bölüm de boş olabilir (`for (;;)`).
- `for (...);` gövdeyi boşaltır — girintiye değil noktalı virgüle bak.
- for-each değişkeni **kopyadır**; ona atamak kaynağı değiştirmez.
- for-each içinde koleksiyon değiştirmek → **`ConcurrentModificationException`** (thread ile ilgisi yok).
  Güvenli yol: `removeIf` veya `Iterator.remove()`.
- `for`'da `continue` **update'i çalıştırır**; `while`'da artırmayı atlarsan sonsuz döngü.
- `break etiket` o döngüden çıkar, `continue etiket` sonraki turuna geçer; etiket döngünün üstündedir.
- `switch` içinde `break` switch'ten, `continue` **çevreleyen döngüden** sorumludur.
- Döngü değişkeni `for` başlığında bildirildiyse döngü dışında **görünmez**.
