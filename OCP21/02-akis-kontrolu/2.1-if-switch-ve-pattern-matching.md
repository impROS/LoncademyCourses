## Neden bu konu

`switch`, Java 21'in **en çok değişen** özelliğidir ve sınavın "yeni" tarafının merkezindedir.
Artık dört ayrı şey var: eski `switch` **deyimi**, `switch` **ifadesi**, `instanceof` **pattern matching**
ve `switch` **pattern matching**. Bunların kuralları farklıdır ve sınav ikisini kasten karıştırır.

Kaybedilen puanlar: **exhaustiveness** (tüm durumlar kapsandı mı), **fall-through**,
**dominance** (bir `case` diğerini gölgeliyor mu), **null davranışı**.

**Büyük fikir:** `switch` **deyimi** bir şey *yapar* ve düşme (fall-through) yapar; `switch` **ifadesi**
bir değer *üretir*, düşmez ve **tüm durumları kapsamak zorundadır**.

## 1. if/else — kısa ama tuzaklı

```java
int x = 5;
if (x = 3) { }        // DERLENMEZ: int, boolean'a donusturulemez
if (x == 3) { }       // OK
```

Java'da `if` **yalnızca `boolean`** kabul eder; C'deki "sıfır dışı doğrudur" kuralı yoktur.
Tek istisna: `Boolean` wrapper otomatik unbox edilir — ve `null` ise **NPE** atar.

```java
Boolean b = null;
if (b) { }            // RUNTIME: NullPointerException
```

> ⚠️ **Tuzak:** Süslü parantez olmadan yazılan `if` **yalnızca bir sonraki deyimi** kapsar.
> ```java
> if (x > 3)
>     System.out.println("a");
>     System.out.println("b");   // her zaman calisir
> ```

## 2. ⭐ switch **deyimi** (statement)

### İzin verilen selector tipleri

| Tip | Geçerli mi |
|---|---|
| `byte`, `short`, `char`, `int` | ✅ |
| `Byte`, `Short`, `Character`, `Integer` | ✅ (unbox edilir, `null` → NPE) |
| `String` | ✅ |
| `enum` | ✅ |
| `long`, `float`, `double`, `boolean` | ❌ **Derleme hatası** |
| Herhangi bir referans tipi | ✅ **yalnızca pattern label kullanırsan** (Java 21) |

> **Hafıza kancası:** "long, float, double, boolean — dördü de yasak." (`long` yasak olması en çok şaşırtandır.)

### case etiketleri **sabit** olmalı

```java
final int A = 1;
int b = 2;
switch (x) {
    case A: break;        // OK   (final, derleme zamani sabiti)
    case b: break;        // DERLENMEZ: constant expression required
    case 1 + 2: break;    // OK   (sabit ifade)
}
```

### ⭐ Fall-through

`break` yoksa **sonraki case'e düşer** ve etiketleri kontrol etmez:

```java
int x = 2;
switch (x) {
    case 1: System.out.println("bir");
    case 2: System.out.println("iki");
    case 3: System.out.println("uc");
    default: System.out.println("varsayilan");
}
// cikti: iki / uc / varsayilan
```

`default` **her yerde olabilir** — sonda olmak zorunda değildir; ama düşme kuralı yine geçerlidir.

## 3. ⭐⭐ switch **ifadesi** (expression) — ok sözdizimi ve `yield`

```java
String ad = switch (gun) {
    case 1, 7 -> "hafta sonu";
    case 2, 3, 4, 5, 6 -> "hafta ici";
    default -> "gecersiz";
};
```

| Kural | Deyim (`:`) | İfade (`->`) |
|---|---|---|
| Değer üretir mi | Hayır | **Evet** |
| Fall-through | **Var** | **Yok** |
| `break` gerekir mi | Evet | Hayır |
| Tüm durumlar kapsanmalı mı | Hayır | **Evet (exhaustive)** |
| Blok içinde değer döndürme | — | **`yield`** |
| Sonunda noktalı virgül | Yok | **Var** (atama deyimidir) |

```java
int puan = switch (harf) {
    case "A" -> 4;
    case "B" -> 3;
    default -> {
        System.out.println("bilinmeyen");
        yield 0;                 // blok kullanirsan yield ZORUNLU
    }
};
```

> ⚠️ **Tuzak 1:** `->` ile blok kullanıp `yield` yazmazsan **derlenmez**.
> ⚠️ **Tuzak 2:** `switch` ifadesinde `return` **kullanılamaz** — `yield` kullanılır.
> ⚠️ **Tuzak 3:** İfade biçiminde `default` yoksa ve selector `enum` değilse **derlenmez**.
> Tüm `enum` sabitlerini yazdıysan `default` gerekmez.

### İki sözdizimi karıştırılamaz

Aynı `switch` içinde hem `case X ->` hem `case Y:` kullanamazsın → **derleme hatası**.

## 4. ⭐⭐ `instanceof` pattern matching

```java
// eski
if (o instanceof String) {
    String s = (String) o;
    System.out.println(s.length());
}
// Java 16+
if (o instanceof String s) {
    System.out.println(s.length());
}
```

### Flow scoping — değişken nerede görünür

`s` yalnızca derleyicinin "kesin olarak `String`" diyebildiği yerde geçerlidir:

```java
if (o instanceof String s && s.length() > 2) { }     // OK  (&& kisa devre)
if (o instanceof String s || s.length() > 2) { }     // DERLENMEZ: s garanti degil

if (!(o instanceof String s)) {
    return;                 // s burada YOK
}
System.out.println(s.length());   // OK — negatif dal donduyse s kesinlesti
```

> ⚠️ **Tuzak:** Pattern değişkeni ile aynı isimli bir yerel değişken varsa **derlenmez**.

## 5. ⭐⭐⭐ switch pattern matching (Java 21)

Java 21'de `switch` artık **tip desenleri** kabul eder. Sınavın en yeni ve en verimli konusu.

```java
static String anlat(Object o) {
    return switch (o) {
        case null            -> "null geldi";
        case Integer i when i > 100 -> "buyuk sayi: " + i;
        case Integer i       -> "sayi: " + i;
        case String s        -> "metin uzunlugu: " + s.length();
        default              -> "bilinmeyen";
    };
}
```

### Kurallar

| Kural | Detay |
|---|---|
| **null** | Klasik `switch` null'da **NPE** atar. Pattern `switch`'te `case null` yazarsan yakalarsın; yazmazsan **yine NPE**. `case null, default ->` birlikte yazılabilir. |
| **Guard (`when`)** | Desenden sonra koşul: `case Integer i when i > 100 ->`. `when` bir **anahtar kelime değil**, bağlamsal isimdir. |
| **Dominance** | Genel desen, özel deseni **gölgeleyemez**. Önce `case Object o` yazarsan sonrasındaki her şey **derleme hatası** verir. Guard'lı desen, guard'sız aynı desenden **önce** gelmelidir. |
| **Exhaustiveness** | Pattern `switch` ifadesi tüm tipleri kapsamalı: ya `default` ya da `sealed` hiyerarşinin **tüm** alt tipleri (3.5). |
| **MatchException** | Sealed hiyerarşi derlemeden sonra değişirse çalışma zamanında `MatchException` atılabilir. |

```java
// DERLENMEZ — dominance ihlali
switch (o) {
    case Object x -> "her sey";
    case String s -> "metin";     // ulasilamaz
}

// DERLENMEZ — guard'siz desen once gelirse guard'li ulasilamaz
switch (o) {
    case Integer i -> "sayi";
    case Integer i when i > 5 -> "buyuk";   // ulasilamaz
}
```

### Record pattern (yapı ayrıştırma)

```java
record Nokta(int x, int y) {}
record Cizgi(Nokta bas, Nokta son) {}

static String tarif(Object o) {
    return switch (o) {
        case Cizgi(Nokta(var x1, var y1), Nokta p2) -> "bas=(" + x1 + "," + y1 + ") son=" + p2;
        case Nokta(int x, int y) when x == y        -> "kosegen nokta";
        case Nokta n                                -> "nokta " + n;
        default                                     -> "?";
    };
}
```

İç içe ayrıştırma yapılabilir, `var` kullanılabilir. **Record pattern `null` ile eşleşmez** —
iç bileşen null olabilir ama desenin kendisi null nesneye uymaz.

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| `switch (someLong)` | **Derlenmez** | `long` desteklenmez; `int` desteklenir |
| `switch` deyiminde `break` yok | **Fall-through** olur | İfadede (`->`) düşme yoktur |
| `switch` ifadesinde `default` yok | Derlenmez (enum tümü yazılmadıysa) | Deyimde `default` isteğe bağlı |
| `->` blokta `yield` yok | Derlenmez | `return` de kullanılamaz |
| `case b:` (b final değil) | Derlenmez | Etiket sabit ifade olmalı |
| Klasik `switch` + `null` selector | **NPE** | Pattern switch'te `case null` yakalayabilir |
| Pattern switch + null, `case null` yok | **NPE** | `default` null'ı yakalamaz |
| `case Object o` en üstte | Derlenmez (dominance) | Genel desen sonda olmalı |
| Guard'sız desen guard'lıdan önce | Derlenmez | Özelden genele sıralanır |
| `if (o instanceof String s \|\| ...)` | Derlenmez | `\|\|` ile `s` garanti değil |
| Aynı switch'te `:` ve `->` | Derlenmez | İki sözdizimi karıştırılamaz |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Fall-through sayımı**
> ```java
> int x = 2;
> switch (x) {
>     case 1: System.out.print("a");
>     case 2: System.out.print("b");
>     case 3: System.out.print("c");
> }
> ```
> → **`bc`**. `break` yok, düşer.

**Kalıp 2 — Selector tipi**
> ```java
> long x = 2;
> switch (x) { case 2: break; }
> ```
> → **Compilation fails.** `long` desteklenmez.

**Kalıp 3 — Exhaustiveness**
> ```java
> String s = switch (o) {
>     case Integer i -> "sayi";
>     case String t  -> "metin";
> };
> ```
> → **Compilation fails.** `Object` için `default` yok.

**Kalıp 4 — Dominance**
> ```java
> switch (o) {
>     case CharSequence c -> "cs";
>     case String s       -> "str";
> }
> ```
> → **Compilation fails.** `String`, `CharSequence`'in altındadır; ikinci `case` ulaşılamaz.

**Kalıp 5 — null**
> ```java
> String s = null;
> switch (s) { case "a" -> {} default -> {} }
> ```
> → **NullPointerException at runtime.** `case null` yazılmadıkça `default` null'ı yakalamaz.

## 60 saniyelik özet

- `if` yalnızca `boolean` alır; `Boolean` null ise NPE.
- `switch` selector: `byte/short/char/int` + wrapper'ları, `String`, `enum`, (Java 21) pattern ile her tip.
  **`long`, `float`, `double`, `boolean` yasak.**
- `case` etiketleri **derleme zamanı sabiti** olmalı.
- Deyim biçiminde `break` yoksa **düşer**; `default` her konumda olabilir.
- İfade biçimi (`->`) düşmez, **değer üretir**, **exhaustive olmak zorundadır**, blokta **`yield`** ister.
- İfade içinde `return` **kullanılamaz**; iki sözdizimi **karıştırılamaz**.
- `instanceof` pattern değişkeni **flow scoping** ile sınırlıdır: `&&` çalışır, `||` çalışmaz.
- Pattern switch: `case null` yoksa null → **NPE**.
- `when` guard'ı, guard'sız aynı desenden **önce** yazılmalı; genel desen **sonda** olmalı (dominance).
- `sealed` hiyerarşide tüm alt tipler yazıldıysa `default` gerekmez; sonradan tip eklenirse `MatchException`.
- Record pattern iç içe ayrıştırır ve **null ile eşleşmez**.
