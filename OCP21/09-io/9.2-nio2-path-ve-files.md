> **Süre:** ~35 dakika okuma + 20 dakika pratik

## Neden bu konu

Bu, sınavın **en hesaplanabilir** konularından biri: `resolve`, `relativize` ve `normalize`
sonuçları **kurallıdır** ve kâğıt üstünde türetilebilir. Ezberlersen puan garantidir.

En sık tuzak: **`Path` metotları dosya sistemine dokunmaz.** `Path.of("/yok/olan")` sorunsuz
çalışır; dosyanın var olup olmadığını yalnızca `Files` metotları bilir.

**Büyük fikir:** `Path` **metin işlemleri** yapar (sözdizimsel), `Files` **disk işlemleri**
yapar (fiziksel). Soruda hangi sınıf geçiyorsa cevap o eksende aranır.

## 1. ⭐ `Path` oluşturma ve bileşenleri

```java
Path p = Path.of("/ev/kullanici/belge/rapor.txt");     // tercih edilen (Java 11+)
Path q = Paths.get("/ev/kullanici");                    // eski, hala calisir
Path r = Path.of("ev", "kullanici", "rapor.txt");       // parcali
```

| Metot | `/ev/kullanici/belge/rapor.txt` için |
|---|---|
| `getFileName()` | `rapor.txt` |
| `getParent()` | `/ev/kullanici/belge` |
| `getRoot()` | `/` — **göreli yolda `null`** |
| `getNameCount()` | **`4`** — kök **sayılmaz** |
| `getName(0)` | `ev` — kökten sonraki **ilk** öğe |
| `subpath(1, 3)` | `kullanici/belge` — başlangıç **dahil**, bitiş **hariç** |
| `isAbsolute()` | `true` |
| `toAbsolutePath()` | Göreli yolu çalışma dizinine göre tamamlar |
| `toRealPath()` | **Diske bakar** — dosya yoksa `IOException` |

> ⚠️ **Tuzak:** `getNameCount()` **kökü saymaz**. `/a/b` için `2`, `a/b` için de `2`.
> `getName(0)` da her zaman **kökten sonraki** ilk öğedir.

## 2. ⭐⭐⭐ `resolve`, `relativize`, `normalize`

### `resolve` — birleştirme

| İfade | Sonuç | Kural |
|---|---|---|
| `Path.of("/a/b").resolve("c/d")` | `/a/b/c/d` | Göreli yol **eklenir** |
| `Path.of("/a/b").resolve("/x/y")` | **`/x/y`** | Argüman **mutlaksa** onu döner! |
| `Path.of("/a/b/c.txt").resolveSibling("d.txt")` | `/a/b/d.txt` | Kardeş dosya |

> ⚠️⚠️ **Tuzak:** `resolve`'a **mutlak** bir yol verirsen soldaki tamamen **yok sayılır**.

### `relativize` — "buradan oraya nasıl giderim"

| İfade | Sonuç |
|---|---|
| `Path.of("/a/b").relativize(Path.of("/a/b/c/d"))` | `c/d` |
| `Path.of("/a/b/c/d").relativize(Path.of("/a/b"))` | **`../..`** |
| `Path.of("/a").relativize(Path.of("b"))` | ❌ **`IllegalArgumentException`** |

> ⚠️⚠️ **Tuzak:** İki yol da **aynı türden** olmalı — ikisi mutlak veya ikisi göreli.
> Karıştırırsan `IllegalArgumentException`.

### `normalize` — `.` ve `..` temizler

```java
Path.of("/a/b/../c/./d").normalize();          // /a/c/d
Path.of("/a/b/../c").equals(Path.of("/a/c"));  // FALSE — equals normalize ETMEZ
```

> ⚠️ `Path.equals` **sözdizimsel** karşılaştırır. Anlamsal eşitlik için önce `normalize()`,
> gerekirse `toRealPath()` kullanılır.

## 3. ⭐⭐ `Files` — disk işlemleri

| Metot | Not |
|---|---|
| `Files.exists(p)` / `notExists(p)` | İkisi de `false` olabilir (erişim yoksa) |
| `Files.createFile(p)` | Varsa **`FileAlreadyExistsException`** |
| `Files.createDirectory(p)` | Üst dizin yoksa **`NoSuchFileException`** |
| `Files.createDirectories(p)` | Ara dizinleri **de** oluşturur, varsa **hata vermez** |
| `Files.delete(p)` | Yoksa **`NoSuchFileException`**; dizin doluysa `DirectoryNotEmptyException` |
| `Files.deleteIfExists(p)` | Yoksa **`false`** döner, exception atmaz |
| `Files.copy(a, b)` / `move(a, b)` | Hedef varsa **`FileAlreadyExistsException`** — `StandardCopyOption.REPLACE_EXISTING` ile çözülür |
| `Files.size(p)` | Byte cinsinden `long` |
| `Files.isDirectory` / `isRegularFile` / `isReadable` | |
| `Files.readString(p)` / `writeString(p, s)` | Java 11+, kısa yol |
| `Files.readAllLines(p)` | `List<String>` — **tüm dosyayı belleğe alır** |
| **`Files.lines(p)`** | `Stream<String>` — **tembel**, try-with-resources'ta **kapatılmalı** |
| `Files.newBufferedReader/Writer(p)` | Akış üretir |
| `Files.list(p)` | **Bir seviye**, `Stream<Path>` — kapatılmalı |
| `Files.walk(p)` | **Alt ağacın tamamı**, `Stream<Path>` — kapatılmalı |
| `Files.find(p, derinlik, matcher)` | Filtreli dolaşım |

```java
try (Stream<String> satirlar = Files.lines(p)) {      // AKIS KAPATILMALI
    satirlar.filter(s -> !s.isBlank()).forEach(System.out::println);
}
```

> ⚠️⚠️ **Tuzak:** `Files.lines`, `Files.list` ve `Files.walk` **açık bir dosya tanıtıcısı** tutar
> ve try-with-resources ile kapatılmalıdır. `Files.readAllLines` kapatma gerektirmez ama
> **tüm dosyayı belleğe** alır.

| `readAllLines` | `lines` |
|---|---|
| `List<String>` | `Stream<String>` |
| Hepsi belleğe | **Tembel**, satır satır |
| Kapatma gerekmez | **Kapatma şart** |

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| `Path.of("/yok/olan")` | Sorunsuz çalışır | `Path` diske **bakmaz** |
| `getNameCount()` kökü sayar mı | **Hayır** | `/a/b` → 2 |
| `resolve` mutlak argümanla | **Argümanı döner** | Soldaki yok sayılır |
| `relativize` mutlak + göreli | **`IllegalArgumentException`** | Aynı tür olmalı |
| `equals` normalize eder mi | **Hayır** | Sözdizimsel karşılaştırma |
| `subpath(1,3)` | Başlangıç dahil, bitiş **hariç** | |
| `Files.delete` yok olan dosya | **`NoSuchFileException`** | `deleteIfExists` `false` döner |
| `Files.createDirectory` ara dizin yoksa | **Hata** | `createDirectories` oluşturur |
| `Files.copy` hedef varsa | **`FileAlreadyExistsException`** | `REPLACE_EXISTING` gerekir |
| `Files.lines` | **Kapatılmalı** | `readAllLines` gerekmez |
| `Files.list` vs `walk` | Bir seviye vs **tüm ağaç** | |
| `toRealPath()` | **Diske bakar**, `IOException` atar | `toAbsolutePath` bakmaz |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — resolve mutlak**
> ```java
> System.out.println(Path.of("/a/b").resolve("/x/y"));
> ```
> → **`/x/y`**.

**Kalıp 2 — relativize geri**
> ```java
> System.out.println(Path.of("/a/b/c/d").relativize(Path.of("/a/b")));
> ```
> → **`../..`**.

**Kalıp 3 — getNameCount**
> ```java
> System.out.println(Path.of("/a/b/c").getNameCount());
> ```
> → **`3`** (kök sayılmaz).

**Kalıp 4 — equals**
> ```java
> System.out.println(Path.of("/a/b/../c").equals(Path.of("/a/c")));
> ```
> → **`false`**.

**Kalıp 5 — delete**
> ```java
> Files.delete(Path.of("yok.txt"));
> ```
> → **`NoSuchFileException`**. `deleteIfExists` `false` dönerdi.

## 60 saniyelik özet

- **`Path` = metin işlemi, `Files` = disk işlemi.** `Path` var olmayan yolla sorunsuz çalışır.
- `getNameCount()` **kökü saymaz**; `getName(0)` kökten sonraki ilk öğedir.
- `subpath(a, b)`: `a` **dahil**, `b` **hariç**.
- `resolve` argüman **mutlaksa** soldakini **yok sayar**.
- `relativize` iki yolun da **aynı türden** olmasını ister; değilse `IllegalArgumentException`.
- Geriye gitmek gerekiyorsa `relativize` **`..`** üretir.
- `normalize` `.` ve `..` temizler; **`equals` normalize etmez**.
- `toAbsolutePath()` diske **bakmaz**, `toRealPath()` **bakar** ve `IOException` atar.
- `Files.delete` yoksa **`NoSuchFileException`**, `deleteIfExists` **`false`**.
- `createDirectory` ara dizin yoksa **hata**, `createDirectories` **oluşturur**.
- `Files.copy`/`move` hedef varsa **`FileAlreadyExistsException`** → `REPLACE_EXISTING`.
- **`Files.lines`, `list`, `walk` kapatılmalıdır** (try-with-resources); `readAllLines` gerekmez.
