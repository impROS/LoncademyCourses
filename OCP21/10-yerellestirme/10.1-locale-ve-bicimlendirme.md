# 10.1 — Locale, ResourceBundle ve Biçimlendirme

> **Alan:** Implementing Localization — tahmini ~1-2 soru
> **Süre:** ~30 dakika okuma + 20 dakika pratik
> **Test:** [`10.1-test.html`](10.1-test.html) · 14 soru

---

## Neden bu konu

Sınavın en küçük alanı ama **iki soruluk garanti puan** içerir ve kuralları nettir.
En çok sorulan şey: **`ResourceBundle` bir anahtarı bulamazsa nereye bakar?**

İkinci sıklık: `Locale` yazım kuralı — **dil küçük harf, ülke BÜYÜK harf**.

**Büyük fikir:** Yerelleştirme iki parçadır: **metinler** (`ResourceBundle`) ve
**sayı/tarih biçimleri** (`NumberFormat`, `DateTimeFormatter`). İkisi de bir `Locale` ile sürülür.

---

## 1. ⭐ `Locale`

```java
Locale.getDefault();                     // JVM varsayilani
Locale.US;                               // hazir sabitler
Locale.of("tr", "TR");                   // Java 19+ (constructor deprecated)
Locale.forLanguageTag("tr-TR");          // BCP 47 etiketi (TIRE ile)
new Locale.Builder().setLanguage("tr").setRegion("TR").build();
Locale.setDefault(Locale.US);            // varsayilani degistir
```

| Kural | Detay |
|---|---|
| Dil kodu | **Küçük harf** (`tr`, `en`, `fr`) — zorunlu |
| Ülke kodu | **BÜYÜK harf** (`TR`, `US`) — isteğe bağlı |
| `toString()` | **`tr_TR`** (alt çizgi) |
| `toLanguageTag()` | **`tr-TR`** (tire) |
| Yalnızca dil | `Locale.of("tr")` geçerli |
| Yalnızca ülke | ❌ Anlamsız — dil zorunlu |
| `getLanguage()` / `getCountry()` | `tr` / `TR` |

> ⚠️ **Tuzak:** `new Locale("TR", "tr")` **derlenir ve çalışır** ama yanlış anlamlıdır —
> Java kodları düzeltmez. Sınav bunu "hangisi doğru yazım" diye sorar.

## 2. ⭐⭐⭐ `ResourceBundle` ve arama sırası

Dosya adlandırma: **`TemelAd_dil_ULKE.properties`**

```
Mesaj.properties            <- varsayilan (default bundle)
Mesaj_tr.properties         <- dil
Mesaj_tr_TR.properties      <- dil + ulke
```

```java
var b = ResourceBundle.getBundle("Mesaj", Locale.of("tr", "TR"));
b.getString("selam");
```

### ⭐⭐ Arama sırası (bir anahtar için)

1. `Mesaj_tr_TR` (istenen locale, en özel)
2. `Mesaj_tr` (dil)
3. `Mesaj_<varsayilan locale dil_ULKE>` — **JVM varsayılanı**
4. `Mesaj_<varsayilan locale dil>`
5. **`Mesaj`** (default bundle)
6. Hâlâ yoksa → **`MissingResourceException`**

> ⚠️⚠️ **Tuzak:** Bundle **seçimi** ile **anahtar araması** farklıdır. Bundle seçildikten sonra
> bir anahtar o dosyada yoksa **üst (daha genel) bundle'lara doğru** aranmaya devam edilir.
> Bu yüzden `Mesaj_tr_TR.properties` yalnızca **farklı olan** anahtarları içerebilir.

| Durum | Sonuç |
|---|---|
| Anahtar özel bundle'da var | O değer |
| Anahtar yalnızca default bundle'da var | **Default bundle'daki değer** |
| Anahtar hiçbir yerde yok | **`MissingResourceException`** (unchecked) |
| Hiçbir bundle dosyası yok | `MissingResourceException` |

### `.properties` biçimi

```properties
selam=Merhaba
veda: Gule gule
uzun.metin=birinci satir \
  devami
```

`=`, `:` veya boşluk ayırıcı olabilir; `#` ve `!` yorum satırı başlatır.

> `ResourceBundle` ayrıca `ListResourceBundle` alt sınıfıyla da yazılabilir (Java kodu olarak).

## 3. ⭐⭐ `NumberFormat`

```java
NumberFormat.getInstance(locale);           // genel sayi
NumberFormat.getNumberInstance(locale);     // ayni sey
NumberFormat.getCurrencyInstance(locale);   // para
NumberFormat.getPercentInstance(locale);    // yuzde
NumberFormat.getIntegerInstance(locale);    // tam sayi
NumberFormat.getCompactNumberInstance(locale, NumberFormat.Style.SHORT);  // Java 12+
```

| İfade (`1234567.891`) | `Locale.US` | `tr_TR` |
|---|---|---|
| `getInstance` | `1,234,567.891` | `1.234.567,891` |
| `getCurrencyInstance` (1234.5) | `$1,234.50` | `₺1.234,50` |
| `getPercentInstance` (0.25) | `25%` | `%25` |
| `getCompactNumberInstance` (1234567) | `1M` | `1 Mn` |

> ⚠️⚠️ **Tuzak:** Türkçe locale'de **binlik ayırıcı nokta, ondalık ayırıcı virgüldür** —
> İngilizcenin tam tersi. Sınav bunu doğrudan sorar.

### `parse` — metinden sayıya

```java
NumberFormat.getInstance(tr).parse("1.234,5");     // 1234.5
```

| Kural | Detay |
|---|---|
| Dönüş tipi | **`Number`** — `Integer`, `Long` veya `Double` olabilir |
| Checked exception | **`ParseException`** atar → yakalanmalı |
| Geçersiz baştan sonra | Ayrıştırabildiği kadarını alır, **exception atmayabilir** |

## 4. Tarih/saat yerelleştirme

```java
DateTimeFormatter.ofLocalizedDate(FormatStyle.SHORT).withLocale(Locale.of("tr","TR"));
DateTimeFormatter.ofLocalizedDateTime(FormatStyle.MEDIUM);
DateTimeFormatter.ofPattern("dd MMMM yyyy", Locale.of("tr","TR"));   // 23 Ağustos 2026
```

| `FormatStyle` | Örnek (US, tarih) |
|---|---|
| `SHORT` | `8/23/26` |
| `MEDIUM` | `Aug 23, 2026` |
| `LONG` | `August 23, 2026` |
| `FULL` | `Sunday, August 23, 2026` |

> ⚠️ Bir `LocalDate`'i **saat** içeren bir localized formatter ile biçimlendirmek
> **`UnsupportedTemporalTypeException`** atar (1.3).

`String.format(Locale.US, "%,.2f", 1234.5)` biçiminde `String.format` da locale alabilir.

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| Locale yazımı | **dil küçük, ülke BÜYÜK** | `tr_TR` |
| `toString()` vs `toLanguageTag()` | `tr_TR` vs **`tr-TR`** | Alt çizgi / tire |
| Yalnızca ülke ile Locale | ❌ Dil zorunlu | |
| Bundle adı | `Ad_dil_ULKE.properties` | Sıra sabittir |
| Anahtar özel bundle'da yok | **Daha genele bakılır** | Hemen exception atmaz |
| Anahtar hiçbir yerde yok | **`MissingResourceException`** | **Unchecked** |
| Türkçe `1234.5` | **`1.234,5`** | Nokta binlik, virgül ondalık |
| `NumberFormat.parse` dönüşü | **`Number`** | `int`/`double` değil |
| `parse` exception'ı | **Checked `ParseException`** | Yakalanmalı |
| `getCompactNumberInstance` | Java 12+ | `1M` gibi |
| `LocalDate` + saatli formatter | **`UnsupportedTemporalTypeException`** | 1.3 |
| `Locale.setDefault` | JVM genelini değiştirir | Testlerde dikkat |

## 🖥 Pratik — Kendi bundle'ını kur

> **Amaç:** Arama sırasını ve locale'e göre biçimlendirmeyi görmek · **Süre:** 20 dk
> **💸 Maliyet:** Yok

### Adımlar

1. Kurs kökünden örnek klasörüne git:
   ```bash
   cd 10-yerellestirme/ornekler
   ```
2. Üç properties dosyasını incele — her biri **farklı** anahtarlar içeriyor:
   ```bash
   cat Mesaj.properties Mesaj_tr.properties Mesaj_tr_TR.properties
   ```
3. Derle ve çalıştır (properties dosyaları classpath'te olmalı):
   ```bash
   javac -d . Yerellestirme.java && java -cp . Yerellestirme
   ```
4. `01 arama sirasi` çıktısında üç anahtarın **üç farklı dosyadan** geldiğini doğrula:
   `selam` → `_tr`, `veda` → `_tr_TR`, `sadece.varsayilan` → default bundle.
5. `Mesaj_tr.properties` dosyasından `selam` satırını sil, tekrar çalıştır.
   Değer artık **default bundle**'dan gelecek.
6. `03 sayi bicimleri` bloğunda Türkçe ve İngilizce ayırıcıların **ters** olduğunu gör.

- [ ] **Kontrol:** Üç anahtar üç farklı dosyadan çözüldü.
- [ ] **Kontrol:** Var olmayan anahtar `MissingResourceException` attı.
- [ ] **Kaydet:** `1234567.891` Türkçe locale'de nasıl göründü? ______

### 💸 Temizlik

```bash
rm -f *.class
```

- [ ] **Kontrol:** `ls *.class` → dosya kalmadı

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Arama sırası**
> `Mesaj_tr_TR.properties` yalnızca `veda` içeriyor, `Mesaj.properties` `selam` ve `veda` içeriyor.
> `Locale("tr","TR")` ile `selam` istenirse?
> → **`Mesaj.properties`'teki değer.**

**Kalıp 2 — Eksik anahtar**
> Anahtar hiçbir bundle'da yok.
> → **`MissingResourceException`** (unchecked).

**Kalıp 3 — Locale yazımı**
> Hangisi doğru? `Locale.of("TR","tr")` mi `Locale.of("tr","TR")` mi?
> → **İkincisi.** Dil küçük, ülke büyük.

**Kalıp 4 — Sayı biçimi**
> Türkçe locale'de `1234.5` nasıl yazılır?
> → **`1.234,5`**.

**Kalıp 5 — parse dönüşü**
> ```java
> Number n = NumberFormat.getInstance().parse("42");
> ```
> → Dönüş **`Number`**, `int` değil. Ayrıca **`ParseException`** yakalanmalı.

## 60 saniyelik özet

- `Locale`: **dil küçük harf**, **ülke BÜYÜK harf**. Dil zorunlu, ülke isteğe bağlı.
- `toString()` → `tr_TR` (alt çizgi), `toLanguageTag()` → `tr-TR` (tire).
- `Locale.of(...)` Java 19+; constructor **deprecated**.
- Bundle adı: **`TemelAd_dil_ULKE.properties`**.
- Anahtar bulunamazsa **daha genel** bundle'lara doğru aranır; en sonda default bundle.
- Hiçbir yerde yoksa **`MissingResourceException`** — **unchecked**.
- Özel bundle yalnızca **farklı olan** anahtarları içerebilir.
- `NumberFormat`: `getInstance`, `getCurrencyInstance`, `getPercentInstance`,
  `getIntegerInstance`, `getCompactNumberInstance` (Java 12+).
- Türkçe'de **nokta binlik, virgül ondalık** — İngilizcenin tersi.
- `parse` **`Number`** döner ve **checked `ParseException`** atar.
- `DateTimeFormatter.ofLocalizedDate(FormatStyle...)` + `withLocale(...)`.
- `LocalDate`'i saatli formatter'a vermek **`UnsupportedTemporalTypeException`** atar.
