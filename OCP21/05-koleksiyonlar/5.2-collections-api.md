## Neden bu konu

Bu, koleksiyon alanının en geniş konusu. Sınav dört yerden vurur:
**hangi uygulamanın hangi garantisi var** (sıra, null, sıralı mı), **`List.remove` overload tuzağı**,
**`Queue` metotlarının exception mı `null` mü döndüğü** ve **wildcard'lara ne ekleyebildiğin**.

**Büyük fikir:** Her koleksiyon arayüzü bir **sözleşme**, her uygulama o sözleşmenin bir
**takasıdır**: hız mı, sıra mı, sıralılık mı. Soruyu çözmek için "bu tip **neyi garanti eder**"
sorusunu sor.

## 1. ⭐ Hiyerarşi ve uygulamalar

```
Collection
├── List      — sirali, tekrar VAR, indeksli
├── Set       — tekrar YOK
└── Queue / Deque — uc noktalari

Map — Collection DEGIL, ayri hiyerarsi
```

| Tip | Sıra garantisi | `null` | Not |
|---|---|---|---|
| `ArrayList` | Ekleme sırası | ✅ | Rastgele erişim hızlı, ortadan ekleme yavaş |
| `LinkedList` | Ekleme sırası | ✅ | `List` **ve** `Deque` |
| `HashSet` | **Yok** | ✅ 1 tane | En hızlı |
| `LinkedHashSet` | Ekleme sırası | ✅ 1 tane | |
| `TreeSet` | **Sıralı** | ❌ **NPE** | `Comparable`/`Comparator` şart |
| `HashMap` | **Yok** | key 1, value çok | |
| `LinkedHashMap` | Ekleme sırası | ✅ | |
| `TreeMap` | **Anahtara göre sıralı** | key ❌ **NPE** | |
| `ArrayDeque` | Ekleme sırası | ❌ **NPE** | Stack ve Queue için tercih edilen |
| `PriorityQueue` | **Öncelik** (baş eleman en küçük) | ❌ NPE | `toString` sıralı **görünmez** |

> ⚠️⚠️ **Tuzak:** `TreeSet`, `TreeMap` (anahtar), `ArrayDeque` ve `PriorityQueue`
> **`null` kabul etmez** → `NullPointerException`. `HashSet` ve `HashMap` kabul eder.

## 2. ⭐⭐ Fabrika metotları (immutable)

```java
List<String> l = List.of("a", "b");
Set<String>  s = Set.of("a", "b");
Map<String,Integer> m = Map.of("a", 1, "b", 2);
Map<String,Integer> m2 = Map.ofEntries(Map.entry("a", 1));
List<String> kopya = List.copyOf(digerListe);
```

| Kural | Detay |
|---|---|
| Değiştirilebilir mi | ❌ **`UnsupportedOperationException`** (`add`, `remove`, `set`) |
| `null` eleman | ❌ **`NullPointerException`** |
| `Set.of` tekrarlı eleman | ❌ **`IllegalArgumentException`** |
| `Map.of` tekrarlı anahtar | ❌ **`IllegalArgumentException`** |
| `Map.of` argüman sayısı | En fazla **10 çift**; fazlası için `Map.ofEntries` |
| Sıra garantisi | `List.of` ekleme sırası; `Set.of`/`Map.of` **sıra garantisi vermez** |

## 3. ⭐⭐⭐ `List.remove` overload tuzağı

`List` iki `remove` metodu bildirir: `remove(int index)` ve `remove(Object o)`.

```java
List<Integer> l = new ArrayList<>(List.of(10, 20, 30));
l.remove(1);                        // INDEKS -> 20 silinir  ->  [10, 30]
l.remove(Integer.valueOf(1));       // NESNE  -> 1 aranir, yok  ->  degismez
```

> ⚠️⚠️ **Tuzak:** `List<Integer>` üzerinde `remove(1)` **indeksi siler**, değeri değil.
> Overload çözümlemesinde **tam eşleşme (int) kutulamayı yener** (3.2).
> Değere göre silmek için `remove(Integer.valueOf(1))` veya `remove((Integer) 1)` yazılır.

## 4. Sık kullanılan metotlar

### Collection / List

| Metot | Not |
|---|---|
| `add(e)` / `add(i, e)` | `List`'te iki biçim |
| `remove(Object)` / `remove(int)` | Yukarıdaki tuzak |
| `removeIf(Predicate)` | Güvenli toplu silme (2.2) |
| `contains` / `indexOf` | `equals` kullanır |
| `set(i, e)` | Eskisini **döner** |
| `get(i)` | Sınır dışı → `IndexOutOfBoundsException` |
| `size()` | Dizide `length`, String'de `length()` |
| `isEmpty()` / `clear()` | |
| `toArray(new T[0])` | Tipli dizi |
| `replaceAll(UnaryOperator)` | Tüm elemanları dönüştürür |

### Map

| Metot | Ne yapar |
|---|---|
| `put(k,v)` | **Eski değeri döner** (yoksa `null`) |
| `get(k)` | Yoksa `null` |
| `getOrDefault(k, d)` | Yoksa `d` |
| `putIfAbsent(k,v)` | Yalnızca yoksa (veya değeri null ise) yazar |
| `computeIfAbsent(k, fn)` | Yoksa hesaplar ve **yazar** |
| `computeIfPresent(k, fn)` | Varsa hesaplar; `null` dönerse **siler** |
| `merge(k, v, fn)` | Yoksa `v`, varsa `fn(eski, v)`; sonuç `null` ise **siler** |
| `remove(k)` | Silinen değeri döner |
| `containsKey` / `containsValue` | |
| `entrySet` / `keySet` / `values` | **Görünüm** — değişiklik map'e yansır |
| `forEach((k,v) -> ...)` | |

### Queue / Deque — ⭐ exception mı, `null` mü?

| İşlem | **Exception atar** | **Özel değer döner** |
|---|---|---|
| Ekle | `add(e)` → `IllegalStateException` | `offer(e)` → `false` |
| Çıkar | `remove()` → `NoSuchElementException` | `poll()` → `null` |
| Bak | `element()` → `NoSuchElementException` | `peek()` → `null` |

**Deque'i yığın (stack) gibi kullanmak:** `push` / `pop` / `peek` — hepsi **baştan** çalışır.
**Kuyruk gibi:** `offer` (sona) / `poll` (baştan).

> **Hafıza kancası:** "`o` ile başlayanlar (`offer`, `poll`, `peek`) **nazik**: exception atmaz."

## 5. ⭐⭐ Generics ve wildcard'lar

```java
List<String> l = new ArrayList<>();          // diamond
class Kutu<T> { T deger; }
class Sayilar<T extends Number> { }          // sinirli tip parametresi
```

| Wildcard | Anlam | Okuma | Yazma |
|---|---|---|---|
| `List<?>` | Bilinmeyen tip | ✅ `Object` olarak | ❌ (yalnızca `null`) |
| `List<? extends Number>` | Number **veya alt tipi** | ✅ `Number` olarak | ❌ **(yalnızca `null`)** |
| `List<? super Integer>` | Integer **veya üst tipi** | ⚠️ Yalnızca `Object` | ✅ `Integer` ve alt tipleri |

> **PECS:** **P**roducer **E**xtends, **C**onsumer **S**uper.
> Koleksiyondan **okuyacaksan** `extends`, koleksiyona **yazacaksan** `super`.

```java
List<? extends Number> a = List.of(1, 2);
Number n = a.get(0);                 // OK
// a.add(3);                         // DERLENMEZ

List<? super Integer> b = new ArrayList<Number>();
b.add(3);                            // OK
Object o = b.get(0);                 // yalnizca Object olarak okunur
```

### Tip silme (type erasure)

Generic tip bilgisi **çalışma zamanında yoktur**:

```java
new ArrayList<String>().getClass() == new ArrayList<Integer>().getClass();   // true
// if (l instanceof List<String>) { }        // DERLENMEZ
// T[] dizi = new T[10];                     // DERLENMEZ
```

> ⚠️ `List<Object> l = new ArrayList<String>();` **derlenmez** — generics **kovaryant değildir**
> (dizilerin aksine, 5.1).

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — remove tuzağı**
> ```java
> List<Integer> l = new ArrayList<>(List.of(10, 20, 30));
> l.remove(1);
> System.out.println(l);
> ```
> → **`[10, 30]`**.

**Kalıp 2 — Immutable liste**
> ```java
> List<String> l = List.of("a");
> l.add("b");
> ```
> → **`UnsupportedOperationException` at runtime.**

**Kalıp 3 — Wildcard**
> ```java
> List<? extends Number> l = new ArrayList<Integer>();
> l.add(5);
> ```
> → **Compilation fails.**

**Kalıp 4 — Queue**
> ```java
> Queue<String> q = new ArrayDeque<>();
> System.out.println(q.poll());
> ```
> → **`null`**. `remove()` olsaydı `NoSuchElementException`.

**Kalıp 5 — Set.of tekrar**
> ```java
> Set.of("a", "a");
> ```
> → **`IllegalArgumentException` at runtime.**

## 60 saniyelik özet

- `TreeSet`, `TreeMap` (anahtar), `ArrayDeque`, `PriorityQueue` **null kabul etmez** → NPE.
- Fabrika metotları (`List.of`, `Set.of`, `Map.of`) **immutable**'dır ve **null almaz**.
  `Set.of`/`Map.of` **tekrarda** `IllegalArgumentException` atar. `Map.of` en fazla **10 çift**.
- `List<Integer>.remove(1)` **indeksi** siler — değer için `Integer.valueOf(1)`.
- `map.put` **eski değeri** döner; `getOrDefault`, `putIfAbsent`, `merge`, `computeIfAbsent` bilinmeli.
- Queue: **exception** atanlar `add`/`remove`/`element`; **null/false** dönenler `offer`/`poll`/`peek`.
- `Deque` yığın olarak `push`/`pop`/`peek`, kuyruk olarak `offer`/`poll`.
- `PriorityQueue`'da yalnızca **baş eleman** garantilidir; `toString` sıralı değildir.
- `List<? extends X>`'e **eklenemez** (null hariç); `List<? super X>`'e **eklenir**.
- **PECS**: okuyacaksan `extends`, yazacaksan `super`.
- Generics **kovaryant değildir**; tip bilgisi **çalışma zamanında silinir** (erasure).
- `entrySet`/`keySet`/`values` birer **görünümdür**; değişiklik map'e yansır.
