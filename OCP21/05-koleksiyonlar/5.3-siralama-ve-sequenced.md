# 5.3 — Sıralama (Comparable/Comparator) ve Sequenced Collections

> **Alan:** Working with Arrays and Collections — tahmini ~2 soru
> **Süre:** ~35 dakika okuma + 20 dakika pratik
> **Test:** [`5.3-test.html`](5.3-test.html) · 15 soru

## Neden bu konu

İki ayrı konu, aynı dosyada, çünkü ikisi de "koleksiyonda **sıra**" ile ilgili.

**Comparator**, `thenComparing` ve `reversed` zincirleriyle sorulur — zincirin **sırası**
sonucu değiştirir ve sınav bunu sever.

**Sequenced Collections** ise **Java 21'in yeniliğidir** (JEP 431) ve 1Z0-830'da **kesinlikle** çıkar.
Java 17 kaynaklarında bu konu **hiç yoktur**.

**Büyük fikir:** Java 21 öncesinde "ilk elemanı al" işleminin **her koleksiyon için farklı** bir yolu
vardı (`list.get(0)`, `set.iterator().next()`, `deque.peekFirst()`). Sequenced Collections bunu
**tek bir arayüzde** birleştirir.

## 1. ⭐ `Comparable` — doğal sıralama

```java
class Kisi implements Comparable<Kisi> {
    String ad; int yas;
    @Override public int compareTo(Kisi o) { return Integer.compare(yas, o.yas); }
}
```

| Kural | Detay |
|---|---|
| Metot | **`compareTo(T o)`** — tek parametre |
| Dönüş | Negatif (`this` önce), `0` (eşit), pozitif (`this` sonra) |
| Nerede kullanılır | `TreeSet`, `TreeMap`, `Collections.sort`, `Arrays.sort`, `PriorityQueue` |
| Uygulanmamışsa | `TreeSet`'e ekleyince **`ClassCastException`** (runtime) |
| `equals` ile tutarlılık | **Önerilir**: `compareTo == 0` ⟺ `equals == true`. Değilse `TreeSet` mantıksız davranır |

> ⚠️ **Tuzak:** Fark hesaplarken `a - b` yazma — **taşabilir**. `Integer.compare(a, b)` kullan.

---

## 2. ⭐⭐ `Comparator` — dışarıdan sıralama

```java
Comparator<Kisi> c = Comparator.comparing(k -> k.ad);
list.sort(c);
```

| Fabrika / metot | Ne yapar |
|---|---|
| `Comparator.comparing(fn)` | Anahtar çıkarır (`Comparable` olmalı) |
| `comparingInt` / `comparingLong` / `comparingDouble` | Kutulamayı önler |
| `thenComparing(fn)` | **Eşitlik durumunda** ikinci ölçüt |
| `reversed()` | **O ana kadarki** zincirin tamamını ters çevirir |
| `Comparator.naturalOrder()` / `reverseOrder()` | Hazır |
| `nullsFirst(c)` / `nullsLast(c)` | `null` elemanları konumlandırır |

### ⭐⭐ Zincir sırası tuzağı

```java
// once yasa gore, ESITSE ada gore; sonra HEPSI ters
Comparator<Kisi> a = Comparator.comparingInt(Kisi::yas).thenComparing(Kisi::ad).reversed();

// once yasa gore TERS, ESITSE ada gore duz
Comparator<Kisi> b = Comparator.comparingInt(Kisi::yas).reversed().thenComparing(Kisi::ad);
```

> ⚠️⚠️ **`reversed()` kendinden önceki her şeyi ters çevirir**, sadece son adımı değil.
> Sınav bu iki zinciri yan yana koyup farklı sonuç bekler.

### Sıralama metotları

| Metot | Not |
|---|---|
| `list.sort(c)` | **Yerinde**, `void`. `c` `null` ise doğal sıralama |
| `Collections.sort(list)` | Elemanlar `Comparable` olmalı |
| `Arrays.sort(dizi, c)` | Yalnızca **nesne** dizisi (primitif dizide comparator olmaz) |
| `stream.sorted(c)` | **Yeni** stream üretir, kaynağı değiştirmez (6.2) |

`Comparable` uygulamayan bir tipi comparator'sız sıralamak → **`ClassCastException`**.

## 3. ⭐⭐⭐ Sequenced Collections (Java 21 — JEP 431)

Üç yeni arayüz eklendi:

```
SequencedCollection<E>   extends Collection<E>
SequencedSet<E>          extends SequencedCollection<E>, Set<E>
SequencedMap<K,V>        extends Map<K,V>
```

### `SequencedCollection` metotları

| Metot | Ne yapar |
|---|---|
| `getFirst()` / `getLast()` | Baş/son eleman — **boşsa `NoSuchElementException`** |
| `addFirst(e)` / `addLast(e)` | Uçlara ekler |
| `removeFirst()` / `removeLast()` | Uçtan siler ve **döner** |
| `reversed()` | **Ters sıralı görünüm** (kopya **değil**) |

### `SequencedMap` metotları

| Metot | Ne yapar |
|---|---|
| `firstEntry()` / `lastEntry()` | `Map.Entry` — **boşsa `null`** |
| `putFirst(k,v)` / `putLast(k,v)` | Belirli uca yerleştirir |
| `pollFirstEntry()` / `pollLastEntry()` | Alır ve siler |
| `sequencedKeySet()` / `sequencedValues()` / `sequencedEntrySet()` | Sıralı görünümler |
| `reversed()` | Ters görünüm |

### ⭐ Kim uyguluyor, kim uygulamıyor

| Tip | `SequencedCollection` / `SequencedSet` / `SequencedMap` |
|---|---|
| `List` (`ArrayList`, `LinkedList`) | ✅ `SequencedCollection` |
| `Deque` (`ArrayDeque`, `LinkedList`) | ✅ `SequencedCollection` |
| `LinkedHashSet` | ✅ `SequencedSet` |
| `SortedSet` / `TreeSet` | ✅ `SequencedSet` |
| `LinkedHashMap` | ✅ `SequencedMap` |
| `SortedMap` / `TreeMap` | ✅ `SequencedMap` |
| **`HashSet`** | ❌ **Hayır** — sıra kavramı yok |
| **`HashMap`** | ❌ **Hayır** |

> ⚠️⚠️ **Tuzak:** `TreeSet` ve `TreeMap` `Sequenced`'tır ama **konumlu ekleme yapamaz**:
> `addFirst`, `addLast`, `putFirst`, `putLast` → **`UnsupportedOperationException`**.
> Sıra **karşılaştırıcı tarafından** belirlenir, sen dayatamazsın.

```java
SequencedCollection<Integer> l = new ArrayList<>(List.of(1, 2, 3));
l.addFirst(0);              // [0, 1, 2, 3]
l.getLast();                // 3
l.reversed();               // [3, 2, 1, 0]   — GORUNUM

new TreeSet<>(List.of("b","a")).addFirst("z");   // UnsupportedOperationException
```

> `reversed()` bir **görünümdür**: kaynağı değiştirirsen ters görünüm de değişir.

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| `compareTo` parametre sayısı | **1** | `compare` 2 alır |
| `Comparable` olmayan tipi sıralama | Runtime `ClassCastException` | Derlenir |
| `.thenComparing(x).reversed()` | **Tamamı** ters | Sadece son adım değil |
| `.reversed().thenComparing(x)` | İlk ölçüt ters, ikincisi düz | — |
| `list.sort(c)` dönüşü | **`void`**, yerinde | `stream.sorted` yeni üretir |
| `Arrays.sort(int[], comp)` | Derlenmez | Comparator yalnızca nesne dizisinde |
| `HashSet.getFirst()` | **Derlenmez** | `HashSet` `SequencedCollection` değil |
| `TreeSet.addFirst(x)` | Runtime `UnsupportedOperationException` | Derlenir |
| Boş listede `getFirst()` | **`NoSuchElementException`** | `firstEntry()` **`null`** döner |
| `reversed()` | **Görünüm** | Kopya değil |
| `LinkedHashMap.putFirst` | ✅ Çalışır | `TreeMap`'te exception |
| `a - b` ile karşılaştırma | **Taşma riski** | `Integer.compare` kullan |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Zincir sırası**
> `comparing(A).thenComparing(B).reversed()` ile `comparing(A).reversed().thenComparing(B)`
> için sıralanmış liste sorulur. → **İkisi farklıdır.**

**Kalıp 2 — Sequenced olmayan tip**
> ```java
> Set<String> s = new HashSet<>();
> s.getFirst();
> ```
> → **Compilation fails.**

**Kalıp 3 — TreeSet konumlu ekleme**
> ```java
> new TreeSet<>(List.of("a")).addFirst("z");
> ```
> → **`UnsupportedOperationException` at runtime.**

**Kalıp 4 — Boş koleksiyon**
> ```java
> new ArrayList<String>().getFirst();
> ```
> → **`NoSuchElementException`**. `firstEntry()` olsaydı `null` dönerdi.

**Kalıp 5 — Comparable eksikliği**
> ```java
> List<Object> l = new ArrayList<>(List.of(new Object()));
> Collections.sort(l);
> ```
> → **Compilation fails** (tip kısıtı) veya ham tiple yazılırsa **`ClassCastException`**.

## 60 saniyelik özet

- `Comparable.compareTo` **bir** parametre alır, `Comparator.compare` **iki**.
- Fark hesaplarken `Integer.compare` kullan; `a - b` **taşabilir**.
- `reversed()` **kendinden önceki tüm zinciri** ters çevirir — konumu sonucu değiştirir.
- `list.sort` yerinde ve `void`; `stream.sorted` **yeni** üretir.
- Comparator yalnızca **nesne** dizilerinde/koleksiyonlarında; primitif dizide olmaz.
- **Java 21:** `SequencedCollection`, `SequencedSet`, `SequencedMap` eklendi.
- `getFirst`/`getLast`/`addFirst`/`addLast`/`removeFirst`/`removeLast`/`reversed()`.
- `SequencedMap`: `firstEntry`/`lastEntry`/`putFirst`/`putLast`/`pollFirstEntry`/`pollLastEntry`.
- `List`, `Deque`, `LinkedHashSet`, `TreeSet`, `LinkedHashMap`, `TreeMap` **uygular**;
  **`HashSet` ve `HashMap` uygulamaz**.
- `TreeSet`/`TreeMap`'te konumlu ekleme → **`UnsupportedOperationException`**.
- Boş koleksiyonda `getFirst()` → **`NoSuchElementException`**; `firstEntry()` → **`null`**.
- `reversed()` bir **görünümdür**, kopya değil.
