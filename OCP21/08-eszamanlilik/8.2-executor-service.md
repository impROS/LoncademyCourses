# 8.2 — ExecutorService, Callable ve Future

> **Alan:** Managing Concurrent Code Execution — tahmini ~2 soru
> **Süre:** ~35 dakika okuma + 20 dakika pratik
> **Test:** [`8.2-test.html`](8.2-test.html) · 15 soru

## Neden bu konu

Sınav burada **API davranışı** sorar: `submit` ne döner, `get()` ne zaman bloklar,
görev exception atarsa nereden öğrenirsin, `shutdown` ile `shutdownNow` farkı ne.

En sık kaçırılan nokta: **görevin fırlattığı exception, `get()` çağrılana kadar görünmez** ve
`ExecutionException` içine **sarılmış** olarak gelir.

**Büyük fikir:** `ExecutorService` "thread yönetimini bana bırak" demektir. Sen **görev** verirsin,
o **ne zaman ve hangi thread'de** çalıştıracağına karar verir. Karşılığında görevin sonucunu ve
hatasını **`Future` üzerinden** almak zorundasın.

## 1. ⭐ Executor üretme

| Fabrika metodu | Ne yapar |
|---|---|
| `Executors.newSingleThreadExecutor()` | **Tek** thread, görevler **sırayla** |
| `Executors.newFixedThreadPool(n)` | `n` thread'lik sabit havuz |
| `Executors.newCachedThreadPool()` | Gerektikçe büyür, boşta kalanı 60 sn sonra kapatır |
| `Executors.newScheduledThreadPool(n)` | Zamanlanmış görevler |
| `Executors.newSingleThreadScheduledExecutor()` | Tek thread'li zamanlayıcı |
| **`Executors.newVirtualThreadPerTaskExecutor()`** | **Java 21** — görev başına bir virtual thread |
| `Executors.newWorkStealingPool()` | ForkJoinPool tabanlı |

```java
try (var exec = Executors.newFixedThreadPool(2)) {     // Java 19+: AutoCloseable
    exec.submit(() -> System.out.println("gorev"));
}   // close() -> shutdown() + tum gorevler bitene kadar BEKLER
```

> ⚠️ `ExecutorService` Java 19'dan beri **`AutoCloseable`**'dır; `close()` içeride `shutdown()`
> çağırır ve **tüm görevlerin bitmesini bekler**. Öncesinde `try/finally` ile `shutdown()`
> yazmak zorundaydın.

---

## 2. ⭐⭐ Görev gönderme

| Metot | Alır | Döner |
|---|---|---|
| `execute(Runnable)` | `Runnable` | **`void`** — sonuç izlenemez |
| `submit(Runnable)` | `Runnable` | `Future<?>` — `get()` **`null`** döner |
| `submit(Callable<T>)` | `Callable<T>` | `Future<T>` |
| `invokeAll(Collection<Callable<T>>)` | Liste | **Tümü bitince** `List<Future<T>>` |
| `invokeAny(Collection<Callable<T>>)` | Liste | **İlk başarılı** sonucun **değeri** (Future değil!) |

| | `Runnable` | `Callable<V>` |
|---|---|---|
| Metot | `void run()` | `V call() throws Exception` |
| Değer döner mi | ❌ | ✅ |
| Checked exception | ❌ | ✅ **atabilir** |

```java
Future<Integer> f = exec.submit(() -> 42);          // Callable
Future<?> r = exec.submit(() -> System.out.print("x"));  // Runnable
r.get();                                            // null
```

> ⚠️ **Tuzak:** `() -> 42` bir `Callable`, `() -> System.out.print("x")` bir `Runnable`'dır.
> Derleyici **dönüş değeri olup olmamasına** göre overload seçer.

---

## 3. ⭐⭐⭐ `Future`

| Metot | Davranış |
|---|---|
| `get()` | **Bloklar** — görev bitene kadar bekler |
| `get(long, TimeUnit)` | Süre dolarsa **`TimeoutException`** |
| `isDone()` | Bitti mi (başarı, hata veya iptal fark etmez) |
| `cancel(boolean mayInterrupt)` | İptal dener; başarısını `boolean` döner |
| `isCancelled()` | |

### Exception nasıl gelir

```java
Future<Integer> f = exec.submit(() -> { throw new IllegalStateException("patladi"); });
// buraya kadar HICBIR hata gorunmez
try {
    f.get();
} catch (ExecutionException e) {
    e.getCause();      // IllegalStateException: patladi
} catch (InterruptedException e) { }
```

| `get()` hangi exception'ları atar | Ne zaman |
|---|---|
| **`ExecutionException`** (checked) | Görev exception attı — asıl hata **`getCause()`**'ta |
| `InterruptedException` (checked) | Bekleyen thread kesildi |
| `TimeoutException` (checked) | Yalnızca süreli `get`'te |
| `CancellationException` (unchecked) | Görev iptal edilmişti |

> ⚠️⚠️ **Tuzak:** Görevin hatası **`submit` sırasında değil, `get()` sırasında** ortaya çıkar.
> `get()` hiç çağrılmazsa hata **sessizce kaybolur**. Sınav "ne yazdırır?" diye sorup
> hiçbir çıktı olmadığını bekler.

---

## 4. ⭐ Kapatma

| Metot | Ne yapar |
|---|---|
| `shutdown()` | Yeni görev **kabul etmez**, kuyruktakiler **çalışır**. **Bloklamaz** |
| `shutdownNow()` | Çalışanları **kesmeye çalışır**, bekleyenleri `List<Runnable>` olarak döner |
| `awaitTermination(n, unit)` | Bitişi **bekler**; süre içinde bittiyse `true` |
| `isShutdown()` | `shutdown` çağrıldı mı |
| `isTerminated()` | **Tüm görevler bitti mi** |
| `close()` (Java 19+) | `shutdown()` + bitene kadar bekle |

```java
exec.shutdown();
exec.isShutdown();       // true
exec.isTerminated();     // false  — gorevler henuz bitmemis olabilir
exec.awaitTermination(1, TimeUnit.SECONDS);
exec.isTerminated();     // true
```

> ⚠️ Kapatıldıktan sonra `submit` → **`RejectedExecutionException`** (unchecked).

> ⚠️ `shutdown()` **beklemez**. "Görevler bitti mi" diye soruyorsan `awaitTermination` veya
> `isTerminated` gerekir.

---

## 5. Zamanlanmış görevler

```java
var s = Executors.newScheduledThreadPool(1);
s.schedule(() -> System.out.println("1 sn sonra"), 1, TimeUnit.SECONDS);
s.scheduleAtFixedRate(gorev, 0, 2, TimeUnit.SECONDS);      // BASLANGIC'lar arasi 2 sn
s.scheduleWithFixedDelay(gorev, 0, 2, TimeUnit.SECONDS);   // BITIS-BASLANGIC arasi 2 sn
```

| | `scheduleAtFixedRate` | `scheduleWithFixedDelay` |
|---|---|---|
| Aralık neye göre | **Başlangıçlar** arası | Bir öncekinin **bitişi** ile |
| Görev uzun sürerse | Sıradakiler **birikir/gecikir** | Aralık kayar |

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| `execute` dönüşü | **`void`** | `submit` `Future` döner |
| `submit(Runnable).get()` | **`null`** | Runnable değer üretmez |
| Görevdeki exception | **`get()`'te** `ExecutionException` | `submit`'te görünmez |
| Asıl hata nerede | **`getCause()`** | `getMessage()` sarmalayana ait |
| `get()` hiç çağrılmazsa | Hata **kaybolur** | — |
| `invokeAll` | **Tümü bitince** döner | `invokeAny` ilk başarılıyı döner |
| `invokeAny` dönüşü | **Değerin kendisi** | `Future` değil |
| `shutdown()` | **Bloklamaz** | `awaitTermination` bloklar |
| `isShutdown` vs `isTerminated` | Çağrıldı mı vs **bitti mi** | Farklı sorular |
| Kapalıya `submit` | **`RejectedExecutionException`** | Unchecked |
| `Callable` vs `Runnable` | Değer + checked exception | `Thread` yalnızca `Runnable` alır (8.1) |
| `scheduleAtFixedRate` | **Başlangıçlar** arası sabit | `WithFixedDelay` bitişe göre |
| `close()` | `shutdown` + **bekler** | Java 19+ |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Sessiz hata**
> ```java
> exec.submit(() -> { throw new RuntimeException("x"); });
> ```
> ve `get()` çağrılmıyor. → **Hiçbir çıktı yok.**

**Kalıp 2 — Sarmalama**
> ```java
> try { f.get(); } catch (ExecutionException e) { System.out.println(e.getCause()); }
> ```
> → Asıl exception **`getCause()`**'ta.

**Kalıp 3 — Runnable dönüşü**
> ```java
> Future<?> f = exec.submit(() -> System.out.print("x"));
> System.out.println(f.get());
> ```
> → **`xnull`**.

**Kalıp 4 — Kapatma**
> ```java
> exec.shutdown();
> exec.submit(() -> 1);
> ```
> → **`RejectedExecutionException`**.

**Kalıp 5 — isTerminated**
> `shutdown()` hemen sonrası `isTerminated()` ne döner?
> → Genelde **`false`**; görevler bitmemiş olabilir.

## 60 saniyelik özet

- `ExecutorService` Java 19'dan beri **`AutoCloseable`**; `close()` **bekler**.
- `execute` **`void`**, `submit` **`Future`** döner. `submit(Runnable).get()` → **`null`**.
- `Callable` değer döner ve **checked exception atabilir**; `Runnable` ikisini de yapamaz.
- Görevin exception'ı **`get()`'te** `ExecutionException` olarak gelir; asıl hata **`getCause()`**.
- `get()` çağrılmazsa hata **sessizce kaybolur**.
- `get()` **bloklar**; süreli sürüm **`TimeoutException`** atar.
- `invokeAll` **tümü bitince** `List<Future>`, `invokeAny` **ilk başarılı değeri** döner.
- `shutdown()` **beklemez**; `awaitTermination` bekler.
- `isShutdown` "çağrıldı mı", `isTerminated` "**bitti mi**" sorusudur.
- Kapalı executor'a `submit` → **`RejectedExecutionException`**.
- `scheduleAtFixedRate` **başlangıçlar** arası, `scheduleWithFixedDelay` **bitiş-başlangıç** arası sabit.
- `Executors.newVirtualThreadPerTaskExecutor()` Java 21'in görev başına virtual thread çözümüdür.
