## Neden bu konu

Record'lar Java 16'dan beri standart ve sınav bunları **çok** sever, çünkü kısa kodda yoğun kural var:
neyi otomatik üretir, neyi yasaklar, compact constructor'da neye atayabilirsin.

Ayrıca record'lar **pattern matching**'in (2.1) ve **sealed** hiyerarşilerin (3.5) yapı taşıdır —
üçü aynı soruda birlikte gelir.

**Büyük fikir:** Record bir **veri taşıyıcısıdır**: bileşenlerini (component) sen bildirirsin,
geri kalan her şeyi derleyici üretir. Kısıtların tamamı "bu nesne **immutable** ve **şeffaf** kalmalı"
ilkesinden çıkar.

## 1. ⭐ Derleyici ne üretir

```java
public record Nokta(int x, int y) { }
```

Bu tek satır şunları üretir:

| Üretilen | Detay |
|---|---|
| `private final int x;` / `private final int y;` | Alanlar **her zaman `private final`** |
| `public Nokta(int x, int y)` | **Canonical constructor** |
| `public int x()` / `public int y()` | **Accessor** — `getX()` **değil**, bileşen adının aynısı |
| `equals` / `hashCode` | Tüm bileşenlere göre değer eşitliği |
| `toString` | `Nokta[x=1, y=2]` |

```java
var n = new Nokta(1, 2);
n.x();                                  // 1     — n.getX() DEGIL, n.x DE DEGIL
System.out.println(n);                  // Nokta[x=1, y=2]
new Nokta(1,2).equals(new Nokta(1,2));  // true
```

> ⚠️ **Tuzak:** Accessor `x()`'tir. Şıklarda `getX()` veya doğrudan alan erişimi `n.x` görürsen
> **derleme hatasıdır** (alan `private`).

## 2. ⭐⭐ Yasaklar ve serbestlikler

| Yapabilir misin | Cevap |
|---|---|
| Örnek alanı eklemek (`private int z;`) | ❌ **Derleme hatası** |
| **Statik** alan eklemek | ✅ |
| Örnek metodu eklemek | ✅ |
| Statik metot / statik initializer eklemek | ✅ |
| **Örnek** initializer bloğu (`{ ... }`) eklemek | ❌ **Derleme hatası** |
| Başka bir sınıfı `extends` etmek | ❌ Record **implicitly final** ve zaten `java.lang.Record`'u genişletir |
| Bir arayüzü `implements` etmek | ✅ |
| Record'u `abstract` yapmak | ❌ |
| Record'u `final` yazmak | ✅ (zaten öyle, gereksiz ama geçerli) |
| Accessor'ı override etmek | ✅ |
| `equals`/`hashCode`/`toString` override etmek | ✅ |
| Generic olmak (`record Kutu<T>(T deger)`) | ✅ |
| Varargs bileşen (`record R(int... n)`) | ✅ |
| Bileşen adını `record` yapmak | ✅ (`record` da ayrılmış tip adıdır, anahtar kelime değil) |

> **İç içe record'lar implicitly `static`'tir** — dış sınıfın örneğine bağlı değildirler.

## 3. ⭐⭐⭐ Constructor biçimleri

### Compact constructor — doğrulama ve normalleştirme

```java
public record Aralik(int alt, int ust) {
    public Aralik {                       // parantez YOK
        if (alt > ust) throw new IllegalArgumentException("alt > ust");
        alt = Math.max(alt, 0);           // PARAMETREYI degistir
        // this.alt = alt;                // DERLENMEZ: alana atama yasak
    }
}
```

| Kural | Detay |
|---|---|
| Sözdizimi | `public Aralik {` — **parametre listesi yazılmaz** |
| İçinde ne yapılır | Doğrulama + **parametre değişkenlerini** değiştirme |
| Alana atama | ❌ `this.alt = ...` **derleme hatası** |
| Alanların atanması | Blok bittiğinde derleyici **otomatik** yapar |
| Erişim belirteci | Record'un kendisinden **daha kısıtlı olamaz** |

### Canonical constructor — açık yazım

```java
public record Aralik(int alt, int ust) {
    public Aralik(int alt, int ust) {     // parametre listesi TAM ve AYNI sirada
        this.alt = alt;                   // burada alanlara atama ZORUNLU
        this.ust = ust;
    }
}
```

Compact ve canonical **aynı anda yazılamaz** — ikisi de aynı constructor'dır.

### Ek (overloaded) constructor

```java
public record Aralik(int alt, int ust) {
    public Aralik(int ust) {
        this(0, ust);                     // canonical'a delege etmek ZORUNLU
    }
}
```

> ⚠️ **Tuzak:** Ek constructor **ilk deyim olarak** `this(...)` ile canonical'ı çağırmak zorundadır.
> Doğrudan `this.alt = ...` yazamaz.

## 4. Record'lar ve pattern matching

Record'lar **record pattern** ile ayrıştırılabilir (2.1):

```java
record Nokta(int x, int y) {}
record Cizgi(Nokta bas, Nokta son) {}

if (o instanceof Cizgi(Nokta(var x1, var y1), Nokta son)) {
    System.out.println(x1 + "," + y1 + " -> " + son);
}
```

| Kural | Detay |
|---|---|
| İç içe ayrıştırma | ✅ Sınırsız derinlikte |
| `var` kullanımı | ✅ Bileşen tipini yazmak zorunda değilsin |
| Bileşen sayısı | **Tam olarak** eşleşmeli — eksik/fazla yazarsan derlenmez |
| `null` ile eşleşme | ❌ Record pattern `null` nesneye **uymaz** |
| Sealed + record | Exhaustive `switch` için ideal ikili (3.5) |

## 5. `equals`, `hashCode` ve immutability sınırı

Record'un ürettiği `equals` **tüm bileşenleri** karşılaştırır (primitifleri `==`, referansları `equals`).

```java
record Kutu(List<String> icerik) {}
var l = new ArrayList<String>(List.of("a"));
var k = new Kutu(l);
l.add("b");
System.out.println(k);      // Kutu[icerik=[a, b]]  <- record DEGISTI!
```

> ⚠️⚠️ **Tuzak:** Record **shallow immutable**'dır. Bileşen değiştirilebilir bir nesneyse
> (`List`, `Date`, dizi) record'un içeriği dışarıdan değiştirilebilir. Gerçek immutability için
> compact constructor'da **savunmacı kopya** almalısın:
> ```java
> record Kutu(List<String> icerik) {
>     Kutu { icerik = List.copyOf(icerik); }
> }
> ```

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| `n.getX()` | **Derlenmez** | Accessor bileşen adıyla aynıdır: `n.x()` |
| `n.x` (alan erişimi) | Derlenmez | Alanlar `private` |
| Record'a `private int z;` | Derlenmez | Örnek alan eklenemez |
| Record'a `static int z;` | ✅ Derlenir | Statik alan serbest |
| Record'a `{ ... }` örnek bloğu | Derlenmez | Örnek initializer yasak |
| `record A extends B` | Derlenmez | Record implicitly final, üstü sabit |
| `record A implements I` | ✅ | Arayüz serbest |
| Compact ctor'da `this.x = x;` | Derlenmez | Yalnızca parametreye atanır |
| Compact + canonical birlikte | Derlenmez | İkisi aynı constructor |
| Ek ctor'da `this(...)` yok | Derlenmez | Canonical'a delege şart |
| İç içe record | **Implicitly static** | `static` yazmaya gerek yok |
| Record pattern + `null` | Eşleşmez | `case null` ayrı yazılır |
| Değiştirilebilir bileşenli record | **Tam immutable değil** | Savunmacı kopya gerekir |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Accessor adı**
> ```java
> record P(int x) {}
> System.out.println(new P(5).getX());
> ```
> → **Compilation fails.** Doğrusu `x()`.

**Kalıp 2 — Örnek alan**
> ```java
> record P(int x) { private int y; }
> ```
> → **Compilation fails.** Record'a örnek alan eklenemez.

**Kalıp 3 — Compact constructor**
> ```java
> record P(int x) {
>     P { this.x = x * 2; }
> }
> ```
> → **Compilation fails.** Compact constructor'da alana atanamaz; `x = x * 2;` yazılmalı.

**Kalıp 4 — Ek constructor**
> ```java
> record P(int x, int y) {
>     P(int x) { this.x = x; this.y = 0; }
> }
> ```
> → **Compilation fails.** `this(x, 0);` ile canonical çağrılmalı.

**Kalıp 5 — equals**
> ```java
> System.out.println(new P(1,2).equals(new P(1,2)));
> ```
> → **`true`**. Record `equals`'ı bileşen değerlerine bakar.

## 60 saniyelik özet

- Record derleyicisi üretir: `private final` alanlar, canonical constructor, **bileşen adlı accessor'lar**,
  `equals`, `hashCode`, `toString`.
- Accessor `x()`'tir — `getX()` **değil**, `n.x` **değil**.
- **Örnek alan ve örnek initializer bloğu yasak**; statik alan/metot ve örnek metot serbest.
- Record **implicitly final**, `extends` edemez; `implements` edebilir.
- **Compact constructor**: parantezsiz, yalnızca **parametreye** atanır, alanlar sonda otomatik atanır.
- **Canonical constructor** açık yazılırsa alanlara atama **zorunlu**; compact ile birlikte yazılamaz.
- Ek constructor **ilk deyimde `this(...)`** ile canonical'ı çağırmalı.
- İç içe record'lar **implicitly static**.
- Record pattern iç içe ayrıştırır, `var` kabul eder, **`null` ile eşleşmez**.
- Record **shallow immutable**: değiştirilebilir bileşen için **savunmacı kopya** şart.
