## Neden bu konu

Sınav sana "sınıf nedir" diye sormaz. **"Bu sınıf `new` edildiğinde satırlar hangi sırayla çalışır?"**
diye sorar ve şıklara dört farklı çıktı koyar. Bu sıra **ezberlenir**, mantıkla türetilmez.

İkinci kaynak: **constructor kuralları**. `this()` nerede olabilir, varsayılan constructor ne zaman
üretilir, `final` alan nerede atanmalı.

**Büyük fikir:** Bir nesne kurulurken **statik kısım bir kez**, **örnek kısmı her `new`'de** çalışır ve
her ikisinde de **metin sırası** belirleyicidir. Kalıtım varsa **önce üst sınıf** tamamlanır.

---

## 1. Alanlar, yerel değişkenler ve varsayılan değerler

| | **Alan (field)** | **Yerel değişken** |
|---|---|---|
| Varsayılan değer | ✅ Var (`0`, `false`, `null`) | ❌ **Yok** — kullanmadan önce atamalısın |
| Kapsam | Sınıf/nesne ömrü | Blok |
| `final` ise | Constructor'a kadar atanabilir | Bildirimde veya sonra bir kez |
| Erişim belirteci | `public/protected/private/(paket)` | ❌ Alamaz |

```java
class A {
    int x;                     // 0
    String s;                  // null
    void m() {
        int y;
        System.out.println(y); // DERLENMEZ: might not have been initialized
    }
}
```

> ⚠️ **Tuzak:** Yerel değişkenin **bildirilmesi** yeterli değildir; derleyici **kesin atanmışlık**
> (definite assignment) analizi yapar. `if` dallarının **hepsinde** atanmadıysa yine hata verir.

## 2. ⭐ Constructor kuralları

| Kural | Detay |
|---|---|
| İsim | **Sınıf adıyla birebir aynı**, dönüş tipi **yok** |
| `void` yazarsan | Artık constructor değil, **normal metottur** (derlenir, sessizce çalışmaz!) |
| Varsayılan constructor | **Hiç constructor yazmadıysan** derleyici parametresiz ekler. Bir tane bile yazdıysan **eklemez** |
| `this(...)` | Aynı sınıfın başka constructor'ını çağırır, **ilk deyim** olmalı |
| `super(...)` | Üst sınıf constructor'ı, **ilk deyim** olmalı |
| İkisi birlikte | ❌ `this()` ve `super()` aynı constructor'da olamaz |
| Hiçbiri yazılmazsa | Derleyici **`super();`** ekler |
| Özyineleme | `this()` döngüsü → **derleme hatası** (`recursive constructor invocation`) |

```java
class A {
    A(int x) { }
}
class B extends A {
    B() { }        // DERLENMEZ: A'nin parametresiz constructor'i yok,
}                  // derleyici super() eklemeye calisir ve bulamaz
```

> ⚠️⚠️ **Tuzak — çok sorulur:** `public void Kedi() { }` bir **constructor değildir**, `Kedi` adında
> bir metottur. `new Kedi()` yazdığında bu metot çalışmaz. Şıklarda çıktı eksik gelir.

## 3. ⭐⭐⭐ Başlatma sırası — ezberlenecek

### Tek sınıfta

1. **Statik alanlar ve statik bloklar** — **metin sırasına göre**, sınıf ilk kez yüklendiğinde **bir kez**
2. **Örnek alanlar ve örnek initializer blokları** — metin sırasına göre, **her `new`'de**
3. **Constructor gövdesi**

```java
class Sira {
    static { System.out.print("1 "); }
    static int a = yaz("2 ");
    { System.out.print("3 "); }
    int b = yaz("4 ");
    Sira() { System.out.print("5 "); }

    static int yaz(String s) { System.out.print(s); return 0; }

    public static void main(String[] args) {
        new Sira();
        System.out.println();
        new Sira();
    }
}
// cikti: 1 2 3 4 5
//        3 4 5        <- statik kisim TEKRAR calismaz
```

### Kalıtım varsa

```
Ust sinifin statikleri  →  Alt sinifin statikleri
    →  Ust sinifin ornek initializer'lari  →  Ust sinifin constructor govdesi
    →  Alt sinifin ornek initializer'lari  →  Alt sinifin constructor govdesi
```

> **Hafıza kancası:** "Statikler önce ve bir kez; her seviyede **önce alanlar, sonra constructor**;
> yukarıdan aşağıya."

> ⚠️⚠️ **Tuzak:** Üst sınıfın constructor'ı, alt sınıfın **override ettiği** bir metodu çağırırsa,
> o metot alt sınıf alanları **henüz başlatılmadan** çalışır → alanlar varsayılan değerinde görünür.

```java
class Ust { Ust() { yaz(); } void yaz() { } }
class Alt extends Ust {
    int x = 5;
    void yaz() { System.out.println(x); }   // 0 yazar, 5 degil!
}
```

### İleri referans yasağı

```java
class C {
    int a = b;     // DERLENMEZ: illegal forward reference
    int b = 5;
}
```

## 4. `final` alanlar

| Nerede atanır | Geçerli mi |
|---|---|
| Bildirimde: `final int x = 5;` | ✅ |
| Örnek initializer bloğunda | ✅ |
| **Her** constructor'da | ✅ |
| Bir constructor'da atanıp diğerinde atanmazsa | ❌ Derleme hatası |
| İki kez atanırsa | ❌ Derleme hatası |
| Hiç atanmazsa | ❌ Derleme hatası (varsayılan değer **kurtarmaz**) |

`static final` alanlar aynı kuralı **statik blokta** karşılar.

> ⚠️ **Tuzak:** `final` bir **referans**, nesnenin içeriğini korumaz — yalnızca yeniden bağlamayı engeller.
> `final List<String> l = new ArrayList<>(); l.add("x");` **geçerlidir**.

## 5. Nesne yaşam döngüsü ve çöp toplama

| Aşama | Ne olur |
|---|---|
| Oluşturma | `new` → bellek ayrılır → başlatma sırası çalışır |
| Kullanım | En az bir **erişilebilir** referans var |
| **GC'ye uygun (eligible)** | Hiçbir canlı thread'den **erişilemez** hâle gelir |
| Toplama | JVM ne zaman istese; **garanti yok** |

```java
StringBuilder a = new StringBuilder("x");
StringBuilder b = a;
a = null;               // nesne HALA erisilebilir (b uzerinden)
b = null;               // ARTIK GC'ye uygun
```

| İfade | Doğru mu |
|---|---|
| `System.gc()` çöp toplamayı **başlatır** | ❌ Yalnızca **öneridir**, JVM yok sayabilir |
| Referans `null` yapılınca nesne **hemen** silinir | ❌ Yalnızca uygun hâle gelir |
| `finalize()` çağrılacağı garantidir | ❌ **Deprecated**, çağrılmayabilir |
| Birbirine referans veren iki ada nesne toplanabilir | ✅ Kök erişilebilirlik esastır |

| `this()` ikinci satırda | Derlenmez | İlk deyim olmalı |
| `this()` ve `super()` birlikte | Derlenmez | İkisi de ilk deyim olamaz |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Sıra sorusu**
> Statik blok, statik alan, örnek blok, alan ve constructor karışık sırayla verilir; çıktı istenir.
> → **Statikler bir kez, metin sırasına göre; sonra örnek kısmı; en son constructor.**

**Kalıp 2 — Sahte constructor**
> ```java
> class Kedi {
>     public void Kedi() { System.out.print("a"); }
>     public static void main(String[] a) { new Kedi(); }
> }
> ```
> → **Hiçbir şey yazılmaz.** `Kedi()` bir metottur.

**Kalıp 3 — Eksik super**
> ```java
> class A { A(int x) {} }
> class B extends A { }
> ```
> → **Compilation fails.** `B`'nin varsayılan constructor'ı `super()` çağırır, `A`'da yok.

**Kalıp 4 — this() konumu**
> ```java
> class A {
>     A() { System.out.print("x"); this(1); }
>     A(int i) {}
> }
> ```
> → **Compilation fails.** `this()` ilk deyim olmalı.

**Kalıp 5 — GC uygunluğu**
> ```java
> String a = new String("x");
> String b = a;
> a = null;
> ```
> → Nesne **GC'ye uygun değil**; `b` hâlâ gösteriyor.

## 60 saniyelik özet

- Alanlar varsayılan değer alır, **yerel değişkenler almaz**.
- Constructor **sınıf adıyla aynı** ve **dönüş tipi yok**; `void` yazarsan metot olur.
- Varsayılan constructor yalnızca **hiç constructor yazılmadıysa** üretilir.
- `this()` / `super()` **ilk deyim** olmalı ve **birlikte kullanılamaz**.
- Sıra: **statikler (bir kez, metin sırası) → örnek alan/blokları → constructor gövdesi**.
- Kalıtımda: tüm statikler → üst sınıfın örnek kısmı + ctor → alt sınıfın örnek kısmı + ctor.
- Üst constructor override edilmiş metodu çağırırsa alt alanlar **henüz başlatılmamıştır**.
- İleri referans (`int a = b;` üstte) **derleme hatası**.
- `final` alan **tam olarak bir kez** atanmalı; her constructor'da atanmalı.
- `final` referans, nesnenin **içeriğini** dondurmaz.
- Nesne, **erişilemez** olduğunda GC'ye uygun olur; `System.gc()` yalnızca öneridir.
