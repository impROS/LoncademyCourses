## Neden bu konu

Enum sandığından fazlasıdır: **alanı, constructor'ı, metodu ve hatta sabit başına gövdesi** olabilen
tam bir sınıftır. Sınav bunu bilip bilmediğini test eder — özellikle **constructor'ın ne zaman ve kaç kez
çalıştığını**, **noktalı virgül kuralını** ve **`switch` içindeki etiket yazımını**.

**Büyük fikir:** Enum, **sabit sayıda ve önceden bilinen** örneği olan bir sınıftır. Tüm kısıtları
(constructor `private`, `extends` yasak, `final`) bu tek cümleden çıkar.

## 1. ⭐ Temel yapı ve hazır metotlar

```java
enum Renk { KIRMIZI, YESIL, MAVI }
```

| Metot | Döner | Not |
|---|---|---|
| `values()` | `Renk[]` | `static`, **her çağrıda yeni dizi** üretir |
| `valueOf(String)` | `Renk` | `static`; bulamazsa **`IllegalArgumentException`** |
| `name()` | `String` | Sabitin **tam adı**, `final` — override edilemez |
| `ordinal()` | `int` | **0 tabanlı** bildirim sırası |
| `toString()` | `String` | Varsayılan `name()`; **override edilebilir** |
| `compareTo` | `int` | `ordinal` farkına göre |
| `equals` / `hashCode` | — | `final`, referans eşitliği (her sabit tektir) |

```java
Renk.valueOf("MAVI");        // Renk.MAVI
Renk.valueOf("mavi");        // IllegalArgumentException — buyuk/kucuk harf ONEMLI
Renk.valueOf("MOR");         // IllegalArgumentException
Renk.MAVI.ordinal();         // 2
Renk.values().length;        // 3
```

> ⚠️ **Tuzak:** `ordinal()` bildirim sırasına bağlıdır. Sabitleri yeniden sıraladığında değişir —
> **veritabanına ordinal yazmak** klasik bir hatadır. Sınav bunu "hangi ifade kırılgandır" diye sorar.

> `enum` sabitleri **tek örnektir (singleton)**, bu yüzden `==` ile karşılaştırmak **güvenlidir**
> ve tercih edilir.

## 2. ⭐⭐ Alan, constructor ve metot

```java
enum Gezegen {
    DUNYA(5.97e24, 6.37e6),
    MARS(6.42e23, 3.39e6);              // <-- NOKTALI VIRGUL zorunlu

    private final double kutle, yaricap;

    Gezegen(double kutle, double yaricap) {      // ortuk PRIVATE
        this.kutle = kutle;
        this.yaricap = yaricap;
    }

    double yercekimi() { return 6.67e-11 * kutle / (yaricap * yaricap); }
}
```

| Kural | Detay |
|---|---|
| Constructor erişimi | **Örtük `private`** — `public`/`protected` yazarsan **derleme hatası** |
| Ne zaman çalışır | Sınıf ilk kez yüklendiğinde, **her sabit için bir kez** |
| Noktalı virgül | Sabit listesinden sonra **başka üye varsa zorunlu** |
| Sabitler nerede olmalı | Gövdedeki **ilk** eleman |
| `new Renk()` | ❌ Derleme hatası |
| `extends` | ❌ Enum zaten `java.lang.Enum`'u genişletir |
| `implements` | ✅ Serbest |
| Enum `abstract` olabilir mi | ❌ Ama **sabit başına gövde** ile aynı etki elde edilir |

## 3. Sabit başına gövde (constant-specific body)

```java
enum Islem {
    TOPLA { public int uygula(int a, int b) { return a + b; } },
    CIKAR { public int uygula(int a, int b) { return a - b; } };

    public abstract int uygula(int a, int b);    // her sabit uygulamak ZORUNDA
}

Islem.TOPLA.uygula(3, 4);      // 7
```

| Kural | Detay |
|---|---|
| `abstract` metot bildirdiysen | **Her** sabit gövde vermek zorunda |
| Gövdeli sabit | Aslında **anonim alt sınıftır** — `Islem.TOPLA.getClass()` `Islem$1` döner |
| Gövdeli sabitli enum | `final` **değildir** (alt sınıfları var), ama yine de genişletilemez |
| `default` metot benzeri | Enum'da somut metot yazıp bazı sabitlerde override edebilirsin |

## 4. ⭐ Enum ve `switch`

```java
Renk r = Renk.MAVI;
switch (r) {
    case KIRMIZI -> System.out.println("kirmizi");    // NITELIKSIZ (klasik yazim)
    case Renk.MAVI -> System.out.println("mavi");     // NITELIKLI — Java 21'de GECERLI
    default -> System.out.println("diger");
}
```

| Kural | Detay |
|---|---|
| Niteliksiz etiket (`KIRMIZI`) | ✅ Her sürümde geçerli; enum tipi selector'den anlaşılır |
| Nitelikli etiket (`Renk.MAVI`) | ✅ **Java 21'de geçerli** (daha eski sürümlerde derleme hatasıydı) |
| Tüm sabitler yazıldıysa | `switch` **ifadesi** `default` istemez |
| `default` + yeni sabit | Yeni sabit sessizce `default`'a düşer — sealed'daki (3.5) aynı risk |
| `null` selector | `case null` yoksa **NPE** (2.1) |

> ⚠️ **Tuzak:** Klasik `switch` **deyiminde** `case Renk.MAVI:` yazımı eski sürümlerde hataydı;
> Java 21'de artık geçerlidir. Eski kaynaklardan çalışıyorsan bu bilgi güncel değildir.

## 5. EnumSet ve EnumMap

Enum'lara özel, **bit vektörü/dizi** tabanlı ve çok hızlı koleksiyonlar:

```java
EnumSet<Renk> sicak = EnumSet.of(Renk.KIRMIZI);
EnumSet<Renk> hepsi = EnumSet.allOf(Renk.class);
EnumSet<Renk> yok   = EnumSet.noneOf(Renk.class);
EnumSet<Renk> aralik= EnumSet.range(Renk.KIRMIZI, Renk.YESIL);
EnumSet<Renk> tersi = EnumSet.complementOf(sicak);

EnumMap<Renk, Integer> sayac = new EnumMap<>(Renk.class);
sayac.put(Renk.MAVI, 1);
```

| Not | Detay |
|---|---|
| `new EnumSet<>()` | ❌ Constructor yok — **fabrika metotları** kullanılır |
| `new EnumMap<>(...)` | ✅ Constructor var, **`Class` nesnesi ister** |
| Sıralama | İkisi de **`ordinal` sırasında** dolaşır |
| `null` anahtar | ❌ İkisi de kabul etmez |

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| `public Renk() {}` enum içinde | **Derlenmez** | Constructor örtük `private` |
| `new Renk()` | Derlenmez | Enum örnekleri sabit sayıda |
| Sabitlerden sonra metot, `;` yok | Derlenmez | Noktalı virgül zorunlu |
| Sabitler gövdenin ortasında | Derlenmez | İlk eleman olmalı |
| `valueOf("mavi")` | `IllegalArgumentException` | Büyük/küçük harf duyarlı |
| `valueOf` bulamayınca | Exception | `null` **dönmez** |
| `ordinal()` | 0 tabanlı, **kırılgan** | Sıra değişirse değer değişir |
| `name()` override | ❌ `final` | `toString()` override edilebilir |
| Enum sabitlerini `==` ile karşılaştırma | ✅ Güvenli | Her sabit tek örnektir |
| `enum X extends Y` | Derlenmez | Zaten `Enum`'u genişletir |
| `enum X implements Y` | ✅ | Arayüz serbest |
| `case Renk.MAVI` (Java 21) | ✅ Geçerli | Eski sürümlerde hataydı |
| `new EnumSet<>()` | Derlenmez | Fabrika metodu kullan |
| `values()` her çağrıda | **Yeni dizi** | Döngüde çağırmak maliyetli |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Noktalı virgül**
> ```java
> enum E { A, B
>     void m() {}
> }
> ```
> → **Compilation fails.** Sabitlerden sonra `;` gerekir.

**Kalıp 2 — Constructor erişimi**
> ```java
> enum E { A; public E() {} }
> ```
> → **Compilation fails.** Enum constructor'ı `private` olmalı.

**Kalıp 3 — valueOf**
> ```java
> System.out.println(Renk.valueOf("Mavi"));
> ```
> → **`IllegalArgumentException` at runtime.**

**Kalıp 4 — ordinal**
> ```java
> enum E { A, B, C }
> System.out.println(E.C.ordinal());
> ```
> → **`2`**.

**Kalıp 5 — Constructor sayısı**
> Üç sabiti olan bir enum'un constructor'ına `println` konur, `main` içinde tek bir sabit kullanılır.
> → **Üç satır** yazılır: tüm sabitler sınıf yüklenirken oluşturulur.

## 60 saniyelik özet

- Enum bir **sınıftır**: alanı, constructor'ı, metodu, hatta sabit başına gövdesi olabilir.
- Constructor **örtük `private`**; sınıf yüklenirken **her sabit için bir kez** çalışır.
- Sabitler gövdenin **ilk** elemanıdır; başka üye varsa sonlarına **`;`** konur.
- `values()` her çağrıda **yeni dizi**; `valueOf` bulamazsa **`IllegalArgumentException`**.
- `name()` `final`'dır, `toString()` override edilebilir.
- `ordinal()` **0 tabanlıdır** ve sıraya bağlı olduğu için **kırılgandır**.
- Sabitler tek örnektir → `==` karşılaştırması **güvenlidir**.
- `extends` yasak, `implements` serbest; `new` ile üretilemez.
- Gövdeli sabitler **anonim alt sınıflardır** (`Islem$1`).
- `switch`'te hem `KIRMIZI` hem **Java 21'de** `Renk.KIRMIZI` yazımı geçerlidir.
- `EnumSet` fabrika metotlarıyla, `EnumMap` `Class` alan constructor'la üretilir; ikisi de `ordinal`
  sırasında dolaşır ve `null` kabul etmez.
