## 1. Metot imzası ve overloading

**İmza = metot adı + parametre tipleri (sıralı).** Dönüş tipi, parametre adları, `throws` listesi
ve erişim belirteci **imzaya dahil değildir**.

```java
int f(int x) { return 0; }
String f(int y) { return ""; }     // DERLENMEZ: ayni imza (donus tipi fark etmez)
int f(long x) { return 0; }        // OK: farkli parametre tipi
```

### ⭐⭐⭐ Overload çözümleme — üç tur

| Tur | Ne denenir | Örnek |
|---|---|---|
| **1. Tam eşleşme / alt tip** | Cast'siz, dönüşümsüz | `f(int)` çağrısına `f(int)` |
| **2. Genişletme (widening)** | Primitif genişletme veya üst tipe atama | `int` → `long` → `float` → `double` |
| **3. Kutulama (boxing)** | Autoboxing + ardından üst tipe genişletme | `int` → `Integer` → `Object` |
| **4. Varargs** | **En son** çare | `f(int...)` |

```java
static void f(long x)     { System.out.println("long"); }
static void f(Integer x)  { System.out.println("Integer"); }
static void f(int... x)   { System.out.println("varargs"); }

f(5);      // "long"   <- genisletme, kutulamadan ONCE gelir
```

> ⚠️⚠️ **Tuzak:** Genişletme, kutulamayı **her zaman** yener. Kutulama da varargs'ı yener.
> `f(5)` çağrısında `Integer` sürümü asla seçilmez — `long` varsa.

**Kutulamadan sonra genişletme olmaz:**
```java
static void g(Long x) { }
g(5);          // DERLENMEZ: int -> Integer olur, Integer -> Long OLMAZ
g(5L);         // OK: long -> Long
```

**Kutuladıktan sonra üst tipe gitmek serbesttir:**
```java
static void h(Object o) { }
h(5);          // OK: int -> Integer -> Object
```

## 2. ⭐ Varargs

| Kural | Detay |
|---|---|
| Sayı | Bir metotta **en fazla bir** varargs parametresi |
| Konum | **En sonda** olmalı |
| Çağrı biçimi | `f(1,2,3)` veya `f(new int[]{1,2,3})` — ikisi de geçerli |
| Gövdede | Normal bir **dizidir**: `x.length`, `x[0]` |
| Argümansız çağrı | `f()` geçerli → **boş dizi** (null değil) |
| `null` gönderme | `f(null)` → dizi **null olur**, boş dizi değil → `x.length` NPE |
| Belirsizlik | İki varargs overload'ı aynı anda uyuyorsa **derleme hatası** |

```java
static void f(String... s) { System.out.println(s.length); }
f();               // 0
f("a", "b");       // 2
f(new String[0]);  // 0
f((String) null);  // 1
f((String[]) null);// RUNTIME: NullPointerException
```

## 3. Erişim belirteçleri ve `static`

| Belirteç | Aynı sınıf | Aynı paket | Alt sınıf (farklı paket) | Herkes |
|---|---|---|---|---|
| `private` | ✅ | ❌ | ❌ | ❌ |
| *(paket-özel, yazılmayan)* | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ (**yalnızca kalıtım üzerinden**) | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

> ⚠️ **Tuzak:** `protected` üye, farklı paketteki alt sınıfta **kendi** referansı üzerinden erişilebilir;
> aynı tipteki **başka** bir nesne üzerinden erişilemez.

### static kuralları

```java
class A {
    int x;
    static int y;
    static void s() {
        System.out.println(y);      // OK
        System.out.println(x);      // DERLENMEZ: static baglamda ornek uyesi
    }
    void i() {
        System.out.println(y);      // OK: ornek metot statik uyeye erisir
    }
}
```

| Durum | Sonuç |
|---|---|
| Statik metottan örnek alanı/metodu | ❌ Derleme hatası |
| Örnek metottan statik üye | ✅ |
| `a.staticMetot()` (örnek referansı üzerinden) | ✅ Derlenir (uyarı verir); `a` **null olsa bile çalışır** |
| Statik metot override edilebilir mi | ❌ **Hiding** olur, override değil (3.4) |

## 4. ⭐ Değer ile geçiş (pass-by-value)

**Java her zaman değer ile geçirir.** Nesnelerde geçirilen değer **referansın kopyasıdır**.

```java
static void degistir(StringBuilder sb, String s, int i) {
    sb.append("!");      // nesneyi degistirir       -> disarida GORULUR
    sb = new StringBuilder("yeni");   // kopyayi baglar -> disarida GORULMEZ
    s += "!";            // String immutable         -> GORULMEZ
    i++;                 // primitif kopyasi         -> GORULMEZ
}
```

> **Hafıza kancası:** "Nesnenin **içini** değiştirirsen görülür, **referansı** değiştirirsen görülmez."

## 5. ⭐⭐ `var` — yerel değişken tip çıkarımı

```java
var liste = new ArrayList<String>();     // ArrayList<String>
var sayi = 5;                            // int
for (var s : liste) { }                  // OK
```

| Nerede | Geçerli mi |
|---|---|
| Yerel değişken (initializer'lı) | ✅ |
| `for` / for-each değişkeni | ✅ |
| try-with-resources kaynağı | ✅ |
| Lambda parametresi (`(var a, var b) ->`) | ✅ (hepsi `var` olmalı) |
| **Alan (field)** | ❌ |
| **Metot parametresi** | ❌ |
| **Dönüş tipi** | ❌ |
| **`catch` parametresi** | ❌ |
| Initializer'sız: `var x;` | ❌ |
| `var x = null;` | ❌ (tip çıkarılamaz) |
| `var x = {1, 2, 3};` | ❌ (dizi kısayolu olmaz) |
| Aynı satırda çoklu: `var a = 1, b = 2;` | ❌ |
| Lambda ataması: `var f = () -> {};` | ❌ (hedef tip yok) |

> ⚠️ **Tuzak:** `var` bir **anahtar kelime değil**, ayrılmış bir tip adıdır. `int var = 5;` **derlenir**;
> `var` adında bir değişken/metot/paket tanımlayabilirsin ama **sınıf adı** olarak kullanamazsın.

`var` **statik tiptir** — çalışma zamanında değişmez:
```java
var x = 5;
x = "metin";      // DERLENMEZ: x zaten int
```

## 6. Immutability ve effectively final

### Immutable sınıf tarifi

1. Sınıfı `final` yap (veya tüm constructor'ları `private`)
2. Tüm alanları `private final` yap
3. **Setter yazma**
4. Constructor'da alınan **değiştirilebilir** nesnelerin **kopyasını** al
5. Getter'larda da **kopya döndür**

```java
public final class Kisi {
    private final String ad;
    private final List<String> etiketler;

    public Kisi(String ad, List<String> etiketler) {
        this.ad = ad;
        this.etiketler = new ArrayList<>(etiketler);      // savunmaci kopya
    }
    public List<String> getEtiketler() {
        return List.copyOf(etiketler);                     // disari kopya
    }
}
```

> ⚠️ **Tuzak:** Savunmacı kopya alınmazsa sınıf **immutable değildir** — çağıran, verdiği listeyi
> sonradan değiştirerek nesnenin içini bozabilir. Sınav bu senaryoyu sorar.

### Effectively final

Bir yerel değişken **hiç yeniden atanmıyorsa** `final` yazılmasa bile *effectively final*'dır.
Lambda ve iç sınıflar **yalnızca** böyle değişkenleri yakalayabilir (6.1, 3.8).

```java
int sayi = 5;
Runnable r = () -> System.out.println(sayi);   // OK: effectively final
sayi = 6;                                       // Bu satir eklenirse YUKARISI DERLENMEZ
```

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| Yalnızca dönüş tipi farklı iki metot | **Derlenmez** | Dönüş tipi imzaya dahil değil |
| `f(5)` — `f(long)` ve `f(Integer)` var | **`long`** seçilir | Genişletme kutulamadan önce |
| `f(5)` — `f(Integer)` ve `f(int...)` var | **`Integer`** seçilir | Kutulama varargs'tan önce |
| `g(5)` — yalnızca `g(Long)` var | **Derlenmez** | `int → Integer → Long` zinciri yok |
| `h(5)` — yalnızca `h(Object)` var | ✅ Derlenir | Kutulama sonrası üst tipe geçiş serbest |
| `f()` — varargs metot | Boş dizi, `length == 0` | `null` değil |
| `f((String[]) null)` | Runtime NPE | Dizi null olur |
| Statik metottan örnek alanı | Derlenmez | Ters yön serbest |
| `null.staticMetot()` benzeri çağrı | Çalışır | Statik çağrı referansı kullanmaz |
| `var x;` | Derlenmez | Initializer zorunlu |
| `var x = null;` | Derlenmez | Tip çıkarılamaz |
| Alan olarak `var` | Derlenmez | Yalnızca yerel değişkende |
| `int var = 5;` | ✅ Derlenir | `var` ayrılmış kelime değil |
| Metoda `StringBuilder` verip `append` | Dışarıda **görülür** | İçerik değişti |
| Metotta parametreye yeni nesne atama | Dışarıda **görülmez** | Referansın kopyası bağlandı |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Overload sırası**
> `void f(long)`, `void f(Integer)`, `void f(int...)` tanımlı. `f(5)` hangisini çağırır?
> → **`f(long)`**.

**Kalıp 2 — Kutulama zinciri**
> `void f(Long x)` tanımlı, `f(5)` çağrılıyor.
> → **Compilation fails.** `int` → `Integer` olur, `Integer` → `Long` olmaz.

**Kalıp 3 — Varargs null**
> ```java
> static void f(String... s) { System.out.println(s.length); }
> f(null);
> ```
> → **NullPointerException at runtime.** `null` doğrudan dizi olarak geçer.

**Kalıp 4 — var kısıtı**
> ```java
> var x = null;
> ```
> → **Compilation fails.** Tip çıkarılamaz.

**Kalıp 5 — Pass-by-value**
> ```java
> static void m(StringBuilder sb) { sb = new StringBuilder("b"); }
> StringBuilder s = new StringBuilder("a");
> m(s);
> System.out.println(s);
> ```
> → **`a`**. Referansın kopyası yeniden bağlandı, dışarısı etkilenmedi.

## 60 saniyelik özet

- İmza = **ad + parametre tipleri**. Dönüş tipi imzaya dahil **değil**.
- Overload sırası: **tam eşleşme → genişletme → kutulama → varargs**. Geri dönüş yok.
- `int → Integer → Long` **yoktur**; `int → Integer → Object` **vardır**.
- Varargs: en fazla bir tane, **en sonda**; `f()` boş dizi verir, `f((T[])null)` NPE atar.
- Statik metottan örnek üyesine erişilmez; ters yön serbesttir.
- Java **her zaman değer ile geçirir**; nesnede geçen şey **referansın kopyasıdır**.
- `var` yalnızca **yerel değişken, döngü değişkeni, try-with-resources ve lambda parametresinde**.
- `var x;`, `var x = null;`, `var` alan/parametre/dönüş tipi → **derlenmez**. `int var = 5;` derlenir.
- Immutable sınıf: `final` sınıf + `private final` alanlar + setter yok + **savunmacı kopya**.
- Lambda/iç sınıf yalnızca **effectively final** yerel değişkeni yakalayabilir.
