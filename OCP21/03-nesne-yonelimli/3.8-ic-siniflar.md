## Neden bu konu

Dört ayrı iç sınıf türü var ve sınav ikisini kasten karıştırır: **static nested** ile **inner**.
Aradaki tek fark "dış sınıfın örneğine bağlı mı" sorusudur ve bu fark **nesne üretme sözdizimini**
değiştirir: `new Dis.Ic()` mi, `dis.new Ic()` mi?

Ayrıca Java 16'da bir kural değişti: **inner ve local sınıflar artık `static` üye bildirebiliyor.**
Eski kaynaklardan çalışıyorsan bu bilgi yanlış olacak.

**Büyük fikir:** `static` olmayan her iç sınıf, dış sınıfın örneğine **gizli bir referans** taşır.
Bütün kurallar bu tek gerçekten çıkar.

## 1. ⭐⭐ Dört tür — tek tabloda

| | **static nested** | **inner (member)** | **local** | **anonymous** |
|---|---|---|---|---|
| Nerede bildirilir | Sınıf gövdesi | Sınıf gövdesi | **Metot içi** | İfade içinde |
| `static` mi | ✅ | ❌ | ❌ | ❌ |
| Dış örneğe referans | ❌ Yok | ✅ **Var** | Bağlama göre | Bağlama göre |
| Nasıl üretilir | `new Dis.Ic()` | **`dis.new Ic()`** | `new Ic()` (metot içinde) | `new Tip() { ... }` |
| Dış sınıfın `private` üyesi | ✅ (statik olanlar) | ✅ **Hepsi** | ✅ | ✅ |
| Erişim belirteci alabilir mi | ✅ (4'ü de) | ✅ | ❌ | ❌ |
| `static` üye bildirebilir mi | ✅ | ✅ **(Java 16+)** | ✅ **(Java 16+)** | ✅ (Java 16+) |
| Constructor'ı var mı | ✅ | ✅ | ✅ | ❌ **Yok** |
| Kaç tip genişletir | Normal kurallar | Normal kurallar | Normal kurallar | **Tam olarak 1** (sınıf **veya** arayüz) |

> **İç içe `record`, `enum` ve `interface` her zaman örtük `static`'tir** (3.3, 3.7).

## 2. static nested vs inner

```java
class Dis {
    private int x = 1;
    private static int sx = 2;

    static class Nested {
        int oku() { return sx; }        // yalnizca STATIK uyelere erisir
        // int hata() { return x; }     // DERLENMEZ
    }

    class Inner {
        int oku() { return x + sx; }    // HER SEYE erisir
    }
}

// uretim
Dis.Nested n = new Dis.Nested();        // dis ORNEK GEREKMEZ
Dis d = new Dis();
Dis.Inner i = d.new Inner();            // dis ORNEK GEREKLI
```

> ⚠️⚠️ **Tuzak:** `new Dis.Inner()` **derlenmez**. Sözdizimi `d.new Inner()`'dır —
> `new` anahtar kelimesi **noktadan sonra** gelir. Sınav bunu çok sorar.

### Gölgeleme ve `Dis.this`

```java
class Dis {
    int x = 1;
    class Ic {
        int x = 2;
        void yaz() {
            int x = 3;
            System.out.println(x);            // 3  yerel
            System.out.println(this.x);       // 2  ic sinif alani
            System.out.println(Dis.this.x);   // 1  dis sinif alani
        }
    }
}
```

## 3. Local sınıflar

```java
void metot() {
    int sayi = 5;                       // effectively final olmali
    class Yerel {
        void yaz() { System.out.println(sayi); }
    }
    new Yerel().yaz();
    // sayi = 6;   <- bu satiri eklersen YUKARISI DERLENMEZ
}
```

| Kural | Detay |
|---|---|
| Kapsam | Bildirildiği **bloktan** çıkınca yok olur |
| Erişim belirteci | ❌ `public`/`private` **yazılamaz** |
| `final`/`abstract` | ✅ Yazılabilir |
| Yakalanan yerel değişken | **Effectively final** olmak zorunda (3.2) |
| Dış sınıfın alanları | ✅ Erişilir (statik metottaysa yalnızca statikler) |
| `static` üye | ✅ Java 16+ |

## 4. ⭐ Anonim sınıflar

```java
Runnable r = new Runnable() {
    @Override public void run() { System.out.println("calisti"); }
};                                            // <-- NOKTALI VIRGUL zorunlu

abstract class Sekil { abstract double alan(); }
Sekil s = new Sekil() { double alan() { return 1; } };
```

| Kural | Detay |
|---|---|
| Ne genişletir | **Tam olarak bir** sınıf **veya** bir arayüz — ikisi birden **olmaz** |
| Constructor | ❌ **Yok** — üst sınıfın constructor argümanları `new Tip(arg) { }` ile verilir |
| Initializer bloğu | ✅ Kurulum için `{ ... }` kullanılır |
| Adı var mı | ❌ Derlenmiş adı `Dis$1`, `Dis$2` … |
| Sonundaki noktalı virgül | **Zorunlu** — bu bir **ifadedir**, bildirim değil |
| Yakalama | Effectively final yerel değişkenler |
| Ne zaman lambda tercih edilir | Hedef **fonksiyonel arayüzse** (6.1) — daha kısa ve `this` farklıdır |

> ⚠️ **Tuzak:** Anonim sınıf içinde `this` **anonim sınıfın kendisini** gösterir.
> Lambda içinde `this` **çevreleyen sınıfı** gösterir. Bu, ikisi arasındaki en önemli davranış farkıdır.

## Sık karıştırılanlar — tek tabloda

| Soruda geçen | Doğru cevap | Neden diğeri değil |
|---|---|---|
| `new Dis.Inner()` (inner, static değil) | **Derlenmez** | `dis.new Inner()` olmalı |
| `new Dis.Nested()` | ✅ Geçerli | Static nested dış örnek istemez |
| Static nested'dan dış örnek alanı | Derlenmez | Yalnızca statiklere erişir |
| Inner'dan dış `private` alan | ✅ Erişir | Gizli referans var |
| `Dis.this.x` | Dış sınıfın alanı | `this.x` iç sınıfınki |
| Local sınıfa `public` | Derlenmez | Erişim belirteci alamaz |
| Local sınıfta `static` alan | ✅ **Java 16+** | Eski sürümlerde yasaktı |
| Anonim sınıfa constructor | Derlenmez | Adı yok, constructor da yok |
| Anonim sınıf sonunda `;` yok | Derlenmez | İfadedir |
| Anonim sınıf iki arayüz | Derlenmez | Tam olarak bir tip |
| Anonim sınıfta `this` | **Anonim sınıf** | Lambda'da çevreleyen sınıf |
| İç içe `record`/`enum`/`interface` | Örtük `static` | `static` yazmaya gerek yok |
| Lambda'nın yakaladığı değişken | Effectively final | Değiştirirsen derlenmez |

## Sınavda nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — Üretim sözdizimi**
> ```java
> class Dis { class Ic {} }
> Dis.Ic i = new Dis.Ic();
> ```
> → **Compilation fails.** `new Dis().new Ic()` olmalı.

**Kalıp 2 — Static nested erişimi**
> ```java
> class Dis { int x = 1; static class N { int m() { return x; } } }
> ```
> → **Compilation fails.** Static nested örnek alanına erişemez.

**Kalıp 3 — Gölgeleme**
> `Dis.this.x`, `this.x` ve yerel `x` aynı metotta verilir; hangisi hangisidir sorulur.

**Kalıp 4 — Anonim sınıf noktalı virgülü**
> ```java
> Runnable r = new Runnable() { public void run() {} }
> ```
> → **Compilation fails.** Sonuna `;` gerekir.

**Kalıp 5 — Effectively final**
> ```java
> void m() {
>     int i = 0;
>     Runnable r = () -> System.out.println(i);
>     i++;
> }
> ```
> → **Compilation fails.** `i` effectively final değil.

## 60 saniyelik özet

- Dört tür: **static nested**, **inner**, **local**, **anonymous**.
- Ayırt edici soru: "dış sınıfın **örneğine** bağlı mı?"
- `new Dis.Nested()` ✅ · `dis.new Inner()` ✅ · `new Dis.Inner()` ❌.
- Static nested yalnızca **statik** dış üyelere; inner **her şeye** (private dahil) erişir.
- `Dis.this.x` dış sınıfın alanı, `this.x` iç sınıfın alanı.
- Local sınıf **erişim belirteci alamaz**; kapsamı bildirildiği bloktur.
- **Java 16'dan beri** inner ve local sınıflar `static` üye bildirebilir.
- Anonim sınıf **tam olarak bir** tipi genişletir/uygular, **constructor'ı yoktur**, sonunda **`;`** vardır.
- Anonim sınıfta `this` = **anonim sınıf**; lambda'da `this` = **çevreleyen sınıf**.
- Yakalanan yerel değişkenler **effectively final** olmalı.
- İç içe `record`, `enum` ve `interface` örtük **`static`**'tir.
