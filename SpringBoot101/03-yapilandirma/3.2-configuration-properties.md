> **Alan:** Yapılandırma
> **Süre:** ~30 dakika okuma + 20 dakika pratik
> **Test:** [`3.2-test.html`](3.2-test.html) · 14 soru

---

## Neden bu konu

`@Value` bir ayar için iyidir. Sekiz ayar için şuna dönüşür:

```java
@Service
public class SiparisServisi {
    public SiparisServisi(
            @Value("${siparis.magaza-adi}") String magazaAdi,
            @Value("${siparis.zaman-asimi:3000}") int zamanAsimi,
            @Value("${siparis.bekleme:30s}") Duration bekleme,
            @Value("${siparis.sunucular}") List<String> sunucular,
            @Value("${siparis.yeniden-deneme:3}") int yenidenDeneme,
            @Value("${siparis.e-posta}") String ePosta,
            @Value("${siparis.aktif:true}") boolean aktif,
            SiparisDeposu depo) { ... }
}
```

Bu kodun üç derdi var ve üçü de ciddi:

| Dert | Somut sonucu |
|---|---|
| Ayar adları **metin** olarak yazılı | Yazım hatasını derleyici yakalamaz; çalışma zamanında patlar ya da varsayılan sessizce devreye girer |
| Doğrulama yok | `zaman-asimi=-5` yazan biri olur, hiçbir şey uyarmaz |
| Ayarlar dağınık | Aynı `siparis.*` ailesi beş sınıfa yayılır; kimse tam listeyi bilmez |

**Büyük fikir:** Ayarları tek tek okumak yerine, ilgili olanları **bir nesneye bağla**.
O nesne artık ayarların tek doğrusu, tek belgesi ve tek doğrulama noktası olur.

---

## 1. En sade hâl: `record` ile bağlama ⭐

```java
package tr.loncademy.siparis;

import org.springframework.boot.context.properties.ConfigurationProperties;
import java.time.Duration;
import java.util.List;

@ConfigurationProperties(prefix = "siparis")
public record SiparisAyarlari(
        String magazaAdi,
        int zamanAsimi,
        Duration bekleme,
        List<String> sunucular) {
}
```

Ayar dosyası:

```properties
siparis.magaza-adi=Merkez
siparis.zaman-asimi=3000
siparis.bekleme=45s
siparis.sunucular[0]=a.sirket.com
siparis.sunucular[1]=b.sirket.com
```

Çalıştırınca gerçek çıktı:

```
### AYAR = SiparisAyarlari[magazaAdi=Merkez, zamanAsimi=3000, bekleme=PT45S,
                           sunucular=[a.sirket.com, b.sirket.com]]
```

Üç şeye dikkat et:

1. **`magaza-adi` → `magazaAdi`** — relaxed binding ([3.1](3.1-oncelik-sirasi.md)) burada da çalışıyor.
2. **`45s` → `PT45S`** — metin, `Duration` nesnesine çevrildi. Sen ayrıştırma kodu yazmadın.
3. **`sunucular[0]`, `[1]` → `List<String>`** — liste kendiliğinden kuruldu.

`record` kullanmanın hediyesi: alanlar `final`, nesne değişmez. Ayarlar açılışta bir kere
okunur, kimse sonradan değiştiremez.

## 2. Bean'i devreye almanın iki yolu

`@ConfigurationProperties` sınıfı tek başına bean olmaz. İki seçeneğin var:

### Yol A — `@EnableConfigurationProperties` (record ile bunu kullan)

```java
@SpringBootApplication
@EnableConfigurationProperties(SiparisAyarlari.class)
public class SiparisServisiUygulamasi { ... }
```

### Yol B — `@ConfigurationPropertiesScan`

```java
@SpringBootApplication
@ConfigurationPropertiesScan
public class SiparisServisiUygulamasi { ... }
```

Bu, `@ConfigurationProperties` işaretli **tüm** sınıfları tarar — tek tek listelemekten
kurtarır. Çok sayıda ayar sınıfın varsa tercih et.

### ❌ Neden `@Component` yazmıyoruz

Sınıfın başına `@Component` de yazabilirsin ve çalışır — ama `record` ile **çalışmaz**:
`record` için Spring constructor bağlaması yapar ve bu, `@Component` yoluyla devreye
girmez. `record` kullanıyorsan Yol A ya da Yol B.

## 3. Doğrulama: ayarı açılışta denetle ⭐

Asıl kazanç burada. Ayar sınıfına kısıt ekle:

```java
@Validated                                          // ← doğrulamayı açar
@ConfigurationProperties(prefix = "siparis")
public record SiparisAyarlari(
        @NotBlank String magazaAdi,
        @Min(100) @Max(10_000) int zamanAsimi,
        Duration bekleme,
        List<String> sunucular) {
}
```

Gerekli bağımlılık:

```xml
<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-validation</artifactId>
</dependency>
```

Şimdi biri ayarı bozarsa (`magaza-adi` boş, `zaman-asimi=5`), uygulama **açılmaz** ve şunu
yazar — gerçek çıktı:

```
***************************
APPLICATION FAILED TO START
***************************

Description:

Binding to target tr.loncademy.siparis.SiparisAyarlari failed:

    Property: siparis.magazaAdi
    Value: ""
    Origin: class path resource [application.properties] - 2:0
    Reason: must not be blank

    Property: siparis.zamanAsimi
    Value: "5"
    Origin: class path resource [application.properties] - 2:21
    Reason: must be greater than or equal to 100

Action:

Update your application's configuration
```

Bu çıktıyı iyi oku, çünkü yapabileceği şeyler `@Value`'nun elinden gelmez:

| Ne veriyor | Neden önemli |
|---|---|
| **İki hatayı birden** listeliyor | Tek tek düzeltip yeniden çalıştırmıyorsun |
| **`Origin:` satırı** | Hangi dosya, **hangi satır ve sütun** — `2:21` |
| Okunabilir sebep | `must be greater than or equal to 100` |
| **Açılışta** patlıyor | Yanlış ayar üretime hiç çıkmıyor |

⭐ Bu, bu bölümün asıl dersi: **ayar doğrulaması, hatayı sessiz olmaktan çıkarıp gürültülü
yapar.** [3.1](3.1-oncelik-sirasi.md)'deki "sessiz hata" sorununa karşı en güçlü savunman.

### Sık kullanılan kısıtlar

| Kısıt | Ne der |
|---|---|
| `@NotNull` | `null` olamaz |
| `@NotBlank` | Metin boş ya da sadece boşluk olamaz |
| `@Min` / `@Max` | Sayı aralığı |
| `@Positive` / `@PositiveOrZero` | Pozitiflik |
| `@Size(min=, max=)` | Liste/metin uzunluğu |
| `@Pattern(regexp=)` | Düzenli ifade |
| `@Email` | E-posta biçimi |
| `@Valid` | İç içe nesneyi de doğrula — ⚠️ unutulursa iç nesne **denetlenmez** |

## 4. İç içe yapı

```java
@Validated
@ConfigurationProperties(prefix = "siparis")
public record SiparisAyarlari(
        @NotBlank String magazaAdi,
        @Valid Yeniden yenidenDeneme) {        // ← @Valid olmadan iç kısıtlar çalışmaz

    public record Yeniden(@Min(1) @Max(10) int adet, Duration aralik) {}
}
```

```yaml
siparis:
  magaza-adi: Merkez
  yeniden-deneme:
    adet: 3
    aralik: 2s
```

> 📌 **Sık yapılan hata:** İç içe nesnede `@Valid` yazmayı unutmak. Dış kısıtlar çalışır,
> iç kısıtlar **sessizce** atlanır — yani doğrulama koyduğunu sanırsın ama koymamışsındır.

## 5. Varsayılan değerler

`record` bileşenlerine doğrudan varsayılan yazamazsın. İki yol:

### Yol A — ayar dosyasında varsayılan (tercih et)

Kütüphane yazmıyorsan en basiti budur: değeri `application.properties`'e koy.

### Yol B — sıkıştırılmış constructor

```java
@ConfigurationProperties(prefix = "siparis")
public record SiparisAyarlari(String magazaAdi, Duration bekleme) {

    public SiparisAyarlari {
        if (bekleme == null) bekleme = Duration.ofSeconds(30);
    }
}
```

⚠️ Sınıf (record değil) kullanıyorsan alanlara doğrudan varsayılan atarsın — ama o zaman
değişmezliği kaybedersin.

---

## 6. IDE ipuçları: `application.properties`'te otomatik tamamlama

Şu bağımlılığı eklersen, IDE ayar adlarını tamamlar ve yazım hatasını **yazarken** gösterir:

```xml
<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-configuration-processor</artifactId>
  <optional>true</optional>
</dependency>
```

Derleme sırasında `META-INF/spring-configuration-metadata.json` üretir; IDE bunu okur.
Küçük bir ekleme, günlük hayatta büyük fark.

## 7. Yanlış hâlleri

### ❌ Hata 1 — `record` + `@Component`

```java
@Component                                       // ← record ile çalışmaz
@ConfigurationProperties(prefix = "siparis")
public record SiparisAyarlari(String magazaAdi) {}
```

✅ **Doğrusu:** `@EnableConfigurationProperties` ya da `@ConfigurationPropertiesScan`.

### ❌ Hata 2 — `@Validated` yazmadan kısıt koymak

```java
@ConfigurationProperties(prefix = "siparis")     // ← @Validated yok
public record SiparisAyarlari(@Min(100) int zamanAsimi) {}
```

Kısıt orada duruyor ama **hiç denetlenmiyor.** `zaman-asimi=5` sorunsuz geçer.

✅ **Doğrusu:** Sınıfın başına `@Validated` ekle.

📌 Bu ikisi (`@Validated` unutmak, iç içe `@Valid` unutmak) aynı aileden: **doğrulama
koyduğunu sanmak, ama koymamış olmak.** Bir kısıt eklediğinde onu bilerek bozup gerçekten
patladığını gör.

### ❌ Hata 3 — önek (prefix) yazımı

```java
@ConfigurationProperties(prefix = "siparisAyarlari")   // ← camelCase önek
```

Önek **kebab-case** olmalı: `siparis-ayarlari`. Büyük harfli önek çalışmaz.

---

## Sık karıştırılanlar — tek tabloda

| Karışan | Doğrusu | Neden diğeri değil |
|---|---|---|
| `@Value` / `@ConfigurationProperties` | 1–2 ayar → `@Value`; 3+ → `@ConfigurationProperties` | `@Value` ayar adını metin olarak taşır; doğrulama ve gruplama yapamaz |
| `record` + `@Component` | **Çalışmaz** | `record` constructor bağlaması ister; `@EnableConfigurationProperties` ya da `...Scan` kullan |
| Kısıt yazmak = doğrulama | **Değil** | `@Validated` yoksa kısıtlar sessizce yok sayılır |
| İç içe nesne kendiliğinden doğrulanır | **Doğrulanmaz** | Dış alana `@Valid` yazmalısın |
| Önek camelCase olabilir | **kebab-case** | `siparisAyarlari` değil, `siparis-ayarlari` |
| Doğrulama uygulamayı kırar | **Kırmasını istersin** | Yanlış ayarla açılmak, yanlış ayarla çalışmaktan iyidir |

### Adım 1 — Bağımlılığı ekle

`pom.xml`'de `spring-boot-starter-validation` yoksa ekle
([00.2](../00-baslangic/02-kurulum.md)'de eklemiştik).

### Adım 2 — Ayar sınıfını yaz

`tr/loncademy/siparis/SiparisAyarlari.java`:

```java
package tr.loncademy.siparis;

import jakarta.validation.constraints.Max;
import jakarta.validation.constraints.Min;
import jakarta.validation.constraints.NotBlank;
import java.time.Duration;
import java.util.List;
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.validation.annotation.Validated;

@Validated
@ConfigurationProperties(prefix = "siparis")
public record SiparisAyarlari(
        @NotBlank String magazaAdi,
        @Min(100) @Max(10_000) int zamanAsimi,
        Duration bekleme,
        List<String> sunucular) {
}
```

Ana sınıfa ekle:

```java
@EnableConfigurationProperties(SiparisAyarlari.class)
```

`application.properties`:

```properties
siparis.magaza-adi=Merkez
siparis.zaman-asimi=3000
siparis.bekleme=45s
siparis.sunucular[0]=a.sirket.com
siparis.sunucular[1]=b.sirket.com
```

`main`'e ekle:

```java
System.out.println("### AYAR = " + container.getBean(SiparisAyarlari.class));
```

## Nasıl karşına çıkar — örnek kalıplar

**Kalıp 1 — `Binding to target ... failed` + `Reason:`**
> Ayar doğrulaması çalıştı. `Origin:` satırından dosya ve satırı bul.

**Kalıp 2 — "Kısıt koydum ama geçersiz değer geçiyor"**
> `@Validated` eksik ya da iç içe nesnede `@Valid` eksik.

**Kalıp 3 — "record ayar sınıfım bean değil"**
> `@EnableConfigurationProperties` ya da `@ConfigurationPropertiesScan` eksik.

**Kalıp 4 — "IDE ayar adlarını tamamlamıyor"**
> `spring-boot-configuration-processor` eksik.

**Kalıp 5 — "`Duration` alanım `null` geliyor"**
> Ayar dosyasında karşılığı yok ya da önek yanlış yazılmış.

## 60 saniyelik özet

- 1–2 ayar → `@Value`. **3+ ayar → `@ConfigurationProperties`.**
- `record` ile bağla: alanlar `final`, ayar nesnesi değişmez.
- Bağlama relaxed'tır (`magaza-adi` → `magazaAdi`) ve tip dönüştürür (`45s` → `PT45S`).
- Bean yapmak için **`@EnableConfigurationProperties`** ya da **`@ConfigurationPropertiesScan`** —
  `record` ile `@Component` **çalışmaz**.
- ⭐ **`@Validated` + kısıtlar**, yanlış ayarı açılışta yakalar ve `Origin:` ile
  dosya:satır:sütun verir.
- `@Validated` yoksa kısıtlar **sessizce yok sayılır**.
- İç içe nesnede `@Valid` yazmayı unutma — iç kısıtlar aksi hâlde denetlenmez.
- Önek **kebab-case** yazılır.
- `spring-boot-configuration-processor` IDE'de otomatik tamamlama verir.
